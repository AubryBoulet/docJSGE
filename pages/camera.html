Camera

Classe permettant de gérer l'affichage et le rendu des éléments dans un canvas.

📌 Description

La classe Camera est le cœur du système de rendu de JSGE. Elle permet de définir une zone de visualisation dans un canvas, de gérer les arrière-plans (couleur ou image), et de dessiner des entités à des positions spécifiques. Plusieurs caméras peuvent coexister sur le même canvas, ce qui permet de créer des effets de split-screen ou des interfaces complexes.

⚠️ Important: Une caméra doit toujours être associée à un élément canvas valide. Sans canvas, la caméra ne pourra pas rendre les éléments.

🚀 Utilisation de base

Pour créer une caméra, vous avez besoin d'un élément canvas et de définir ses dimensions :

import { Camera } from "../classes/camera.js";

const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#222"
});

Une fois la caméra créée, vous pouvez commencer à dessiner des éléments :

// Effacer la caméra (à faire à chaque frame)
mainCam.clear();

// Dessiner une entité (après avoir créé l'entité)
entity.drawEntity(mainCam);

🔧 Constructeur

La classe Camera accepte les paramètres suivants :

Paramètre Type Défaut Description
canvas HTMLCanvasElement null L'élément canvas sur lequel la caméra va dessiner. Obligatoire
position {x: number, y: number} {x: 0, y: 0} Position initiale de la caméra dans la scène (en pixels).
dimensions {width: number, height: number} {width: 100, height: 100} Largeur et hauteur de la zone de rendu de la caméra.
backgroundColor string null Couleur d'arrière-plan de la caméra (ex: "#ff0000", "blue", "rgba(0,0,0,0.5)").
backgroundImage string null Chemin vers une image d'arrière-plan (ex: "./assets/background.png").

📜 Propriétés

canvas

Type: HTMLCanvasElement

Description: L'élément canvas associé à la caméra.

ctx

Type: CanvasRenderingContext2D

Description: Le contexte 2D du canvas.

position

Type: {x: number, y: number}

Description: Position de la caméra dans la scène (en pixels).

dimensions

Type: {width: number, height: number}

Description: Taille de la zone de rendu de la caméra.

backgroundColor

Type: string | null

Description: Couleur d'arrière-plan de la caméra.

backgroundImage

Type: string | null

Description: Image d'arrière-plan de la caméra.

backgroundImageVelocity

Type: {x: number, y: number}

Description: Vitesse de défilement de l'image d'arrière-plan (en pixels par frame).

backgroundImageLoop

Type: boolean

Description: Si vrai, l'image d'arrière-plan se répète en boucle.

backgroundImageFillStyle

Type: string

Description: Style de remplissage de l'image. Valeurs possibles : "imageSize" ou "cover".

⚙️ Méthodes

clear()

Description: Efface le contenu de la caméra en appelant clearRect sur le contexte. Si un arrière-plan est défini, il sera redessiné.

Retourne: void

drawCameraBorder(color)

Paramètres:

  • color: string - La couleur de la bordure (ex: "yellow", "#ff0000").

Description: Dessine une bordure colorée autour de la caméra. Utile pour le débogage.

Retourne: void

moveCamera(offset, mode)

Paramètres:

  • offset: {x: number, y: number} - Le déplacement à appliquer.
  • mode: "relative" | "absolute" - Le mode de déplacement.

Description: Déplace la caméra selon un offset. En mode "relative", l'offset est ajouté à la position actuelle. En mode "absolute", l'offset devient la nouvelle position.

Retourne: void

🎯 Exemples

Exemple 1: Caméra avec arrière-plan couleur

Utilisez les flèches pour déplacer la caméra. 

import { Camera } from "../classes/camera.js";

const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#222"
});

// Déplacer la caméra avec les flèches
document.addEventListener("keydown", (e) => {
    const speed = 5;
    switch(e.key) {
        case 'ArrowRight':
            mainCam.moveCamera({x: speed, y: 0}, "relative");
            break;
        case 'ArrowLeft':
            mainCam.moveCamera({x: -speed, y: 0}, "relative");
            break;
        case 'ArrowDown':
            mainCam.moveCamera({x: 0, y: speed}, "relative");
            break;
        case 'ArrowUp':
            mainCam.moveCamera({x: 0, y: -speed}, "relative");
            break;
    }
});

function gameLoop() {
    mainCam.clear();
    // Dessiner vos entités ici...
    requestAnimationFrame(gameLoop);
}
gameLoop();

Exemple 2: Caméra avec image d'arrière-plan animée

import { Camera } from "../classes/camera.js";

const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundImage: "./assets/background.png",
    backgroundImageVelocity: {x: 1, y: 0},
    backgroundImageLoop: true,
    backgroundImageFillStyle: "imageSize"
});

// L'image va défiler automatiquement vers la droite
function gameLoop() {
    mainCam.clear();
    // Dessiner vos entités ici...
    requestAnimationFrame(gameLoop);
}
gameLoop();

Exemple 3: Plusieurs caméras sur le même canvas

import { Camera } from "../classes/camera.js";

const canvas = document.querySelector("#gameCanvas");

// Caméra principale pour le jeu
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 600, height: 600},
    backgroundColor: "#222"
});

// Caméra secondaire pour l'interface
const uiCam = new Camera({
    canvas: canvas,
    position: {x: 600, y: 0},
    dimensions: {width: 200, height: 600},
    backgroundColor: "#111"
});

function gameLoop() {
    // Effacer les deux caméras
    mainCam.clear();
    uiCam.clear();
    
    // Dessiner le jeu dans mainCam
    // ...
    
    // Dessiner l'interface dans uiCam
    // ...
    
    requestAnimationFrame(gameLoop);
}
gameLoop();

💡 Conseils et bonnes pratiques

  • 🔹 Toujours effacer la caméra à chaque frame avec clear() pour éviter les artefacts visuels.
  • 🔹 Utilisez plusieurs caméras pour créer des effets de split-screen ou séparer le jeu de l'interface.
  • 🔹 Pour un jeu avec défilement, utilisez moveCamera() avec un offset relatif pour suivre le joueur.
  • 🔹 Les propriétés backgroundImageVelocity et backgroundImageLoop permettent de créer des arrière-plans animés sans code supplémentaire.
  • 🔹 Utilisez drawCameraBorder() pendant le développement pour visualiser les limites de la caméra.
  • 🔹 Pour de meilleures performances, évitez de créer trop de caméras actives simultanément.
