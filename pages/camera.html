Camera

Class for managing display and rendering of elements in a canvas.

📌 Description

The Camera class is the heart of the JSGE rendering system. It allows you to define a viewing area within a canvas, manage backgrounds (color or image), and draw entities at specific positions. Multiple cameras can coexist on the same canvas, which allows you to create split-screen effects or complex interfaces.

⚠️ Important: A camera must always be associated with a valid canvas element. Without a canvas, the camera cannot render elements.

🚀 Basic Usage

To create a camera, you need a canvas element and define its dimensions:

import { Camera } from "../classes/camera.js";

const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#222"
});

Once the camera is created, you can start drawing elements:

// Clear the camera (do this every frame)
mainCam.clear();

// Draw an entity (after creating the entity)
entity.drawEntity(mainCam);

🔧 Constructor

The Camera class accepts the following parameters:

Parameter Type Default Description
canvas HTMLCanvasElement null The canvas element on which the camera will draw. Required
position {x: number, y: number} {x: 0, y: 0} Initial position of the camera in the scene (in pixels).
dimensions {width: number, height: number} {width: 100, height: 100} Width and height of the camera's rendering area.
backgroundColor string null Background color of the camera (e.g., "#ff0000", "blue", "rgba(0,0,0,0.5)").
backgroundImage string null Path to a background image (e.g., "./assets/background.png").

📜 Properties

canvas

Type: HTMLCanvasElement

Description: The canvas element associated with the camera.

ctx

Type: CanvasRenderingContext2D

Description: The 2D context of the canvas.

position

Type: {x: number, y: number}

Description: Position of the camera in the scene (in pixels).

dimensions

Type: {width: number, height: number}

Description: Size of the camera's rendering area.

backgroundColor

Type: string | null

Description: Background color of the camera.

backgroundImage

Type: string | null

Description: Background image of the camera.

backgroundImageVelocity

Type: {x: number, y: number}

Description: Scrolling speed of the background image (in pixels per frame).

backgroundImageLoop

Type: boolean

Description: If true, the background image repeats in a loop.

backgroundImageFillStyle

Type: string

Description: Fill style of the image. Possible values: "imageSize" or "cover".

⚙️ Methods

clear()

Description: Clears the camera content by calling clearRect on the context. If a background is defined, it will be redrawn.

Returns: void

drawCameraBorder(color)

Parameters:

  • color: string - The border color (e.g., "yellow", "#ff0000").

Description: Draws a colored border around the camera. Useful for debugging.

Returns: void

moveCamera(newPosition, mode)

Parameters:

  • newPosition: {x: number, y: number} - The position offset to apply.
  • mode: "relative" | "absolute" - The movement mode.

Description: Moves the camera by an offset. In "relative" mode, the offset is added to the current position. In "absolute" mode, the offset becomes the new position.

Returns: void

🎯 Examples

Example 1: Camera with Color Background

Use arrow keys to move the camera. 

import { Camera } from "../classes/camera.js";

const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#222"
});

// Move camera with arrow keys
document.addEventListener("keydown", (e) => {
    const speed = 5;
    switch(e.key) {
        case 'ArrowRight':
            mainCam.moveCamera({x: speed, y: 0}, "relative");
            break;
        case 'ArrowLeft':
            mainCam.moveCamera({x: -speed, y: 0}, "relative");
            break;
        case 'ArrowDown':
            mainCam.moveCamera({x: 0, y: speed}, "relative");
            break;
        case 'ArrowUp':
            mainCam.moveCamera({x: 0, y: -speed}, "relative");
            break;
    }
});

function gameLoop() {
    mainCam.clear();
    // Draw your entities here...
    requestAnimationFrame(gameLoop);
}
gameLoop();

Example 2: Camera with Animated Background Image

import { Camera } from "../classes/camera.js";

const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundImage: "./assets/background.png",
    backgroundImageVelocity: {x: 1, y: 0},
    backgroundImageLoop: true,
    backgroundImageFillStyle: "imageSize"
});

// The image will automatically scroll to the right
function gameLoop() {
    mainCam.clear();
    // Draw your entities here...
    requestAnimationFrame(gameLoop);
}
gameLoop();

Example 3: Multiple Cameras on the Same Canvas

import { Camera } from "../classes/camera.js";

const canvas = document.querySelector("#gameCanvas");

// Main camera for the game
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 600, height: 600},
    backgroundColor: "#222"
});

// Secondary camera for the UI
const uiCam = new Camera({
    canvas: canvas,
    position: {x: 600, y: 0},
    dimensions: {width: 200, height: 600},
    backgroundColor: "#111"
});

function gameLoop() {
    // Clear both cameras
    mainCam.clear();
    uiCam.clear();
    
    // Draw game in mainCam
    // ...
    
    // Draw UI in uiCam
    // ...
    
    requestAnimationFrame(gameLoop);
}
gameLoop();

💡 Tips and Best Practices

  • 🔹 Always clear the camera every frame with clear() to avoid visual artifacts.
  • 🔹 Use multiple cameras to create split-screen effects or separate game from UI.
  • 🔹 For a game with scrolling, adjust the camera's position property directly to follow the player. Note: a dedicated scrolling method is planned but not yet implemented.
  • 🔹 The backgroundImageVelocity and backgroundImageLoop properties allow you to create animated backgrounds without additional code.
  • 🔹 Use drawCameraBorder() during development to visualize camera boundaries.
  • 🔹 For better performance, avoid creating too many active cameras simultaneously.
