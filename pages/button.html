Button

Class for creating interactive buttons with mouse event handling.

📌 Description

The Button class inherits from Gadget and allows you to create interactive buttons for the user interface. Buttons can contain text, have background colors, borders, shadows, and respond to mouse events (hover, click).

The special feature of Button is that it allows you to use special effect tags in its text to create advanced animations (waves, blinks, etc.).

🚀 Basic Usage

Create a Simple Button

import { Button } from "../classes/button.js";
import { Camera } from "../classes/camera.js";

// Create a button
const myButton = Button.create("My Button", {
    width: 200,
    height: 50
});

// Set position
myButton.position = {x: 100, y: 100};

// Set events
myButton.onClick = () => {
    console.log("Button clicked!");
};

myButton.onMouseEnter = () => {
    console.log("Mouse over button");
};

myButton.onMouseLeave = () => {
    console.log("Mouse out of button");
};

// Draw the button in a camera
function gameLoop() {
    mainCam.clear();
    myButton.draw(mainCam);
    requestAnimationFrame(gameLoop);
}

Create a Button with Text Effects

import { Button } from "../classes/button.js";

// Create a button with special effects in the text
const fancyButton = Button.create(
    "${wave(2,5,5)} Button ${blink(0,20)} animated ${wave(2,5,10) with effects}",
    {width: 250, height: 60}
);

// Customize appearance
fancyButton.position = {x: 150, y: 150};
fancyButton.backgroundColor = "#3498db";
fancyButton.color = "#fff";

// Add a gradient to the text
const gradient = document.createElement('canvas').getContext('2d').createLinearGradient(0, 0, 250, 0);
gradient.addColorStop(0, "#f1c40f");
gradient.addColorStop(1, "#e74c3c");
fancyButton.addTextGradient("myGrad", gradient);
fancyButton.updateText();

// Draw the button
fancyButton.draw(mainCam);

🔧 Creation Method

The Button class uses a static create() method to create instances:

Parameter Type Default Description
value string "" Button text. Can contain special effect tags.
dimension {width: number, height: number} - Dimensions of the button.
position {x: number, y: number} {x: 0, y: 0} Initial position of the button.
backgroundType "color" | "image" "color" Background type of the button.
src string undefined Path to a background image (if backgroundType is "image").

📜 Properties

In addition to the properties inherited from Gadget, Button offers:

backgroundType

Type: "color" | "image"

Description: Background type of the button.

backgroundColor

Type: string

Description: Background color of the button (if backgroundType is "color").

backgroundImage

Type: string

Description: Path to the background image (if backgroundType is "image").

boxShadow

Type: Array

Description: Array defining the button shadows. Each element is an array [x, y, color, blur, spread, opacity].

borderRadius

Type: Array

Description: Array defining the border radii [top-left, top-right, bottom-right, bottom-left].

textAlign

Type: string

Description: Text alignment in the button ("start", "center", "end", "left", "right").

font

Type: string

Description: Font of the button text.

🎯 Examples

Example 1: Button with Advanced Effects

Hover over the button to see the effects. 

import { Button } from "../classes/button.js";
import { Camera } from "../classes/camera.js";

// Create a button with advanced text effects
const button = Button.create(
    "${wave(5,2,7) Button ${blink(0,20) with} ${wave(2,5,10) effects}}",
    {width: 200, height: 60}
);

// Customize appearance
button.position = {x: 200, y: 150};
button.backgroundColor = "#F0F";
button.color = "#000";
button.textAlign = "center";
button.font = "bold 16px Arial";

// Add shadows
button.boxShadow = [
    [-6, -10, "#FFA", 1],
    [6, 5, "rgba(0, 0, 255, 0.61)", 3]
];

// Add border radius
button.borderRadius = [10, 5, 20, 0];

// Set events
button.onMouseEnter = () => {
    console.log("Mouse over button");
};

button.onMouseLeave = () => {
    console.log("Mouse out of button");
};

button.onClick = () => {
    console.log("Button clicked!");
};

// Draw the button
function gameLoop() {
    mainCam.clear();
    button.draw(mainCam);
    requestAnimationFrame(gameLoop);
}
gameLoop();

Example 2: Button with Text Gradient

import { Button } from "../classes/button.js";

// Create a gradient
const gradient = document.createElement('canvas').getContext('2d').createLinearGradient(0, 0, 200, 0);
gradient.addColorStop(0, "green");
gradient.addColorStop(1, "rgba(0, 255, 0, 0.09)");

// Create a button
const button = Button.create(
    "${grad(myGrad) Text with gradient}",
    {width: 200, height: 50}
);

// Add the gradient to the button
button.addTextGradient("myGrad", gradient);
button.updateText(); // Important: update text after adding gradient

button.position = {x: 100, y: 100};
button.backgroundColor = "#222";
button.color = "#fff"; // This color won't be used as we have a gradient

// Draw the button
button.draw(mainCam);

Example 4: Multiple Buttons with Click Handling

import { Button } from "../classes/button.js";

// Create multiple buttons
const buttons = [];
const buttonConfigs = [
    {text: "New Game", action: startNewGame},
    {text: "Load", action: loadGame},
    {text: "Options", action: showOptions},
    {text: "Quit", action: quitGame}
];

buttonConfigs.forEach((config, index) => {
    const button = Button.create(config.text, {
        width: 150,
        height: 40
    });
    
    button.position = {x: 100, y: 100 + index * 60};
    button.backgroundColor = "#3498db";
    button.color = "#fff";
    button.onClick = config.action;
    
    // Hover effect
    button.onMouseEnter = () => {
        button.backgroundColor = "#2980b9";
    };
    
    button.onMouseLeave = () => {
        button.backgroundColor = "#3498db";
    };
    
    buttons.push(button);
});

// Action functions
function startNewGame() {
    console.log("New game started");
}

function loadGame() {
    console.log("Loading game");
}

function showOptions() {
    console.log("Showing options");
}

function quitGame() {
    console.log("Quit game");
}

// Draw all buttons
function gameLoop() {
    mainCam.clear();
    buttons.forEach(button => button.draw(mainCam));
    requestAnimationFrame(gameLoop);
}

💡 Tips and Best Practices

  • 🔹 Use effect tags to create animated and attractive buttons.
  • 🔹 Call updateText() after adding or modifying gradients.
  • 🔹 Customize appearance with boxShadow and borderRadius for modern buttons.
  • 🔹 Use textAlign to center or align text in the button.
  • 🔹 For buttons with images, make sure the image is loaded before drawing.
  • 🔹 Handle hover states (onMouseEnter, onMouseLeave) for better UX.

📖 Available Effect Tags

Button (via Gadget and Text) supports the following effect tags in the value property:

Tag Parameters Description
${wave(amplitude, frequency, speed)} amplitude: number - Wave amplitude in pixels
frequency: number - Wave frequency
speed: number - Wave speed 		Makes text wave vertically.
${shake(amplitude, frequency, speed)} amplitude: number - Shake amplitude in pixels
frequency: number - Shake frequency
speed: number - Shake speed 		Makes text shake.
${blink(start, duration)} start: number - Blink start position
duration: number - Blink duration in frames 		Makes text blink.
${grad(name)} name: string - Name of the gradient registered with addTextGradient() Applies a color gradient to the text.
