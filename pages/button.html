Button

Classe pour créer des boutons interactifs avec gestion des événements souris.

📌 Description

La classe Button hérite de Gadget et permet de créer des boutons interactifs pour l'interface utilisateur. Les boutons peuvent contenir du texte, avoir des couleurs d'arrière-plan, des bordures, des ombres, et répondre aux événements de la souris (survol, clic).

La particularité de Button est qu'il permet d'utiliser des tags d'effets spéciaux dans son texte pour créer des animations avancées (ondulations, clignotements, etc.).

🚀 Utilisation de base

Créer un bouton simple

import { Button } from "../classes/button.js";
import { Camera } from "../classes/camera.js";

// Créer un bouton
const myButton = Button.create("Mon Bouton", {
    width: 200,
    height: 50
});

// Définir la position
myButton.position = {x: 100, y: 100};

// Définir les événements
myButton.onClick = () => {
    console.log("Bouton cliqué !");
};

myButton.onMouseEnter = () => {
    console.log("Souris sur le bouton");
};

myButton.onMouseLeave = () => {
    console.log("Souris hors du bouton");
};

// Dessiner le bouton dans une caméra
function gameLoop() {
    mainCam.clear();
    myButton.draw(mainCam);
    requestAnimationFrame(gameLoop);
}

Créer un bouton avec des effets de texte

import { Button } from "../classes/button.js";

// Créer un bouton avec des effets spéciaux dans le texte
const fancyButton = Button.create(
    "${wave(2,5,5)} Bouton ${blink(0,20)} animé ${wave(2,5,10) avec effets}",
    {width: 250, height: 60}
);

// Personnaliser l'apparence
fancyButton.position = {x: 150, y: 150};
fancyButton.backgroundColor = "#3498db";
fancyButton.color = "#fff";

// Ajouter un dégradé au texte
const gradient = document.createElement('canvas').getContext('2d').createLinearGradient(0, 0, 250, 0);
gradient.addColorStop(0, "#f1c40f");
gradient.addColorStop(1, "#e74c3c");
fancyButton.addTextGradient("myGrad", gradient);
fancyButton.updateText();

// Dessiner le bouton
fancyButton.draw(mainCam);

🔧 Méthode de création

La classe Button utilise une méthode statique create() pour créer des instances :

Paramètre Type Défaut Description
value string "" Texte du bouton. Peut contenir des tags d'effets spéciaux.
dimension {width: number, height: number} - Dimensions du bouton.
position {x: number, y: number} {x: 0, y: 0} Position initiale du bouton.
backgroundType "color" | "image" "color" Type d'arrière-plan du bouton.
src string undefined Chemin vers une image d'arrière-plan (si backgroundType est "image").

📜 Propriétés

En plus des propriétés héritées de Gadget, Button offre :

backgroundType

Type: "color" | "image"

Description: Type d'arrière-plan du bouton.

backgroundColor

Type: string

Description: Couleur d'arrière-plan du bouton (si backgroundType est "color").

backgroundImage

Type: string

Description: Chemin vers l'image d'arrière-plan (si backgroundType est "image").

boxShadow

Type: Array

Description: Tableau définissant les ombres du bouton. Chaque élément est un tableau [x, y, couleur, flou, étalement, opacity].

borderRadius

Type: Array

Description: Tableau définissant les rayons de bordure [top-left, top-right, bottom-right, bottom-left].

textAlign

Type: string

Description: Alignement du texte dans le bouton ("start", "center", "end", "left", "right").

font

Type: string

Description: Police du texte du bouton.

🎯 Exemples

Exemple 1: Bouton avec effets avancés

Passez la souris sur le bouton pour voir les effets. 

import { Button } from "../classes/button.js";
import { Camera } from "../classes/camera.js";

// Créer un bouton avec des effets de texte avancés
const button = Button.create(
    "${wave(5,2,7) Bouton ${blink(0,20) avec} ${wave(2,5,10) effets}}",
    {width: 200, height: 60}
);

// Personnaliser l'apparence
button.position = {x: 200, y: 150};
button.backgroundColor = "#F0F";
button.color = "#000";
button.textAlign = "center";
button.font = "bold 16px Arial";

// Ajouter des ombres
button.boxShadow = [
    [-6, -10, "#FFA", 1],
    [6, 5, "rgba(0, 0, 255, 0.61)", 3]
];

// Ajouter un rayon de bordure
button.borderRadius = [10, 5, 20, 0];

// Définir les événements
button.onMouseEnter = () => {
    console.log("Souris sur le bouton");
};

button.onMouseLeave = () => {
    console.log("Souris hors du bouton");
};

button.onClick = () => {
    console.log("Bouton cliqué !");
};

// Dessiner le bouton
function gameLoop() {
    mainCam.clear();
    button.draw(mainCam);
    requestAnimationFrame(gameLoop);
}
gameLoop();

Exemple 2: Bouton avec dégradé de texte

import { Button } from "../classes/button.js";

// Créer un dégradé
const gradient = document.createElement('canvas').getContext('2d').createLinearGradient(0, 0, 200, 0);
gradient.addColorStop(0, "green");
gradient.addColorStop(1, "rgba(0, 255, 0, 0.09)");

// Créer un bouton
const button = Button.create(
    "${grad(myGrad) Texte avec dégradé}",
    {width: 200, height: 50}
);

// Ajouter le dégradé au bouton
button.addTextGradient("myGrad", gradient);
button.updateText(); // Important: mettre à jour le texte après avoir ajouté le dégradé

button.position = {x: 100, y: 100};
button.backgroundColor = "#222";
button.color = "#fff"; // Cette couleur ne sera pas utilisée car on a un dégradé

// Dessiner le bouton
button.draw(mainCam);

Exemple 4: Plusieurs boutons avec gestion des clics

import { Button } from "../classes/button.js";

// Créer plusieurs boutons
const buttons = [];
const buttonConfigs = [
    {text: "Nouveau Jeu", action: startNewGame},
    {text: "Charger", action: loadGame},
    {text: "Options", action: showOptions},
    {text: "Quitter", action: quitGame}
];

buttonConfigs.forEach((config, index) => {
    const button = Button.create(config.text, {
        width: 150,
        height: 40
    });
    
    button.position = {x: 100, y: 100 + index * 60};
    button.backgroundColor = "#3498db";
    button.color = "#fff";
    button.onClick = config.action;
    
    // Effet de survol
    button.onMouseEnter = () => {
        button.backgroundColor = "#2980b9";
    };
    
    button.onMouseLeave = () => {
        button.backgroundColor = "#3498db";
    };
    
    buttons.push(button);
});

// Fonctions d'action
function startNewGame() {
    console.log("Nouveau jeu démarré");
}

function loadGame() {
    console.log("Chargement du jeu");
}

function showOptions() {
    console.log("Affichage des options");
}

function quitGame() {
    console.log("Quitter le jeu");
}

// Dessiner tous les boutons
function gameLoop() {
    mainCam.clear();
    buttons.forEach(button => button.draw(mainCam));
    requestAnimationFrame(gameLoop);
}

💡 Conseils et bonnes pratiques

  • 🔹 Utilisez les tags d'effets pour créer des boutons animés et attrayants.
  • 🔹 Appelez updateText() après avoir ajouté ou modifié des dégradés.
  • 🔹 Personnalisez l'apparence avec boxShadow et borderRadius pour des boutons modernes.
  • 🔹 Utilisez textAlign pour centrer ou aligner le texte dans le bouton.
  • 🔹 Pour les boutons avec images, assurez-vous que l'image est chargée avant de dessiner.
  • 🔹 Gérez les états de survol (onMouseEnter, onMouseLeave) pour une meilleure UX.

📖 Tags d'effets disponibles

Button (via Gadget et Text) supporte les tags d'effets suivants dans la propriété value :

Tag Paramètres Description
${wave(amplitude, frequency, speed)} amplitude: number - Amplitude de l'onde en pixels
frequency: number - Fréquence de l'onde
speed: number - Vitesse de l'onde 		Fait onduler le texte verticalement.
${shake(amplitude, frequency, speed)} amplitude: number - Amplitude du tremblement en pixels
frequency: number - Fréquence du tremblement
speed: number - Vitesse du tremblement 		Fait trembler le texte.
${blink(start, duration)} start: number - Position de départ du clignotement
duration: number - Durée du clignotement 		Fait clignoter le texte.
${grad(name)} name: string - Nom du dégradé enregistré avec addTextGradient() Applique un dégradé au texte.
