Particle

Class representing an individual particle in the particle system. Used internally by ParticleEmitter.

📝 Description

The Particle class represents an individual particle with position, velocity, size, color, and lifetime properties. This class is primarily used internally by ParticleEmitter and is not typically instantiated directly by developers.

⚠️ Important: This class is intended for internal use by ParticleEmitter. Developers can modify particle properties if they understand the implications, but this is not recommended for most use cases.

📦 Constructor

The Particle class accepts the following parameters:

Parameter Type Description
x number Initial X coordinate of the particle.
y number Initial Y coordinate of the particle.
vx number Initial X velocity of the particle.
vy number Initial Y velocity of the particle.
size object Size of the particle ({width: number, height: number}).
color string Color of the particle (HEX or RGB format).
lifetime number Lifetime of the particle in milliseconds.

📊 Properties

All properties have getter and setter methods.

x

Type: number

Description: X coordinate of the particle.

y

Type: number

Description: Y coordinate of the particle.

vx

Type: number

Description: X velocity of the particle (pixels per frame).

vy

Type: number

Description: Y velocity of the particle (pixels per frame).

size

Type: object

Description: Size of the particle ({width: number, height: number}).

color

Type: string

Description: Color of the particle (HEX or RGB format).

lifetime

Type: number

Description: Remaining lifetime of the particle in milliseconds.

💡 Tips and Best Practices

  • 🎯 This class is primarily for internal use by ParticleEmitter.
  • 🎯 Particles are automatically managed by ParticleEmitter including creation, updates, and cleanup.
  • 🎯 Particle properties (position, velocity, color) are updated every frame by the emitter.
  • 🎯 Particles with lifetime <= 0 are automatically removed.
  • 🎯 Particles that go out of camera view are automatically removed for performance optimization.
