Bezier

Classe contenant les fonctions d'interpolation (easing) pour les animations fluides.

📌 Description

La classe Bezier contient une collection complète de fonctions d'interpolation (easing functions) pour créer des animations fluides et naturelles. Ces fonctions sont utilisées par la classe Transition pour interpoler les valeurs entre un point de départ et un point d'arrivée.

Chaque fonction d'interpolation prend les mêmes paramètres :

  • 🔹 t - Temps écoulé (en millisecondes)
  • 🔹 b - Valeur de début
  • 🔹 c - Changement de valeur (target - start)
  • 🔹 d - Durée totale (en millisecondes)

La formule générale est : position = b + easing(t, b, c, d)

⚠️ Important: Toutes les fonctions de Bezier sont statiques. Vous ne devez pas instancier la classe Bezier.

🚀 Utilisation de base

Utiliser une fonction d'interpolation directement

import { Bezier } from "../classes/bezier.js";

// Utiliser une fonction d'interpolation
const startValue = 0;
const endValue = 100;
const duration = 2000; // 2 secondes
let startTime = performance.now();

function animate(timestamp) {
    const elapsed = timestamp - startTime;
    
    // Calculer la valeur interpolée
    const progress = Math.min(elapsed / duration, 1);
    const value = Bezier.easeOutElastic(
        progress * duration,  // t
        startValue,          // b
        endValue - startValue, // c
        duration             // d
    );
    
    console.log("Valeur:", value);
    
    if (progress < 1) {
        requestAnimationFrame(animate);
    }
}

requestAnimationFrame(animate);

Utiliser avec la classe Transition

import { Transition } from "../classes/transition.js";

// Transition utilise automatiquement les fonctions de Bezier
const transitionId = Transition.create([
    0,
    500,
    "easeOutElastic",  // Nom de la fonction d'interpolation
    (value) => {
        element.style.left = value + "px";
    },
    1.5  // Durée en secondes
]);

📜 Fonctions d'interpolation

La classe Bezier contient les fonctions d'interpolation suivantes, classées par type :

📈 Linéaire

Bezier.linear(t, b, c, d)

Description: Interpolation linéaire. Vitesse constante.

Formule: c * (t / d) + b

Utilisation: Déplacements à vitesse constante, progressions linéaires.

📊 Quadratique

Bezier.easeInQuad(t, b, c, d)

Description: Accélération quadratique.

Formule: c * (t /= d) * t + b

Utilisation: Animations qui commencent lentement et accélèrent.

Bezier.easeOutQuad(t, b, c, d)

Description: Décélération quadratique.

Formule: -c * (t /= d) * (t - 2) + b

Utilisation: Animations qui commencent rapidement et ralentissent.

Bezier.easeInOutQuad(t, b, c, d)

Description: Accélération puis décélération quadratique.

Formule: t < d/2 ? c/2 * t * t + b : -c/2 * ((--t) * (t - 2) - 1) + b

Utilisation: Animations fluides avec accélération et décélération.

📉 Cubique

Bezier.easeInCubic(t, b, c, d)

Description: Accélération cubique.

Formule: c * (t /= d) * t * t + b

Utilisation: Accélération plus prononcée que Quad.

Bezier.easeOutCubic(t, b, c, d)

Description: Décélération cubique.

Formule: c * ((t = t / d - 1) * t * t + 1) + b

Utilisation: Décélération plus prononcée que Quad.

Bezier.easeInOutCubic(t, b, c, d)

Description: Accélération puis décélération cubique.

Formule: t < d/2 ? c/2 * t * t * t + b : c/2 * ((t -= 2) * t * t + 2) + b

Utilisation: Effet plus prononcé que Quad.

🔢 Quartique

Bezier.easeInQuart(t, b, c, d)

Description: Accélération quartique.

Formule: c * (t /= d) * t * t * t + b

Bezier.easeOutQuart(t, b, c, d)

Description: Décélération quartique.

Formule: -c * ((t = t / d - 1) * t * t * t - 1) + b

Bezier.easeInOutQuart(t, b, c, d)

Description: Accélération puis décélération quartique.

🔢 Quintique

Bezier.easeInQuint(t, b, c, d)

Description: Accélération quintique.

Bezier.easeOutQuint(t, b, c, d)

Description: Décélération quintique.

Bezier.easeInOutQuint(t, b, c, d)

Description: Accélération puis décélération quintique.

🌊 Sinusoïdale

Bezier.easeInSine(t, b, c, d)

Description: Accélération sinusoïdale.

Bezier.easeOutSine(t, b, c, d)

Description: Décélération sinusoïdale.

Bezier.easeInOutSine(t, b, c, d)

Description: Accélération puis décélération sinusoïdale.

🚀 Exponentielle

Bezier.easeInExpo(t, b, c, d)

Description: Accélération exponentielle.

Bezier.easeOutExpo(t, b, c, d)

Description: Décélération exponentielle.

Bezier.easeInOutExpo(t, b, c, d)

Description: Accélération puis décélération exponentielle.

🎯 Circulaire

Bezier.easeInCirc(t, b, c, d)

Description: Accélération circulaire.

Bezier.easeOutCirc(t, b, c, d)

Description: Décélération circulaire.

Bezier.easeInOutCirc(t, b, c, d)

Description: Accélération puis décélération circulaire.

🪀 Élastique

Bezier.easeInElastic(t, b, c, d)

Description: Accélération élastique avec rebond.

Bezier.easeOutElastic(t, b, c, d)

Description: Décélération élastique avec rebond.

Bezier.easeInOutElastic(t, b, c, d)

Description: Accélération puis décélération élastique avec rebond.

🔙 Retour (Back)

Bezier.easeInBack(t, b, c, d)

Description: Accélération avec mouvement de retour.

Bezier.easeOutBack(t, b, c, d)

Description: Décélération avec mouvement de retour.

Bezier.easeInOutBack(t, b, c, d)

Description: Accélération puis décélération avec mouvement de retour.

🏀 Rebond (Bounce)

Bezier.easeOutBounce(t, b, c, d)

Description: Décélération avec effet de rebond.

Bezier.easeInBounce(t, b, c, d)

Description: Accélération avec effet de rebond.

Bezier.easeInOutBounce(t, b, c, d)

Description: Accélération puis décélération avec effet de rebond.

🎯 Exemples

Exemple 1: Visualisation des courbes d'interpolation

Animation automatique montrant une courbe de Bézier cubique. 

import { Bezier } from "../classes/bezier.js";

const canvas = document.querySelector("#bezier-canvas");
const ctx = canvas.getContext("2d");

// Dessiner une courbe de Bézier cubique
function drawBezierCurve() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    
    // Points de contrôle
    const p0 = {x: 50, y: 200};
    const p1 = {x: 150, y: 50};
    const p2 = {x: 250, y: 350};
    const p3 = {x: 350, y: 200};
    
    // Dessiner la courbe
    ctx.strokeStyle = "#3498db";
    ctx.lineWidth = 2;
    ctx.beginPath();
    ctx.moveTo(p0.x, p0.y);
    ctx.bezierCurveTo(p1.x, p1.y, p2.x, p2.y, p3.x, p3.y);
    ctx.stroke();
    
    // Dessiner les points de contrôle
    ctx.fillStyle = "#e74c3c";
    [p0, p1, p2, p3].forEach(p => {
        ctx.beginPath();
        ctx.arc(p.x, p.y, 5, 0, Math.PI * 2);
        ctx.fill();
    });
    
    // Dessiner les lignes de contrôle
    ctx.strokeStyle = "#ddd";
    ctx.lineWidth = 1;
    ctx.beginPath();
    ctx.moveTo(p0.x, p0.y);
    ctx.lineTo(p1.x, p1.y);
    ctx.lineTo(p2.x, p2.y);
    ctx.lineTo(p3.x, p3.y);
    ctx.stroke();
}

drawBezierCurve();

Exemple 2: Comparaison des fonctions d'interpolation

import { Bezier } from "../classes/bezier.js";

const canvas = document.querySelector("#comparison-canvas");
const ctx = canvas.getContext("2d");

// Fonctions d'interpolation à comparer
const easings = [
    "linear",
    "easeInQuad",
    "easeOutQuad",
    "easeInOutQuad",
    "easeOutElastic",
    "easeOutBounce"
];

// Dessiner les courbes de toutes les fonctions
function drawEasingComparison() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    
    const width = canvas.width / easings.length;
    
    easings.forEach((easing, index) => {
        ctx.strokeStyle = getRandomColor();
        ctx.lineWidth = 2;
        ctx.beginPath();
        
        for (let t = 0; t <= 1; t += 0.01) {
            // Normaliser t entre 0 et 1
            const x = index * width + t * width;
            const y = canvas.height - Bezier[easing](t * 1000, 0, 1, 1000) * canvas.height;
            
            if (t === 0) {
                ctx.moveTo(x, y);
            } else {
                ctx.lineTo(x, y);
            }
        }
        
        ctx.stroke();
        
        // Dessiner le nom de la fonction
        ctx.fillStyle = "#000";
        ctx.font = "12px Arial";
        ctx.fillText(easing, index * width + 10, canvas.height - 10);
    });
}

drawEasingComparison();

function getRandomColor() {
    return '#' + Math.floor(Math.random() * 16777215).toString(16);
}

Exemple 3: Animation avec différentes fonctions d'interpolation

import { Bezier } from "../classes/bezier.js";

// Animer plusieurs éléments avec différentes fonctions d'interpolation
const elements = [
    {el: document.getElementById("box1"), easing: "easeInQuad"},
    {el: document.getElementById("box2"), easing: "easeOutElastic"},
    {el: document.getElementById("box3"), easing: "easeInOutBack"},
    {el: document.getElementById("box4"), easing: "easeOutBounce"}
];

let startTime = performance.now();
const duration = 2000;

function animate() {
    const elapsed = performance.now() - startTime;
    const progress = Math.min(elapsed / duration, 1);
    
    elements.forEach(({el, easing}) => {
        const value = Bezier[easing](
            progress * duration,
            0,
            400,
            duration
        );
        el.style.left = value + "px";
    });
    
    if (progress < 1) {
        requestAnimationFrame(animate);
    } else {
        // Réinitialiser pour une nouvelle animation
        startTime = performance.now();
        elements.forEach(({el}) => {
            el.style.left = "0px";
        });
        requestAnimationFrame(animate);
    }
}

animate();

💡 Conseils et bonnes pratiques

  • 🔹 Utilisez easeOutElastic pour des effets de rebond élastique.
  • 🔹 Utilisez easeInOutQuad ou easeInOutCubic pour des animations fluides et naturelles.
  • 🔹 Utilisez linear pour des déplacements à vitesse constante.
  • 🔹 Utilisez easeOutBounce pour des effets de rebond (comme un ballon qui tombe).
  • 🔹 Utilisez easeInBack pour des animations qui "tirent" vers l'arrière avant de partir.
  • 🔹 Expérimentez avec différentes fonctions pour trouver celle qui correspond le mieux à votre effet souhaité.
  • 🔹 Vous pouvez combiner plusieurs fonctions pour créer des animations complexes.
