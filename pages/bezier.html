Bezier

Class containing interpolation (easing) functions for smooth animations.

📌 Description

The Bezier class contains a complete collection of interpolation functions (easing functions) for creating smooth and natural animations. These functions are used by the Transition class to interpolate values between a start point and an end point.

Each interpolation function takes the same parameters:

  • 🔹 t - Elapsed time (in milliseconds)
  • 🔹 b - Start value
  • 🔹 c - Change in value (target - start)
  • 🔹 d - Total duration (in milliseconds)

The general formula is: position = b + easing(t, b, c, d)

⚠️ Important: All Bezier functions are static. You should not instantiate the Bezier class.

🚀 Basic Usage

Use an Interpolation Function Directly

import { Bezier } from "../classes/bezier.js";

// Use an interpolation function
const startValue = 0;
const endValue = 100;
const duration = 2000; // 2 seconds
let startTime = performance.now();

function animate(timestamp) {
    const elapsed = timestamp - startTime;
    
    // Calculate the interpolated value
    const progress = Math.min(elapsed / duration, 1);
    const value = Bezier.easeOutElastic(
        progress * duration,  // t
        startValue,          // b
        endValue - startValue, // c
        duration             // d
    );
    
    console.log("Value:", value);
    
    if (progress < 1) {
        requestAnimationFrame(animate);
    }
}

requestAnimationFrame(animate);

Use with the Transition Class

import { Transition } from "../classes/transition.js";

// Transition automatically uses Bezier functions
const transitionId = Transition.create([
    0,
    500,
    "easeOutElastic",  // Name of the interpolation function
    (value) => {
        element.style.left = value + "px";
    },
    1.5  // Duration in seconds
]);

📜 Interpolation Functions

The Bezier class contains the following interpolation functions, grouped by type:

📈 Linear

Bezier.linear(t, b, c, d)

Description: Linear interpolation. Constant speed.

Formula: c * (t / d) + b

Usage: Constant speed movements, linear progressions.

📊 Quadratic

Bezier.easeInQuad(t, b, c, d)

Description: Quadratic acceleration.

Formula: c * (t /= d) * t + b

Usage: Animations that start slowly and accelerate.

Bezier.easeOutQuad(t, b, c, d)

Description: Quadratic deceleration.

Formula: -c * (t /= d) * (t - 2) + b

Usage: Animations that start quickly and slow down.

Bezier.easeInOutQuad(t, b, c, d)

Description: Quadratic acceleration then deceleration.

Formula: t < d/2 ? c/2 * t * t + b : -c/2 * ((--t) * (t - 2) - 1) + b

Usage: Smooth animations with acceleration and deceleration.

📉 Cubic

Bezier.easeInCubic(t, b, c, d)

Description: Cubic acceleration.

Formula: c * (t /= d) * t * t + b

Usage: More pronounced acceleration than Quad.

Bezier.easeOutCubic(t, b, c, d)

Description: Cubic deceleration.

Formula: c * ((t = t / d - 1) * t * t + 1) + b

Usage: More pronounced slow down than Quad.

Bezier.easeInOutCubic(t, b, c, d)

Description: Cubic acceleration then deceleration.

Formula: t < d/2 ? c/2 * t * t * t + b : c/2 * ((t -= 2) * t * t + 2) + b

Usage: More pronounced effect than Quad.

🔢 Quartic

Bezier.easeInQuart(t, b, c, d)

Description: Quartic acceleration.

Formula: c * (t /= d) * t * t * t + b

Bezier.easeOutQuart(t, b, c, d)

Description: Quartic deceleration.

Formula: -c * ((t = t / d - 1) * t * t * t - 1) + b

Bezier.easeInOutQuart(t, b, c, d)

Description: Quartic acceleration then deceleration.

🔢 Quintic

Bezier.easeInQuint(t, b, c, d)

Description: Quintic acceleration.

Bezier.easeOutQuint(t, b, c, d)

Description: Quintic deceleration.

Bezier.easeInOutQuint(t, b, c, d)

Description: Quintic acceleration then deceleration.

🌊 Sine

Bezier.easeInSine(t, b, c, d)

Description: Sine acceleration.

Bezier.easeOutSine(t, b, c, d)

Description: Sine deceleration.

Bezier.easeInOutSine(t, b, c, d)

Description: Sine acceleration then deceleration.

🚀 Exponential

Bezier.easeInExpo(t, b, c, d)

Description: Exponential acceleration.

Bezier.easeOutExpo(t, b, c, d)

Description: Exponential deceleration.

Bezier.easeInOutExpo(t, b, c, d)

Description: Exponential acceleration then deceleration.

🎯 Circular

Bezier.easeInCirc(t, b, c, d)

Description: Circular acceleration.

Bezier.easeOutCirc(t, b, c, d)

Description: Circular deceleration.

Bezier.easeInOutCirc(t, b, c, d)

Description: Circular acceleration then deceleration.

🪀 Elastic

Bezier.easeInElastic(t, b, c, d)

Description: Elastic acceleration with bounce.

Bezier.easeOutElastic(t, b, c, d)

Description: Elastic deceleration with bounce.

Bezier.easeInOutElastic(t, b, c, d)

Description: Elastic acceleration then deceleration with bounce.

🔙 Back

Bezier.easeInBack(t, b, c, d)

Description: Back acceleration with overshoot.

Bezier.easeOutBack(t, b, c, d)

Description: Back deceleration with overshoot.

Bezier.easeInOutBack(t, b, c, d)

Description: Back acceleration then deceleration with overshoot.

🏀 Bounce

Bezier.easeOutBounce(t, b, c, d)

Description: Bounce deceleration.

Effect: Pronounced bounce effect (like a ball).

Bezier.easeInBounce(t, b, c, d)

Description: Bounce acceleration.

Bezier.easeInOutBounce(t, b, c, d)

Description: Bounce acceleration then deceleration.

🎯 Examples

Example 1: Visualizing Interpolation Curves

Automatic animation showing a cubic Bezier curve. 

import { Bezier } from "../classes/bezier.js";

const canvas = document.querySelector("#bezier-canvas");
const ctx = canvas.getContext("2d");

// Draw a cubic Bezier curve
function drawBezierCurve() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    
    // Control points
    const p0 = {x: 50, y: 200};
    const p1 = {x: 150, y: 50};
    const p2 = {x: 250, y: 350};
    const p3 = {x: 350, y: 200};
    
    // Draw the curve
    ctx.strokeStyle = "#3498db";
    ctx.lineWidth = 2;
    ctx.beginPath();
    ctx.moveTo(p0.x, p0.y);
    ctx.bezierCurveTo(p1.x, p1.y, p2.x, p2.y, p3.x, p3.y);
    ctx.stroke();
    
    // Draw control points
    ctx.fillStyle = "#e74c3c";
    [p0, p1, p2, p3].forEach(p => {
        ctx.beginPath();
        ctx.arc(p.x, p.y, 5, 0, Math.PI * 2);
        ctx.fill();
    });
    
    // Draw control lines
    ctx.strokeStyle = "#ddd";
    ctx.lineWidth = 1;
    ctx.beginPath();
    ctx.moveTo(p0.x, p0.y);
    ctx.lineTo(p1.x, p1.y);
    ctx.lineTo(p2.x, p2.y);
    ctx.lineTo(p3.x, p3.y);
    ctx.stroke();
}

drawBezierCurve();

Example 2: Comparing Interpolation Functions

import { Bezier } from "../classes/bezier.js";

const canvas = document.querySelector("#comparison-canvas");
const ctx = canvas.getContext("2d");

// Interpolation functions to compare
const easings = [
    "linear",
    "easeInQuad",
    "easeOutQuad",
    "easeInOutQuad",
    "easeOutElastic",
    "easeOutBounce"
];

// Draw curves for all functions
function drawEasingComparison() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    
    const width = canvas.width / easings.length;
    
    easings.forEach((easing, index) => {
        ctx.strokeStyle = getRandomColor();
        ctx.lineWidth = 2;
        ctx.beginPath();
        
        for (let t = 0; t <= 1; t += 0.01) {
            // Normalize t between 0 and 1
            const x = index * width + t * width;
            const y = canvas.height - Bezier[easing](t * 1000, 0, 1, 1000) * canvas.height;
            
            if (t === 0) {
                ctx.moveTo(x, y);
            } else {
                ctx.lineTo(x, y);
            }
        }
        
        ctx.stroke();
        
        // Draw function name
        ctx.fillStyle = "#000";
        ctx.font = "12px Arial";
        ctx.fillText(easing, index * width + 10, canvas.height - 10);
    });
}

drawEasingComparison();

function getRandomColor() {
    return '#' + Math.floor(Math.random() * 16777215).toString(16);
}

Example 3: Animation with Different Interpolation Functions

import { Bezier } from "../classes/bezier.js";

// Animate multiple elements with different interpolation functions
const elements = [
    {el: document.getElementById("box1"), easing: "easeInQuad"},
    {el: document.getElementById("box2"), easing: "easeOutElastic"},
    {el: document.getElementById("box3"), easing: "easeInOutBack"},
    {el: document.getElementById("box4"), easing: "easeOutBounce"}
];

let startTime = performance.now();
const duration = 2000;

function animate() {
    const elapsed = performance.now() - startTime;
    const progress = Math.min(elapsed / duration, 1);
    
    elements.forEach(({el, easing}) => {
        const value = Bezier[easing](
            progress * duration,
            0,
            400,
            duration
        );
        el.style.left = value + "px";
    });
    
    if (progress < 1) {
        requestAnimationFrame(animate);
    } else {
        // Reset for new animation
        startTime = performance.now();
        elements.forEach(({el}) => {
            el.style.left = "0px";
        });
        requestAnimationFrame(animate);
    }
}

animate();

💡 Tips and Best Practices

  • 🔹 Use easeOutElastic for elastic bounce effects.
  • 🔹 Use easeInOutQuad or easeInOutCubic for smooth and natural animations.
  • 🔹 Use linear for constant speed movements.
  • 🔹 Use easeOutBounce for bounce effects (like a falling ball).
  • 🔹 Use easeInBack for animations that "pull" backward before starting.
  • 🔹 Experiment with different functions to find the one that best matches your desired effect.
  • 🔹 You can combine multiple functions to create complex animations.
