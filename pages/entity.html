Entity

Class for creating and managing game objects with physics, sprites and animations.

📌 Description

The Entity class represents a game object. It combines a sprite (or multiple), a position, velocity, and physical properties. Entities can be drawn in a camera and updated every frame to create animations and interactions.

This is the central class of JSGE for everything related to game objects: players, enemies, interactive objects, etc.

⚠️ Important: To draw an entity, you must call drawEntity() with a valid camera.

🚀 Basic Usage

Create a Simple Entity

import { Entity } from "../classes/entity.js";
import { Sprite } from "../classes/sprites.js";

// Create a sprite
const playerSprite = await Sprite.load("./assets/player.png", false);

// Create an entity with the sprite
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    scale: 1
});

// Draw the entity in a camera
function gameLoop() {
    mainCam.clear();
    player.drawEntity(mainCam);
    requestAnimationFrame(gameLoop);
}

Create an Entity with Additional Properties

import { Entity } from "../classes/entity.js";

// Define custom properties
const playerStats = {
    life: 100,
    mana: 50,
    takeDamage: function(damage) {
        this.life -= damage;
        console.log(`Life: ${this.life}`);
    },
    heal: function(amount) {
        this.life = Math.min(100, this.life + amount);
    }
};

// Create an entity with custom properties
const player = Entity.create(
    {
        sprite: playerSprite,
        position: {x: 100, y: 100},
        scale: 1,
        physic: true,
        gravity: 0.5
    },
    [playerStats]  // Array of additional properties
);

// Use custom methods
player.takeDamage(10);  // Logs "Life: 90"
player.heal(15);       // Heals 15 points

🔧 Constructor

The Entity class can be instantiated directly, but it's recommended to use the static create() method:

Parameter Type Default Description
datas object - Object containing the entity properties.
assigns Array null Array of objects containing additional properties to add to the entity.

The datas object can contain the following properties:

Property Type Default Description
sprite Sprite - The entity's sprite.
position {x: number, y: number} {x: 0, y: 0} Initial position of the entity.
scale number 1 Scale of the entity.
physic boolean false If true, enables basic physics (gravity, velocity).
gravity number 0 Gravity force applied to the entity.
acceleration {x: number, y: number} {x: 0, y: 0} Initial acceleration of the entity.
velocity {x: number, y: number} {x: 0, y: 0} Initial velocity of the entity.
targetFPS number 60 Target FPS for updates.

⚙️ Methods

update()

Description: Updates the entity (position, animations, physics). Must be called every frame.

Returns: void

drawEntity(camera)

Parameters:

  • camera: Camera - The camera to draw the entity in.

Description: Draws the entity in the specified camera.

Returns: void

addColisionWithEntity(entity, callback)

Parameters:

  • entity: Entity - The entity to detect collisions with.
  • callback: function - Function called when a collision occurs.

Description: Adds collision detection with another entity.

Returns: void

🎯 Examples

Example 1: Entity with Simple Physics

Arrows: Move | Space: Jump 

import { Entity } from "../classes/entity.js";
import { Sprite } from "../classes/sprites.js";
import { Camera } from "../classes/camera.js";

// Create a sprite for the entity
const entitySprite = Sprite.create(40, 40, false);
const ctx = entitySprite.ctx;
ctx.fillStyle = "#e74c3c";
ctx.fillRect(0, 0, 40, 40);

// Create an entity with physics
const player = Entity.create({
    sprite: entitySprite,
    position: {x: 100, y: 100},
    physic: true,
    gravity: 0.5
});

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

// Keyboard input handling
document.addEventListener("keydown", (e) => {
    const force = 5;
    switch(e.key) {
        case 'ArrowRight':
            player.velocity.x = force;
            break;
        case 'ArrowLeft':
            player.velocity.x = -force;
            break;
        case ' ':
            player.velocity.y = -12; // Jump
            break;
    }
});

function gameLoop() {
    mainCam.clear();
    
    // Update entity (applies gravity and physics)
    player.update();
    
    // Draw entity
    player.drawEntity(mainCam);
    
    requestAnimationFrame(gameLoop);
}
gameLoop();

Example 2: Entity with Animations

import { Entity } from "../classes/entity.js";
import { Sprite } from "../classes/sprites.js";

// Load an animated sprite
const characterSprite = await Sprite.load("./assets/character_sheet.png", true);

// Configure the sprite sheet
characterSprite.animations.column = 10;
characterSprite.animations.row = 5;
characterSprite.animations.frameRate = 12;

// Create animations
characterSprite.animations.createAnimationFrames(0, 3, "idle", 12);
characterSprite.animations.createAnimationFrames(10, 17, "walk", 12);

// Create an entity
const character = Entity.create({
    sprite: characterSprite,
    position: {x: 200, y: 200},
    physic: true
});

// Set default animation
character.currentAnimation = "idle";

// Change animation based on state
function updateCharacter() {
    if (Math.abs(character.velocity.x) > 0.1 || Math.abs(character.velocity.y) > 0.1) {
        character.currentAnimation = "walk";
    } else {
        character.currentAnimation = "idle";
    }
}

function gameLoop() {
    mainCam.clear();
    
    updateCharacter();
    character.update();
    character.drawEntity(mainCam);
    
    requestAnimationFrame(gameLoop);
}

Example 3: Collision Detection Between Entities

import { Entity } from "../classes/entity.js";
import { Sprite } from "../classes/sprites.js";

// Create two sprites
const playerSprite = Sprite.create(30, 30, false);
playerSprite.ctx.fillStyle = "#3498db";
playerSprite.ctx.fillRect(0, 0, 30, 30);

const enemySprite = Sprite.create(30, 30, false);
enemySprite.ctx.fillStyle = "#e74c3c";
enemySprite.ctx.fillRect(0, 0, 30, 30);

// Create entities
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    physic: true
});

const enemy = Entity.create({
    sprite: enemySprite,
    position: {x: 200, y: 200},
    physic: true
});

// Add collision detection
player.addColisionWithEntity(enemy, (collisionResult) => {
    console.log("Collision detected!", collisionResult);
    
    // Reverse player velocity
    player.velocity.x *= -1;
    player.velocity.y *= -1;
    
    // Visual effect: make player flash
    player.sprite.ctx.fillStyle = "#f1c40f";
    player.sprite.ctx.fillRect(0, 0, 30, 30);
    
    setTimeout(() => {
        player.sprite.ctx.fillStyle = "#3498db";
        player.sprite.ctx.fillRect(0, 0, 30, 30);
    }, 200);
});

function gameLoop() {
    mainCam.clear();
    
    player.update();
    enemy.update();
    
    player.drawEntity(mainCam);
    enemy.drawEntity(mainCam);
    
    requestAnimationFrame(gameLoop);
}

Example 4: Entity with Custom Properties

import { Entity } from "../classes/entity.js";

// Define player properties
const playerStats = {
    life: 100,
    mana: 50,
    maxLife: 100,
    maxMana: 100,
    level: 1,
    experience: 0,
    
    // Methods
    takeDamage: function(damage) {
        this.life -= damage;
        if (this.life <= 0) {
            this.die();
        }
    },
    
    heal: function(amount) {
        this.life = Math.min(this.maxLife, this.life + amount);
    },
    
    addExperience: function(exp) {
        this.experience += exp;
        if (this.experience >= this.level * 100) {
            this.levelUp();
        }
    },
    
    levelUp: function() {
        this.level++;
        this.experience = 0;
        this.maxLife += 20;
        this.maxMana += 10;
        this.life = this.maxLife;
        this.mana = this.maxMana;
        console.log(`Level up! Level ${this.level}`);
    },
    
    die: function() {
        console.log("Game Over!");
        // Reset position
        this.position.x = 100;
        this.position.y = 100;
        this.life = this.maxLife;
    }
};

// Create an entity with player properties
const player = Entity.create(
    {
        sprite: playerSprite,
        position: {x: 100, y: 100},
        scale: 1.5,
        physic: true,
        gravity: 0.5
    },
    [playerStats]
);

// Use the methods
player.takeDamage(20);  // Reduces life by 20
player.heal(10);       // Heals 10 points
player.addExperience(50); // Adds experience

💡 Tips and Best Practices

  • 🔹 Always call update() every frame to update position and animations.
  • 🔹 Use drawEntity() with a camera to display the entity on screen.
  • 🔹 For platform games, enable physics and set appropriate gravity.
  • 🔹 Use custom properties (assigns) to add specific statistics and methods to your entities.
  • 🔹 For collisions, use addColisionWithEntity() to detect interactions between entities.
  • 🔹 The flippedX and flippedY properties are useful for flipping sprites (e.g., character facing left).
  • 🔹 For better performance, avoid creating too many active entities simultaneously.
