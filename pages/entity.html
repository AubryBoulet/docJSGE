Entity

Class for creating and managing game objects with physics, sprites and animations.

📝 Description

The Entity class represents a game object. It combines a sprite (or multiple), a position, velocity, and physical properties. Entities can be drawn in a camera and updated every frame to create animations and interactions.

This is the central class of JSGE for everything related to game objects: players, enemies, interactive objects, etc.

New Features:

  • Enhanced collision detection with hitbox support
  • Gravity system with acceleration and contact detection
  • Improved entity-to-entity collision handling
  • Auto-update toggle for manual control
  • Frame hitbox support for precise collision detection

ℹ️ Important: To draw an entity, you must add it to a Scene and call scene.draw(camera) followed by camera.flipBuffer(). The entity will be automatically updated if autoUpdate is true (default).
⚠️ IMPORTANT: Entities do NOT have their own drawing functions. You MUST add entities to a Scene and use scene.draw(camera) to render them. Direct drawing is not supported.

🚀 Basic Usage

Create a Simple Entity

import { Entity, Scene } from "./jsge.js";
import { Sprite } from "./jsge.js";

// Create a sprite
const playerSprite = await Sprite.load("./assets/player.png", false);

// Create an entity with the sprite
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    scale: 1
});

// Create a scene - MANDATORY
const gameScene = new Scene();
gameScene.add(player, 1);

// Draw through scene - ONLY way to draw
function gameLoop() {
    mainCam.clear();
    gameScene.draw(mainCam);
    mainCam.flipBuffer(); // MUST be called
    requestAnimationFrame(gameLoop);
}

Create an Entity with Additional Properties

import { Entity, Scene } from "./jsge.js";

// Define custom properties
const playerStats = {
    life: 100,
    score: 0,
    canJump: true
};

// Create an entity with custom properties
const player = Entity.create(
    {
        sprite: playerSprite,
        position: {x: 100, y: 100},
        scale: 1,
        physic: true
    },
    [playerStats]
);

// Add to scene
const gameScene = new Scene();
gameScene.add(player, 1);

// Access custom properties
console.log(player.life); // 100
player.score += 10;

Create an Entity with Physics

import { Entity, Scene } from "./jsge.js";

const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    scale: 1,
    physic: true,           // Enable physics
    gravity: 0.5,           // Gravity strength
    gravityAcceleration: 1, // How quickly gravity accelerates
    acceleration: {x: 0, y: 0}, // Acceleration for movement
    velocity: {x: 0, y: 0}     // Initial velocity
});

// Add to scene
const gameScene = new Scene();
gameScene.add(player, 1);

// In game loop
function gameLoop() {
    mainCam.clear();
    player.update();  // Updates position based on velocity, gravity, etc.
    gameScene.draw(mainCam);
    mainCam.flipBuffer();
    requestAnimationFrame(gameLoop);
}

📥 Constructor

The Entity class accepts the following parameters:

Parameter Type Default Description
options Object {} Configuration object for the entity.
options.sprite Sprite null The sprite to display for this entity.
options.position {x: number, y: number} {x: 0, y: 0} Initial position of the entity.
options.scale number 1 Scale factor for the entity.
options.physic boolean false Whether physics are enabled for this entity.
options.gravity number 0 Gravity strength applied to the entity.
options.gravityAcceleration number 1 How quickly gravity accelerates (increase for faster falling).
options.acceleration {x: number, y: number} {x: 0, y: 0} Acceleration applied to velocity.
options.velocity {x: number, y: number} {x: 0, y: 0} Initial velocity of the entity.

Static Factory Method

The Entity.create() method allows creating entities with custom properties:

Parameter Type Default Description
datas Object null Base configuration for the entity (sprite, position, scale, physics, etc.).
assigns Array<Object> null Array of objects containing custom properties and methods to assign to the entity.

📊 Properties

sprite

Type: Sprite

Description: The sprite displayed by this entity.

position

Type: {x: number, y: number}

Description: Current position of the entity.

scale

Type: number

Description: Scale factor of the entity.

physic

Type: boolean

Description: Whether physics are enabled for this entity.

gravity

Type: number

Description: Gravity strength applied to the entity.

gravityAcceleration

Type: number

Description: Rate at which gravity accelerates.

acceleration

Type: {x: number, y: number}

Description: Acceleration applied to velocity.

velocity

Type: {x: number, y: number}

Description: Current velocity of the entity.

currentAnimation

Type: AnimationFrame | null

Description: The currently playing animation.

frameRate

Type: number

Description: Frame rate for the current animation.

flippedX

Type: boolean

Description: If true, the entity is flipped horizontally.

flippedY

Type: boolean

Description: If true, the entity is flipped vertically.

autoUpdate

Type: boolean

Description: If true, the entity automatically calls update() when drawn. Set to false for manual control.

physics

Type: Array

Description: Array of collision physics objects. Each contains an entity and a collision callback.

⚙️ Methods

⚠️ IMPORTANT: Entities do NOT have public drawing methods. All rendering MUST be done through a Scene. The methods below are for internal use or advanced scenarios only.

draw(cam, zOrder)

Parameters:

  • cam: Camera - The camera to draw through.
  • zOrder: number - The z-order for rendering (default: 0).

Description: ⚠️ NOT RECOMMENDED: While this method exists, you should NOT use it directly. Always use scene.draw(camera) instead for proper rendering with z-order sorting and collision detection.

Returns: void

update()

Description: Updates the entity's position based on velocity, acceleration, and gravity. Also updates animation frames and checks for collisions if physics are enabled.

Returns: void

resetAcceleration()

Description: Resets the current acceleration to zero.

Returns: void

addColisionWithEntity(entity, onCollision)

Parameters:

  • entity: Entity - The entity to detect collisions with.
  • onCollision: Function - Callback function called when collision is detected.

Description: Sets up collision detection between this entity and another entity. The callback is called when the two entities' hitboxes overlap.

Returns: void

// Set up collision between player and enemy
player.addColisionWithEntity(enemy, (collidedEntity) => {
    console.log("Player collided with:", collidedEntity);
    // Handle collision (damage, bounce, etc.)
});

assign(assigns, options)

Parameters:

  • assigns: Array<Object> - Array of objects with properties to assign.
  • options: { overwrite: boolean } - Options object.

Description: Assigns custom properties and methods to the entity. By default, warns if properties already exist. Use { overwrite: true } to force overwrite.

Returns: void

create(datas, assigns) (static)

Parameters:

  • datas: Object - Base configuration for the entity.
  • assigns: Array<Object> - Custom properties and methods to assign.

Description: Static factory method to create an entity with custom properties.

Returns: Entity - The newly created entity.

_processDraw(cam)

Parameters:

  • cam: Camera - The camera to draw through.

Description: ⚠️ PRIVATE METHOD: Internal method called by the camera to process drawing. Handles clipping, positioning, and animation frames. Not intended for direct use. Incorrect usage can cause engine crashes.

Returns: void

🎯 Physics and Collision

The Entity class provides a complete physics system:

Gravity System

Entities can have gravity applied, with configurable acceleration:

const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    gravity: 0.5,           // Gravity strength
    gravityAcceleration: 1, // How fast gravity increases
    velocity: {x: 0, y: 0}
});

// Gravity will automatically pull the entity down
// The entity will accelerate until reaching maximum gravity speed

Platform Collision

Entities with gravity can land on Elements that have onGravityContact callbacks:

import { Entity, Element, Scene } from "./jsge.js";

// Create a scene
const gameScene = new Scene();

// Create a platform element
const platform = new Element({
    sprite: platformSprite,
    position: {x: 200, y: 400}
});

// Set up gravity contact callback
platform.onGravityContact = (element, entity) => {
    console.log("Entity landed on platform!");
    // Play landing sound, trigger effects, etc.
};

// Create a player with gravity
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 200, y: 100},
    gravity: 0.5,
    gravityAcceleration: 1
});

// Add to scene
gameScene.add(platform, 0);
gameScene.add(player, 1);

// Update and draw
function gameLoop() {
    mainCam.clear();
    player.update(); // This will check for gravity contact
    gameScene.draw(mainCam);
    mainCam.flipBuffer();
    requestAnimationFrame(gameLoop);
}

Entity-to-Entity Collision

Set up collision detection between entities:

const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    physic: true
});

const enemy = Entity.create({
    sprite: enemySprite,
    position: {x: 300, y: 100},
    physic: true
});

// Set up collision detection
player.addColisionWithEntity(enemy, (collidedEntity) => {
    console.log("Player collided with enemy!");
    // Handle damage, bounce, etc.
    player.velocity.x = -5; // Bounce back
});

// Create scene and add entities
const gameScene = new Scene();
gameScene.add(player, 1);
gameScene.add(enemy, 1);

// The collision will be checked automatically during update()
function gameLoop() {
    mainCam.clear();
    player.update();
    enemy.update();
    gameScene.draw(mainCam);
    mainCam.flipBuffer();
    requestAnimationFrame(gameLoop);
}

Acceleration and Velocity

Control movement with acceleration and velocity:

const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    acceleration: {x: 0.5, y: 0.5}, // Acceleration rate
    velocity: {x: 0, y: 0}
});

// Set velocity to move
document.addEventListener("keydown", (e) => {
    const speed = 5;
    switch(e.key) {
        case 'ArrowRight': player.velocity.x = speed; break;
        case 'ArrowLeft': player.velocity.x = -speed; break;
        case 'ArrowUp': player.velocity.y = -speed; break;
        case 'ArrowDown': player.velocity.y = speed; break;
    }
});

// Create scene
const gameScene = new Scene();
gameScene.add(player, 1);

// The entity will gradually accelerate to the target velocity
// due to the acceleration property
function gameLoop() {
    mainCam.clear();
    player.update(); // Updates position based on velocity and acceleration
    gameScene.draw(mainCam);
    mainCam.flipBuffer();
    requestAnimationFrame(gameLoop);
}

🎬 Animations

Entities support animated sprites with frame-based animations:

Setting Up Animations

import { Entity, Sprite, Scene } from "./jsge.js";

// Create a sprite with animations
const playerSprite = await Sprite.load("./assets/player-sheet.png", true);

// Add animations to the sprite
playerSprite.animations.addAnimation("walk", {
    frames: [
        { row: 0, column: 0 },
        { row: 0, column: 1 },
        { row: 0, column: 2 },
        { row: 0, column: 3 }
    ],
    frameWidth: 32,
    frameHeight: 48,
    frameRate: 10 // Frames per second
});

// Create an entity
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100}
});

// Set the current animation
player.currentAnimation = "walk";

// Create scene and add
const gameScene = new Scene();
gameScene.add(player, 1);

// The animation will play automatically during update()
function gameLoop() {
    mainCam.clear();
    player.update();
    gameScene.draw(mainCam);
    mainCam.flipBuffer();
    requestAnimationFrame(gameLoop);
}

Controlling Animation Frame Rate

// Change the frame rate of the current animation
player.frameRate = 15; // 15 frames per second

// Or change to a different animation
player.currentAnimation = "jump";
player.frameRate = 8; // Slower frame rate for jump animation

Example 3: Entity with Collision Detection

import { Entity, Sprite, Scene } from "./jsge.js";

const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#222"
});

// Create scene
const gameScene = new Scene();

// Create player
const playerSprite = await Sprite.load("./assets/player.png", false);
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 200, y: 300},
    physic: true
});

// Create collectible items
const coinSprite = await Sprite.load("./assets/coin.png", false);
const coins = [];
for (let i = 0; i < 10; i++) {
    const coin = Entity.create({
        sprite: coinSprite,
        position: {x: Math.random() * 600 + 100, y: Math.random() * 400 + 100},
        physic: true
    });
    
    // Set up collision with player
    player.addColisionWithEntity(coin, (collidedEntity) => {
        console.log("Collected coin!");
        // Remove coin from scene
        gameScene.remove(coin);
        // Increment score
    });
    
    coins.push(coin);
    gameScene.add(coin, 1);
}

gameScene.add(player, 2);

// Movement controls
document.addEventListener("keydown", (e) => {
    const speed = 5;
    switch(e.key) {
        case 'ArrowRight': player.velocity.x = speed; break;
        case 'ArrowLeft': player.velocity.x = -speed; break;
        case 'ArrowUp': player.velocity.y = -speed; break;
        case 'ArrowDown': player.velocity.y = speed; break;
    }
});

function gameLoop() {
    mainCam.clear();
    
    player.update();
    coins.forEach(coin => coin.update());
    
    gameScene.draw(mainCam);
    mainCam.flipBuffer();
    
    requestAnimationFrame(gameLoop);
}
gameLoop();

Example 4: Manual Update Control

import { Entity, Scene } from "./jsge.js";

const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    autoUpdate: false // Disable auto-update
});

// Create scene
const gameScene = new Scene();
gameScene.add(player, 1);

// Now you have full control over when to update
let frameCount = 0;
function gameLoop() {
    mainCam.clear();
    
    // Only update every other frame for performance
    if (frameCount % 2 === 0) {
        player.update();
    }
    
    // But still draw every frame
    gameScene.draw(mainCam);
    mainCam.flipBuffer();
    
    frameCount++;
    requestAnimationFrame(gameLoop);
}

💡 Tips and Best Practices

  • 🎯 Use Entity for dynamic objects: Entities are perfect for players, enemies, collectibles, and any game objects that move or change.
  • 🎯 Use Element for static objects: For backgrounds, platforms, and scenery that don't need physics or animations, use Element instead.
  • 🎯 ALWAYS use Scene for rendering: Entities MUST be added to a Scene. Direct drawing is not supported.
  • 🎯 Enable physics when needed: Set physic: true only for entities that need collision detection to improve performance.
  • 🎯 Configure gravity properly: Adjust gravity and gravityAcceleration to achieve the desired falling speed and feel.
  • 🎯 Use acceleration for smooth movement: The acceleration property creates smooth acceleration/deceleration effects.
  • 🎯 Manage collision callbacks: Use addColisionWithEntity() to set up interactions between game objects.
  • 🎯 Leverage auto-update: By default, entities auto-update when drawn. Set autoUpdate: false for manual control when needed.
  • 🎯 Use flipped properties for direction: Instead of loading separate sprites for left/right facing, use flippedX = true to mirror the sprite.
  • 🎯 Custom properties with assign(): Add game-specific properties (health, score, etc.) using the assign() method or factory pattern.
  • ⚠️ Avoid using _ methods: Methods starting with underscore are private and not intended for direct use. Incorrect usage can cause engine crashes.
