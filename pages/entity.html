Entity

Classe pour créer et gérer des objets du jeu avec physique, sprite et animations.

📌 Description

La classe Entity représente un objet du jeu. Elle combine un sprite (ou plusieurs), une position, une vitesse, et des propriétés physiques. Les entités peuvent être dessinées dans une caméra et mises à jour à chaque frame pour créer des animations et des interactions.

C'est la classe centrale de JSGE pour tout ce qui concerne les objets du jeu : joueurs, ennemis, objets interactifs, etc.

⚠️ Important: Pour dessiner une entité, vous devez appeler drawEntity() avec une caméra valide.

🚀 Utilisation de base

Créer une entité simple

import { Entity } from "../classes/entity.js";
import { Sprite } from "../classes/sprites.js";

// Créer un sprite
const playerSprite = await Sprite.load("./assets/player.png", false);

// Créer une entité avec le sprite
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    scale: 1
});

// Dessiner l'entité dans une caméra
function gameLoop() {
    mainCam.clear();
    player.drawEntity(mainCam);
    requestAnimationFrame(gameLoop);
}

Créer une entité avec des propriétés supplémentaires

import { Entity } from "../classes/entity.js";

// Définir des propriétés personnalisées
const playerStats = {
    life: 100,
    mana: 50,
    takeDamage: function(damage) {
        this.life -= damage;
        console.log(`Life: ${this.life}`);
    },
    heal: function(amount) {
        this.life = Math.min(100, this.life + amount);
    }
};

// Créer une entité avec des propriétés personnalisées
const player = Entity.create(
    {
        sprite: playerSprite,
        position: {x: 100, y: 100},
        scale: 1,
        physic: true,
        gravity: 0.5
    },
    [playerStats]  // Tableau de propriétés supplémentaires
);

// Utiliser les méthodes personnalisées
player.takeDamage(10);  // Affiche "Life: 90"
player.heal(15);       // Soigne de 15 points

🔧 Constructeur

La classe Entity peut être instanciée directement, mais il est recommandé d'utiliser la méthode statique create() :

Paramètre Type Défaut Description
datas object - Objet contenant les propriétés de l'entité.
assigns Array null Tableau d'objets contenant des propriétés supplémentaires à ajouter à l'entité.

L'objet datas peut contenir les propriétés suivantes :

Propriété Type Défaut Description
sprite Sprite - Le sprite de l'entité.
position {x: number, y: number} {x: 0, y: 0} Position initiale de l'entité.
scale number 1 Échelle de l'entité.
physic boolean false Si vrai, active la physique de base (gravité, vitesse).
gravity number 0 Force de gravité appliquée à l'entité.
acceleration {x: number, y: number} {x: 0, y: 0} Accélération initiale de l'entité.
velocity {x: number, y: number} {x: 0, y: 0} Vitesse initiale de l'entité.
targetFPS number 60 FPS cible pour les mises à jour.

⚙️ Méthodes

update()

Description: Met à jour l'entité (position, animations, physique). Doit être appelé à chaque frame.

Retourne: void

drawEntity(camera)

Paramètres:

  • camera: Camera - La caméra dans laquelle dessiner l'entité.

Description: Dessine l'entité dans la caméra spécifiée.

Retourne: void

addColisionWithEntity(entity, callback)

Paramètres:

  • entity: Entity - L'entité avec laquelle détecter les collisions.
  • callback: function - Fonction appelée lors d'une collision.

Description: Ajoute une détection de collision avec une autre entité.

Retourne: void

🎯 Exemples

Exemple 1: Entité avec physique simple

Flèches: Déplacer | Espace: Sauter 

import { Entity } from "../classes/entity.js";
import { Sprite } from "../classes/sprites.js";
import { Camera } from "../classes/camera.js";

// Créer un sprite pour l'entité
const entitySprite = Sprite.create(40, 40, false);
const ctx = entitySprite.ctx;
ctx.fillStyle = "#e74c3c";
ctx.fillRect(0, 0, 40, 40);

// Créer une entité avec physique
const player = Entity.create({
    sprite: entitySprite,
    position: {x: 100, y: 100},
    physic: true,
    gravity: 0.5
});

// Créer une caméra
const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

// Gestion des entrées clavier
document.addEventListener("keydown", (e) => {
    const force = 5;
    switch(e.key) {
        case 'ArrowRight':
            player.velocity.x = force;
            break;
        case 'ArrowLeft':
            player.velocity.x = -force;
            break;
        case ' ':
            player.velocity.y = -12; // Saut
            break;
    }
});

function gameLoop() {
    mainCam.clear();
    
    // Mettre à jour l'entité (applique la gravité et la physique)
    player.update();
    
    // Dessiner l'entité
    player.drawEntity(mainCam);
    
    requestAnimationFrame(gameLoop);
}
gameLoop();

Exemple 2: Entité avec animations

import { Entity } from "../classes/entity.js";
import { Sprite } from "../classes/sprites.js";

// Charger un sprite animé
const characterSprite = await Sprite.load("./assets/character_sheet.png", true);

// Configurer le sprite sheet
characterSprite.animations.column = 10;
characterSprite.animations.row = 5;
characterSprite.animations.frameRate = 12;

// Créer les animations
characterSprite.animations.createAnimationFrames(0, 3, "idle", 12);
characterSprite.animations.createAnimationFrames(10, 17, "walk", 12);

// Créer une entité
const character = Entity.create({
    sprite: characterSprite,
    position: {x: 200, y: 200},
    physic: true
});

// Définir l'animation par défaut
character.currentAnimation = "idle";

// Changer d'animation selon l'état
function updateCharacter() {
    if (Math.abs(character.velocity.x) > 0.1 || Math.abs(character.velocity.y) > 0.1) {
        character.currentAnimation = "walk";
    } else {
        character.currentAnimation = "idle";
    }
}

function gameLoop() {
    mainCam.clear();
    
    updateCharacter();
    character.update();
    character.drawEntity(mainCam);
    
    requestAnimationFrame(gameLoop);
}

Exemple 3: Détection de collisions entre entités

import { Entity } from "../classes/entity.js";
import { Sprite } from "../classes/sprites.js";

// Créer deux sprites
const playerSprite = Sprite.create(30, 30, false);
playerSprite.ctx.fillStyle = "#3498db";
playerSprite.ctx.fillRect(0, 0, 30, 30);

const enemySprite = Sprite.create(30, 30, false);
enemySprite.ctx.fillStyle = "#e74c3c";
enemySprite.ctx.fillRect(0, 0, 30, 30);

// Créer les entités
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    physic: true
});

const enemy = Entity.create({
    sprite: enemySprite,
    position: {x: 200, y: 200},
    physic: true
});

// Ajouter la détection de collision
player.addColisionWithEntity(enemy, (collisionResult) => {
    console.log("Collision détectée !", collisionResult);
    
    // Inverser la vitesse du joueur
    player.velocity.x *= -1;
    player.velocity.y *= -1;
    
    // Faire clignoter le joueur (effet visuel)
    player.sprite.ctx.fillStyle = "#f1c40f";
    player.sprite.ctx.fillRect(0, 0, 30, 30);
    
    setTimeout(() => {
        player.sprite.ctx.fillStyle = "#3498db";
        player.sprite.ctx.fillRect(0, 0, 30, 30);
    }, 200);
});

function gameLoop() {
    mainCam.clear();
    
    player.update();
    enemy.update();
    
    player.drawEntity(mainCam);
    enemy.drawEntity(mainCam);
    
    requestAnimationFrame(gameLoop);
}

Exemple 4: Entité avec propriétés personnalisées

import { Entity } from "../classes/entity.js";

// Définir des propriétés de joueur
const playerStats = {
    life: 100,
    mana: 50,
    maxLife: 100,
    maxMana: 100,
    level: 1,
    experience: 0,
    
    // Méthodes
    takeDamage: function(damage) {
        this.life -= damage;
        if (this.life <= 0) {
            this.die();
        }
    },
    
    heal: function(amount) {
        this.life = Math.min(this.maxLife, this.life + amount);
    },
    
    addExperience: function(exp) {
        this.experience += exp;
        if (this.experience >= this.level * 100) {
            this.levelUp();
        }
    },
    
    levelUp: function() {
        this.level++;
        this.experience = 0;
        this.maxLife += 20;
        this.maxMana += 10;
        this.life = this.maxLife;
        this.mana = this.maxMana;
        console.log(`Level up! Niveau ${this.level}`);
    },
    
    die: function() {
        console.log("Game Over!");
        // Réinitialiser la position
        this.position.x = 100;
        this.position.y = 100;
        this.life = this.maxLife;
    }
};

// Créer une entité avec les propriétés du joueur
const player = Entity.create(
    {
        sprite: playerSprite,
        position: {x: 100, y: 100},
        scale: 1.5,
        physic: true,
        gravity: 0.5
    },
    [playerStats]
);

// Utiliser les méthodes
player.takeDamage(20);  // Réduit la vie de 20
player.heal(10);       // Soigne 10 points
player.addExperience(50); // Ajoute de l'expérience

💡 Conseils et bonnes pratiques

  • 🔹 Toujours appeler update() à chaque frame pour mettre à jour la position et les animations.
  • 🔹 Utilisez drawEntity() avec une caméra pour afficher l'entité à l'écran.
  • 🔹 Pour les jeux de plateforme, activez la physique et définissez une gravité appropriée.
  • 🔹 Utilisez les propriétés personnalisées (assigns) pour ajouter des statistiques et méthodes spécifiques à vos entités.
  • 🔹 Pour les collisions, utilisez addColisionWithEntity() pour détecter les interactions entre entités.
  • 🔹 Les propriétés flippedX et flippedY sont utiles pour retourner les sprites (ex: personnage qui regarde à gauche).
  • 🔹 Pour de meilleures performances, évitez de créer trop d'entités actives simultanément.
