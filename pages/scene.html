Scene

Class for organizing and managing groups of elements with z-order rendering.

📝 Description

The Scene class provides a way to organize and manage groups of elements with z-order (depth) rendering. Scenes allow you to group related elements together and control their rendering order, making it easier to manage complex game worlds with multiple layers of elements.

When a scene is drawn through a camera, all its elements are automatically sorted by their z-order and rendered in the correct order. This is particularly useful for creating layered backgrounds, foregrounds, and UI elements.

ℹ️ Note: Scenes work in conjunction with the Camera class. Use scene.draw(camera) to render all elements in the scene.

🚀 Basic Usage

To create a scene and add elements to it:

import { Scene } from "./classes/scene.js";
import { Element } from "./classes/element.js";

// Create a scene
const gameScene = new Scene();

// Create elements
const background = Element.create({/* ... */});
const player = Element.create({/* ... */});
const foreground = Element.create({/* ... */});

// Add elements to the scene with different z-orders
gameScene.add(background, 0);    // Background (lowest z-order)
gameScene.add(player, 1);        // Player (middle z-order)
gameScene.add(foreground, 2);    // Foreground (highest z-order)

// Draw the scene through a camera
gameScene.draw(mainCam);

📥 Constructor

The Scene class constructor accepts the following parameters:

Parameter Type Default Description
None N/A N/A The Scene constructor takes no parameters. It initializes an empty scene with no elements.

📊 Properties

No public properties

Description: The Scene class does not expose public properties. All element management is done through methods.

⚙️ Methods

add(elem, zOrder)

Parameters:

  • elem: Element | Entity - The element or entity to add to the scene.
  • zOrder: number - The z-order (depth) at which to render this element. Lower values are rendered first (behind), higher values are rendered last (on top).

Description: Adds an element to the scene with a specified z-order. If the element is an instance of Element, it will be automatically added to the displayed elements list.

Returns: void

// Add elements with different z-orders
scene.add(background, 0);
scene.add(player, 1);
scene.add(foreground, 2);

remove(elem)

Parameters:

  • elem: Element | Entity - The element to remove from the scene.

Description: Removes an element from the scene. If the element is an instance of Element, it will be automatically removed from the displayed elements list.

Returns: void

// Remove an element from the scene
scene.remove(player);

zOrder(elem, zOrder)

Parameters:

  • elem: Element | Entity - The element whose z-order should be updated.
  • zOrder: number - The new z-order for the element.

Description: Updates the z-order of an element in the scene. The scene will automatically re-sort all elements after this change.

Returns: void

// Change the z-order of an element
scene.zOrder(player, 3); // Move player to the front

draw(cam)

Parameters:

  • cam: Camera - The camera through which to draw the scene.

Description: Draws all elements in the scene through the specified camera. Elements are automatically sorted by z-order before drawing.

Returns: void

// Draw the scene
scene.draw(mainCam);

🎯 Examples

Example 1: Creating a Layered Scene

Scene with background, player, and foreground elements. 

import { Scene } from "./classes/scene.js";
import { Element } from "./classes/element.js";
import { Camera } from "./classes/camera.js";

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#222"
});

// Create a scene
const gameScene = new Scene();

// Create elements for different layers
const background = Element.create({
    sprite: backgroundSprite,
    position: {x: 0, y: 0}
});

const player = Element.create({
    sprite: playerSprite,
    position: {x: 400, y: 300}
});

const foreground = Element.create({
    sprite: foregroundSprite,
    position: {x: 0, y: 0}
});

// Add elements with different z-orders
scene.add(background, 0);
scene.add(player, 1);
scene.add(foreground, 2);

// Game loop
function gameLoop() {
    mainCam.clear();
    
    // Draw the entire scene
    scene.draw(mainCam);
    
    requestAnimationFrame(gameLoop);
}
gameLoop();

Example 2: Dynamic Z-Order Management

// Create a scene with multiple entities
const scene = new Scene();
const player = Entity.create({/* ... */});
const enemy1 = Entity.create({/* ... */});
const enemy2 = Entity.create({/* ... */});

// Add entities with default z-orders
scene.add(player, 1);
scene.add(enemy1, 1);
scene.add(enemy2, 1);

// Later, bring an enemy to the front
scene.zOrder(enemy1, 2);

// Or move the player behind everything
scene.zOrder(player, 0);

// Remove an entity when it's defeated
scene.remove(enemy2);

Example 3: Multiple Scenes for Different Game States

// Create scenes for different game states
const mainMenuScene = new Scene();
const gameScene = new Scene();
const pauseScene = new Scene();
const gameOverScene = new Scene();

// Populate each scene with appropriate elements
// ...

// In the game loop, draw the appropriate scene
let currentScene = mainMenuScene;

function gameLoop() {
    mainCam.clear();
    
    // Draw the current scene
    currentScene.draw(mainCam);
    
    // Handle scene transitions
    if (gameStarted) {
        currentScene = gameScene;
    }
    if (gamePaused) {
        currentScene = pauseScene;
    }
    if (gameOver) {
        currentScene = gameOverScene;
    }
    
    requestAnimationFrame(gameLoop);
}

💡 Tips and Best Practices

  • 🎯 Use scenes for organization: Group related elements together (e.g., all UI elements in one scene, all background elements in another).
  • 🎯 Manage z-orders carefully: Lower z-order values are drawn first (appear behind), while higher values are drawn last (appear on top).
  • 🎯 Dynamic z-order updates: Use the zOrder() method to bring elements to the front or push them to the back as needed during gameplay.
  • 🎯 Scene transitions: For complex games, consider using multiple scenes for different game states (menu, gameplay, pause, game over).
  • 🎯 Performance consideration: Scenes automatically sort elements by z-order when needed, but avoid changing z-orders every frame for best performance.
  • 🎯 Element management: When you add an Element to a scene, it's automatically added to the global displayed elements list. When removed, it's automatically removed from that list.
