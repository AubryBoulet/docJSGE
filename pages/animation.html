Animation

Class for managing sprite and sprite sheet animations.

📌 Description

The Animation class allows you to manage sprite animations, particularly for sprite sheets. It provides functionality to define animation frames, control playback speed, and manage hitboxes for each frame.

Each animated sprite (animate: true) automatically has an instance of Animation associated with it, accessible via the animations property.

⚠️ Important: To use animations, your sprite must be marked as animated (animate: true) during loading.

🚀 Basic Usage

Create and Use an Animation

import { Sprite } from "../classes/sprites.js";

// Load an animated sprite
const playerSprite = await Sprite.load("./assets/player_sheet.png", true);

// Configure sprite sheet parameters
playerSprite.animations.column = 10;  // Number of columns
playerSprite.animations.row = 5;     // Number of rows
playerSprite.animations.frameRate = 10; // Animation speed

// Create an animation
playerSprite.animations.createAnimationFrames(
    0,    // Start frame
    4,    // End frame
    "idle", // Animation name
    10     // Frame rate (optional)
);

Play an Animation on an Entity

import { Entity } from "../classes/entity.js";

const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100}
});

// Set the current animation
player.currentAnimation = "idle";

// Animation will play automatically when update() is called
function gameLoop() {
    player.update();
    player.drawEntity(mainCam);
    requestAnimationFrame(gameLoop);
}

Type: number

Description: Height of a frame (calculated automatically).

⚙️ Methods

initSpritSheet()

Description: Initializes the frame dimensions of the sprite sheet. Called automatically during loading.

Returns: void

createAnimationFrames(startFrame, endFrame, animationName, frameRate, frameWidth, frameHeight)

Parameters:

  • startFrame: number - Number of the first frame.
  • endFrame: number - Number of the last frame.
  • animationName: string - Name of the animation.
  • frameRate: number - Speed of the animation (optional).
  • frameWidth: number - Width of the frames (optional).
  • frameHeight: number - Height of the frames (optional).

Description: Creates a new animation from a series of frames.

Returns: void

setAnimationFrameHitBox(animationName, startWidth, endWidth, startHeight, endHeight)

Parameters:

  • animationName: string - Name of the animation.
  • startWidth: number - Start X position of the hitbox.
  • endWidth: number - End X position of the hitbox.
  • startHeight: number - Start Y position of the hitbox.
  • endHeight: number - End Y position of the hitbox.

Description: Sets a hitbox for a specific animation.

Returns: void

🎯 Examples

Example 1: Simple Animation

Sprite sheet animation with 4 frames. 

import { Sprite } from "../classes/sprites.js";
import { Entity } from "../classes/entity.js";

// Load an animated sprite
const playerSprite = await Sprite.load("./assets/player_sheet.png", true);

// Configure the sprite sheet (4 columns, 1 row)
playerSprite.animations.column = 4;
playerSprite.animations.row = 1;
playerSprite.animations.frameRate = 10;

// Create an animation "walk" with frames 0 to 3
playerSprite.animations.createAnimationFrames(0, 3, "walk", 10);

// Create an entity with the sprite
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100}
});

// Set the current animation
player.currentAnimation = "walk";

function gameLoop() {
    player.update();
    player.drawEntity(mainCam);
    requestAnimationFrame(gameLoop);
}

Example 2: Multiple Animations

import { Sprite } from "../classes/sprites.js";

// Load a sprite sheet with multiple animations
const characterSprite = await Sprite.load("./assets/character_sheet.png", true);

// Configure the sprite sheet (10 columns, 5 rows)
characterSprite.animations.column = 10;
characterSprite.animations.row = 5;
characterSprite.animations.frameRate = 12;

// Create different animations
// Idle: frames 0-3
characterSprite.animations.createAnimationFrames(0, 3, "idle", 12);

// Walk: frames 10-17
characterSprite.animations.createAnimationFrames(10, 17, "walk", 12);

// Attack: frames 20-25
characterSprite.animations.createAnimationFrames(20, 25, "attack", 15);

// Jump: frames 30-35
characterSprite.animations.createAnimationFrames(30, 35, "jump", 10);

// Set hitboxes for each animation
characterSprite.animations.setAnimationFrameHitBox("idle", 15, 49, 10, 54);
characterSprite.animations.setAnimationFrameHitBox("walk", 15, 49, 10, 54);
characterSprite.animations.setAnimationFrameHitBox("attack", 10, 55, 5, 58);
characterSprite.animations.setAnimationFrameHitBox("jump", 12, 52, 8, 56);

// Use in an entity
const character = Entity.create({
    sprite: characterSprite,
    position: {x: 200, y: 200}
});

// Change animation based on state
function updateCharacter() {
    if (isWalking) {
        character.currentAnimation = "walk";
    } else if (isAttacking) {
        character.currentAnimation = "attack";
    } else if (isJumping) {
        character.currentAnimation = "jump";
    } else {
        character.currentAnimation = "idle";
    }
}

Example 3: Animation with Custom Frame Sizes

import { Sprite } from "../classes/sprites.js";

// Sprite sheet with different frame sizes
const customSprite = await Sprite.load("./assets/custom_sheet.png", true);

// Configure the sprite sheet
customSprite.animations.column = 20;
customSprite.animations.row = 10;

// Create an animation with custom frame dimensions
customSprite.animations.createAnimationFrames(
    0,      // Start frame
    5,      // End frame
    "custom", // Animation name
    8,      // Frame rate
    64,     // Frame width
    128     // Frame height
);

// Create an entity
const entity = Entity.create({
    sprite: customSprite,
    position: {x: 100, y: 100},
    scale: 2  // Scale up the sprite
});

entity.currentAnimation = "custom";

💡 Tips and Best Practices

  • 🔹 Organize your sprite sheets with frames of the same size for easier configuration.
  • 🔹 Use clear and descriptive animation names (e.g., "walk_right", "attack_1", "jump_start").
  • 🔹 Always define hitboxes for your animations if you use collision detection.
  • 🔹 For smooth animations, adjust the frameRate according to the desired speed.
  • 🔹 You can change animations at any time by modifying the entity's currentAnimation property.
  • 🔹 For special effects, create separate animations and switch between them based on game state.
