Animation

Classe pour gérer les animations de sprites et sprite sheets.

📌 Description

La classe Animation permet de gérer les animations de sprites, en particulier pour les sprite sheets. Elle offre des fonctionnalités pour définir des frames d'animation, contrôler la vitesse de lecture, et gérer les hitboxes pour chaque frame.

Chaque sprite animé (animate: true) a automatiquement une instance de Animation associée, accessible via la propriété animations.

⚠️ Important: Pour utiliser les animations, votre sprite doit être marqué comme animé (animate: true) lors de son chargement.

🚀 Utilisation de base

Créer et utiliser une animation

import { Sprite } from "../classes/sprites.js";

// Charger un sprite animé
const playerSprite = await Sprite.load("./assets/player_sheet.png", true);

// Configurer les paramètres du sprite sheet
playerSprite.animations.column = 10;  // Nombre de colonnes
playerSprite.animations.row = 5;     // Nombre de lignes
playerSprite.animations.frameRate = 10; // Vitesse de l'animation

// Créer une animation
playerSprite.animations.createAnimationFrames(
    0,    // Frame de début
    4,    // Frame de fin
    "idle", // Nom de l'animation
    10     // Frame rate (optionnel)
);

Lire une animation sur une entité

import { Entity } from "../classes/entity.js";

const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100}
});

// Définir l'animation actuelle
player.currentAnimation = "idle";

// L'animation se jouera automatiquement lors de l'appel à update()
function gameLoop() {
    player.update();
    player.drawEntity(mainCam);
    requestAnimationFrame(gameLoop);
}

🔧 Constructeur

La classe Animation est généralement instanciée automatiquement par la classe Sprite.

Paramètre Type Défaut Description
image HTMLImageElement - L'image source du sprite sheet.
row number 1 Nombre de lignes dans le sprite sheet.
column number 1 Nombre de colonnes dans le sprite sheet.
frameRate number 1 Vitesse de base des animations (frames par seconde).

📜 Propriétés

image

Type: HTMLImageElement

Description: L'image source du sprite sheet.

row

Type: number

Description: Nombre de lignes dans le sprite sheet.

column

Type: number

Description: Nombre de colonnes dans le sprite sheet.

frameRate

Type: number

Description: Vitesse de base des animations (frames par seconde).

frameWidth

Type: number

Description: Largeur d'un frame (calculée automatiquement).

frameHeight

Type: number

Description: Hauteur d'un frame (calculée automatiquement).

⚙️ Méthodes

initSpritSheet()

Description: Initialise les dimensions des frames du sprite sheet. Appelé automatiquement lors du chargement.

Retourne: void

createAnimationFrames(startFrame, endFrame, animationName, frameRate, frameWidth, frameHeight)

Paramètres:

  • startFrame: number - Numéro du premier frame.
  • endFrame: number - Numéro du dernier frame.
  • animationName: string - Nom de l'animation.
  • frameRate: number - Vitesse de l'animation (optionnel).
  • frameWidth: number - Largeur des frames (optionnel).
  • frameHeight: number - Hauteur des frames (optionnel).

Description: Crée une nouvelle animation à partir d'une série de frames.

Retourne: void

setAnimationFrameHitBox(animationName, startWidth, endWidth, startHeight, endHeight)

Paramètres:

  • animationName: string - Nom de l'animation.
  • startWidth: number - Position X de départ de la hitbox.
  • endWidth: number - Position X de fin de la hitbox.
  • startHeight: number - Position Y de départ de la hitbox.
  • endHeight: number - Position Y de fin de la hitbox.

Description: Définit une hitbox pour une animation spécifique.

Retourne: void

🎯 Exemples

Exemple 1: Animation simple

Animation d'un sprite sheet avec 4 frames. 

import { Sprite } from "../classes/sprites.js";
import { Entity } from "../classes/entity.js";

// Charger un sprite animé
const playerSprite = await Sprite.load("./assets/player_sheet.png", true);

// Configurer le sprite sheet (4 colonnes, 1 ligne)
playerSprite.animations.column = 4;
playerSprite.animations.row = 1;
playerSprite.animations.frameRate = 10;

// Créer une animation "walk" avec les frames 0 à 3
playerSprite.animations.createAnimationFrames(0, 3, "walk", 10);

// Créer une entité avec le sprite
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100}
});

// Définir l'animation actuelle
player.currentAnimation = "walk";

function gameLoop() {
    player.update();
    player.drawEntity(mainCam);
    requestAnimationFrame(gameLoop);
}

Exemple 2: Plusieurs animations

import { Sprite } from "../classes/sprites.js";

// Charger un sprite sheet avec plusieurs animations
const characterSprite = await Sprite.load("./assets/character_sheet.png", true);

// Configurer le sprite sheet (10 colonnes, 5 lignes)
characterSprite.animations.column = 10;
characterSprite.animations.row = 5;
characterSprite.animations.frameRate = 12;

// Créer différentes animations
// Idle: frames 0-3
characterSprite.animations.createAnimationFrames(0, 3, "idle", 12);

// Walk: frames 10-17
characterSprite.animations.createAnimationFrames(10, 17, "walk", 12);

// Attack: frames 20-25
characterSprite.animations.createAnimationFrames(20, 25, "attack", 15);

// Jump: frames 30-35
characterSprite.animations.createAnimationFrames(30, 35, "jump", 10);

// Définir les hitboxes pour chaque animation
characterSprite.animations.setAnimationFrameHitBox("idle", 15, 49, 10, 54);
characterSprite.animations.setAnimationFrameHitBox("walk", 15, 49, 10, 54);
characterSprite.animations.setAnimationFrameHitBox("attack", 10, 55, 5, 58);
characterSprite.animations.setAnimationFrameHitBox("jump", 12, 52, 8, 56);

// Utiliser dans une entité
const character = Entity.create({
    sprite: characterSprite,
    position: {x: 200, y: 200}
});

// Changer d'animation selon l'état
function updateCharacter() {
    if (isWalking) {
        character.currentAnimation = "walk";
    } else if (isAttacking) {
        character.currentAnimation = "attack";
    } else if (isJumping) {
        character.currentAnimation = "jump";
    } else {
        character.currentAnimation = "idle";
    }
}

Exemple 3: Animation avec frames personnalisés

import { Sprite } from "../classes/sprites.js";

// Sprite sheet avec des frames de tailles différentes
const customSprite = await Sprite.load("./assets/custom_sheet.png", true);

// Configurer le sprite sheet
customSprite.animations.column = 20;
customSprite.animations.row = 10;

// Créer une animation avec des dimensions de frame personnalisées
customSprite.animations.createAnimationFrames(
    0,      // Frame de début
    5,      // Frame de fin
    "custom", // Nom de l'animation
    8,      // Frame rate
    64,     // Largeur des frames
    128     // Hauteur des frames
);

// Créer une entité
const entity = Entity.create({
    sprite: customSprite,
    position: {x: 100, y: 100},
    scale: 2  // Agrandir le sprite
});

entity.currentAnimation = "custom";

💡 Conseils et bonnes pratiques

  • 🔹 Organisez vos sprite sheets avec des frames de même taille pour faciliter la configuration.
  • 🔹 Utilisez des noms d'animations clairs et descriptifs (ex: "walk_right", "attack_1", "jump_start").
  • 🔹 Définissez toujours les hitboxes pour vos animations si vous utilisez la détection de collisions.
  • 🔹 Pour des animations fluides, ajustez le frameRate en fonction de la vitesse souhaitée.
  • 🔹 Vous pouvez changer d'animation à tout moment en modifiant la propriété currentAnimation de l'entité.
  • 🔹 Pour des effets spéciaux, créez des animations séparées et basculez entre elles selon l'état du jeu.
