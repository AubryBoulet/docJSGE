JSGE Central Import

Import all JSGE classes from a single file for simplified usage.

📝 Description

The jsge.js file serves as a central import point for the JSGE engine. It re-exports all the main classes from their individual files, allowing you to import everything you need from a single location. This simplifies your import statements and makes your code cleaner and more maintainable.

This file is particularly useful when you're using multiple JSGE classes in your project and want to avoid long, repetitive import paths.

ℹ️ Note: This file uses ES6 module syntax. Make sure your HTML file uses type="module" when importing this file.

🚀 Basic Usage

Import individual classes from the central file:

// Import individual classes
import { Camera } from "./jsge.js";
import { Sprite } from "./jsge.js";
import { Entity } from "./jsge.js";
import { Scene } from "./jsge.js";
import { Button } from "./jsge.js";

Or import everything as a namespace:

// Import everything as JSGE namespace
import JSGE from "./jsge.js";

// Use classes through the namespace
const camera = new JSGE.Camera({/* ... */});
const sprite = await JSGE.Sprite.load("./assets/image.png");
const entity = JSGE.Entity.create({/* ... */});

🎯 Examples

Example 1: Complete Game Setup with Central Import

// myGame.js
import { Camera, Sprite, Entity, Scene, Button, Text } from "./jsge.js";

// HTML: <canvas id="gameCanvas" width="800" height="600"></canvas>

// Initialize
const canvas = document.querySelector("#gameCanvas");
const camera = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#222"
});

// Create a scene
const gameScene = new Scene();

// Load assets and create entities
const playerSprite = await Sprite.load("./assets/player.png", true);
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 400, y: 300},
    physic: true,
    gravity: 0.5
});

// Add to scene
gameScene.add(player, 1);

// Create UI
const scoreText = new Text("Score: 0", 200, 50);
const startButton = Button.create("Start Game", {width: 200, height: 50});

// Game loop
function gameLoop() {
    camera.clear();
    
    // Update and draw
    player.update();
    gameScene.draw(camera);
    
    // Draw UI
    scoreText.draw(camera, 2);
    startButton.draw(camera, 3);
    
    requestAnimationFrame(gameLoop);
}
gameLoop();

Example 2: Using the JSGE Namespace

// Import everything as a namespace
import JSGE from "./jsge.js";

// Use the namespace to access all classes
const camera = new JSGE.Camera({
    canvas: document.querySelector("#gameCanvas"),
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

const playerSprite = await JSGE.Sprite.load("./assets/player.png");
const player = JSGE.Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100}
});

const scene = new JSGE.Scene();
scene.add(player, 1);

// Draw
scene.draw(camera);

💡 Tips and Best Practices

  • 🎯 Use central import for simplicity: Importing from jsge.js reduces the number of import statements and makes your code more readable.
  • 🎯 Import only what you need: While you can import everything, it's good practice to only import the classes you actually use.
  • 🎯 Tree-shaking friendly: Modern bundlers can tree-shake unused imports, so importing from the central file won't increase your bundle size unnecessarily.
  • 🎯 Namespace for quick prototyping: The JSGE namespace is useful for quick prototyping or when you want to avoid import statements altogether.
  • 🎯 Module compatibility: Always use type="module" in your script tags when using ES6 imports.
  • 🎯 Path considerations: Make sure the path to jsge.js is correct relative to your HTML file or JavaScript module.
