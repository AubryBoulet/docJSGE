Gadget

Base class for creating interactive user interface elements.

📝 Description

The Gadget class is the base class for all user interface elements in JSGE. It provides common functionality such as mouse event handling, rendering, and basic properties. The Button and Text classes inherit from Gadget.

Gadget automatically manages mouse interactions (hover, click, etc.) and provides an optimized rendering system with a cache canvas for better performance.

New Features:

  • Enhanced mouse event handling with hitbox support
  • Improved box shadow styling with multiple shadows
  • Border radius support for rounded corners
  • Text value integration for display
  • Transition support for animations
  • Static gadget management for global mouse tracking

ℹ️ Important: Gadget is designed to be extended. You should not instantiate it directly, but rather use its subclasses like Button or create your own custom gadgets.

🚀 Basic Usage

Create a Custom Gadget

import { Gadget } from "./jsge.js";
import { Camera } from "./jsge.js";

// Create a subclass of Gadget
class CustomGadget extends Gadget {
    constructor({position, dimension, value}) {
        super({position, dimension, value});
        // Additional customization
        this.customProperty = "my value";
    }
    
    // Custom method
    customMethod() {
        console.log("Custom method called");
    }
}

// Use the custom gadget
const myGadget = new CustomGadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "My Gadget"
});

// Draw the gadget
myGadget.draw(mainCam);

Create a Simple Gadget Directly

import { Gadget } from "./jsge.js";

// Create a gadget with text
const panel = new Gadget({

// Customize appearance
panel.backgroundColor = "#3498db";
panel.color = "#fff";
panel.border = { lineWidth: 2, color: "#2980b9" };

// Draw the gadget
panel.draw(mainCam);

📥 Constructor

The Gadget class accepts the following parameters:

Parameter Type Default Description
options Object {} Configuration object for the gadget.
options.position {x: number, y: number} {x: 0, y: 0} Initial position of the gadget.
options.dimension {width: number, height: number} {width: 0, height: 0} Dimensions of the gadget.
options.value string "" Initial text value displayed in the gadget. If empty string, no text is created.

📊 Properties

position

Type: {x: number, y: number, offsetX: number, offsetY: number}

Description: Position of the gadget. Includes offset values for shadow/box effects.

dimension

Type: {width: number, height: number}

Description: Dimensions of the gadget.

value

Type: string

Description: Text value displayed in the gadget.

mouseOver

Type: boolean

Description: Whether the mouse is currently over the gadget.

active

Type: boolean

Description: Whether the gadget is currently active (mouse button down over it).

backgroundColor

Type: string

Description: Background color of the gadget.

color

Type: string

Description: Text color of the gadget.

border

Type: {lineWidth: number, color: string, style: string} | null

Description: Border styling for the gadget.

boxShadow

Type: Array | Object | null

Description: Box shadow styling. Can be a single object or array of shadow definitions.

borderRadius

Type: Array | null

Description: Border radius for rounded corners. Can be a single number or array [tl, tr, bl, br].

font

Type: string

Description: Font style for the text.

textAlign

Type: string

Description: Text alignment: 'start', 'end', 'left', 'right', or 'center'.

textBaseline

Type: string

Description: Text baseline: 'top', 'hanging', 'middle', 'alphabetic', 'ideographic', or 'bottom'.

textDirection

Type: string

Description: Text direction: 'ltr', 'rtl', or 'inherit'.

transitions

Type: Array

Description: Array of transition definitions for animations.

onMouseOver

Type: Function | null

Description: Callback called when mouse is over the gadget.

onMouseEnter

Type: Function | null

Description: Callback called when mouse enters the gadget.

onMouseLeave

Type: Function | null

Description: Callback called when mouse leaves the gadget.

onClick

Type: Function | null

Description: Callback called when the gadget is clicked.

mouseEvent (static)

Type: boolean

Description: Whether mouse events have been initialized for gadgets.

mousePosition (static)

Type: {x: number, y: number}

Description: Current mouse position relative to the document.

gadgets (static)

Type: Array<Gadget>

Description: Array of all registered gadgets for mouse event management.

shadowCanvas (static)

Type: HTMLCanvasElement

Description: Static canvas used for shadow rendering.

shadowCtx (static)

Type: CanvasRenderingContext2D

Description: Context for the shadow canvas.

⚙️ Methods

draw(cam, zOrder)

Parameters:

  • cam: Camera - The camera to draw through.
  • zOrder: number - The z-order for rendering (default: 0).

Description: Draws the gadget through the specified camera. The gadget is automatically checked for mouse interactions.

Returns: void

addTextGradient(name, gradient)

Parameters:

  • name: string - Name for the gradient.
  • gradient: CanvasGradient - Gradient object to apply to text.

Description: Adds a text gradient to the gadget's text value. Only works if the gadget has a text value.

Returns: void

updateText()

Description: Forces the text value to update its effects. Useful when changing properties that affect text rendering.

Returns: void

_processDraw(cam)

Parameters:

  • cam: Camera - The camera to draw through.

Description: Internal method called by the camera to process drawing. Handles clipping, positioning, and mouse interaction updates.

Returns: void

#setListeners()

Description: Private method that sets up mouse event listeners for all gadgets. Called automatically when the first gadget is created.

Returns: void

#update(displayedPosition, cam)

Description: Private method that updates mouse interaction state. Checks if mouse is over the gadget and triggers appropriate callbacks.

Returns: void

#updateCachCanvas()

Description: Private method that updates the cache canvas. Called when appearance properties change.

Returns: void

#drawCachCanvas()

Description: Private method that draws to the cache canvas. Handles background, border, shadows, and text rendering.

Returns: void

#isMouseOutOfCamera(cam)

Parameters:

  • cam: Camera - The camera to check against.

Description: Private method that checks if the mouse is outside the camera's view.

Returns: boolean - True if mouse is outside the camera.

🖱️ Mouse Event Handling

Gadget provides comprehensive mouse event handling:

Mouse Event Callbacks

import { Gadget } from "./jsge.js";

const button = new Gadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "Click Me"
});

// Set up mouse event callbacks
button.onMouseOver = (camera) => {
    console.log("Mouse is over the gadget!");
    button.backgroundColor = "#2980b9"; // Darker color on hover
};

button.onMouseEnter = (camera) => {
    console.log("Mouse entered the gadget!");
};

button.onMouseLeave = (camera) => {
    console.log("Mouse left the gadget!");
    button.backgroundColor = "#3498db"; // Restore original color
};

button.onClick = (camera) => {
    console.log("Gadget clicked!");
    // Handle click action
};

// The mouse events are automatically managed
button.draw(mainCam);

Hitbox Configuration

Gadgets have a configurable hitbox for mouse interaction detection:

const gadget = new Gadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50}
});

// The hitbox extends beyond the gadget's dimensions
// Default hitbox: {width: 8, height: 8}
// This means the hitbox extends 8px in all directions

// To create a gadget with a custom hitbox, you would need to extend Gadget
class CustomGadget extends Gadget {
    constructor(options) {
        super(options);
        this.#hitbox = {width: 15, height: 15}; // Larger hitbox
    }
}

Box Shadow

Gadgets support multiple box shadows:

// Single shadow
gadget.boxShadow = {
    offsetX: 5,
    offsetY: 5,
    color: "rgba(0, 0, 0, 0.5)",
    blur: 10,
    inset: false
};

// Multiple shadows (array)
gadget.boxShadow = [
    {
        offsetX: 3,
        offsetY: 3,
        color: "rgba(0, 0, 0, 0.3)",
        blur: 5,
        inset: false
    },
    {
        offsetX: -3,
        offsetY: -3,
        color: "rgba(255, 255, 255, 0.5)",
        blur: 5,
        inset: false
    }
];

// Array of arrays format
gadget.boxShadow = [
    [3, 3, "rgba(0,0,0,0.3)", 5, false],
    [-3, -3, "rgba(255,255,255,0.5)", 5, false]
];

Border Radius

Create rounded corners with border radius:

// Uniform border radius (all corners same)
gadget.borderRadius = [10];

// Different values for each corner [tl, tr, bl, br]
gadget.borderRadius = [10, 5, 10, 5];

// Or with null to use opposite corner
gadget.borderRadius = [10, 5, null, null]; // bl = tl, br = tr

Text Styling

// Set font
gadget.font = "bold 16px Arial";

// Set text alignment
gadget.textAlign = "center";

// Set text baseline
gadget.textBaseline = "middle";

// Set text direction
gadget.textDirection = "ltr";

// Add text gradient
gadget.addTextGradient("rainbow", gadget.shadowCtx.createLinearGradient(0, 0, 200, 0));
gadget.shadowCtx.gradient.addColorStop(0, "#e74c3c");
gadget.shadowCtx.gradient.addColorStop(1, "#f1c40f");

🎬 Transitions

Gadgets support CSS-like transitions for animations:

const gadget = new Gadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "Animated Gadget"
});

// Add a transition
gadget.transition = [
    "opacity",       // Property to transition (note: custom implementation needed)
    500,            // Duration in ms
    "ease-in-out",  // Timing function
    0               // Delay in ms
];

// Multiple transitions
gadget.transition = [
    ["opacity", 300, "ease", 0],
    ["backgroundColor", 500, "linear", 100]
];

🎯 Examples

Example 1: Interactive Panel

import { Gadget } from "./jsge.js";

const panel = new Gadget({
    position: {x: 50, y: 50},
    dimension: {width: 300, height: 200},
    value: "Info Panel"
});

// Style the panel
panel.backgroundColor = "#f8f9fa";
panel.color = "#2c3e50";
panel.border = { lineWidth: 2, color: "#dee2e6" };
panel.borderRadius = [5];
panel.boxShadow = [
    { offsetX: 2, offsetY: 2, color: "rgba(0,0,0,0.1)", blur: 5, inset: false }
];

// Add mouse interactions
panel.onMouseOver = (cam) => {
    panel.boxShadow = [
        { offsetX: 4, offsetY: 4, color: "rgba(0,0,0,0.2)", blur: 8, inset: false }
    ];
    panel._updateCachCanvas();
};

panel.onMouseLeave = (cam) => {
    panel.boxShadow = [
        { offsetX: 2, offsetY: 2, color: "rgba(0,0,0,0.1)", blur: 5, inset: false }
    ];
    panel._updateCachCanvas();
};

// Draw
panel.draw(mainCam);

Example 2: Custom Gadget with Image

import { Gadget } from "./jsge.js";

class ImageGadget extends Gadget {
    constructor({position, dimension, imagePath}) {
        super({position, dimension, value: ""});
        this.imagePath = imagePath;
        this.image = new Image();
        this.image.src = imagePath;
    }
    
    _drawCachCanvas() {
        const ctx = this._cachCanvas.getContext('2d');
        ctx.clearRect(0, 0, this._cachCanvas.width, this._cachCanvas.height);
        
        // Draw background
        if (this.#drawInfos.backgroundColor) {
            ctx.fillStyle = this.#drawInfos.backgroundColor;
            ctx.fillRect(0, 0, this.#cachCanvas.width, this.#cachCanvas.height);
        }
        
        // Draw image
        if (this.image.complete) {
            ctx.drawImage(
                this.image,
                0, 0,
                this.#cachCanvas.width, this.#cachCanvas.height
            );
        }
        
        // Draw border
        if (this.#drawInfos.border) {
            ctx.strokeStyle = this.#drawInfos.border.color;
            ctx.lineWidth = this.#drawInfos.border.lineWidth;
            ctx.strokeRect(0, 0, this.#cachCanvas.width, this.#cachCanvas.height);
        }
    }
}

const imageGadget = new ImageGadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 200},
    imagePath: "./assets/my-image.png"
});

imageGadget.onClick = (cam) => {
    console.log("Image gadget clicked!");
};

imageGadget.draw(mainCam);

Example 3: Tooltip Gadget

import { Gadget } from "./jsge.js";

class Tooltip extends Gadget {
    constructor({position, text}) {
        super({
            position: position,
            dimension: {width: 200, height: 60},
            value: text
        });
        
        this.backgroundColor = "#333";
        this.color = "#fff";
        this.borderRadius = [5];
        this.font = "14px Arial";
    }
}

const tooltip = new Tooltip({
    position: {x: 100, y: 100},
    text: "This is a tooltip!"
});

// Show/hide based on mouse
let isVisible = false;

tooltip.onMouseEnter = () => {
    isVisible = true;
};

tooltip.onMouseLeave = () => {
    isVisible = false;
};

function gameLoop() {
    mainCam.clear();
    
    if (isVisible) {
        tooltip.draw(mainCam);
    }
    
    requestAnimationFrame(gameLoop);
}

💡 Tips and Best Practices

  • 🎯 Extend Gadget for custom UI: Create subclasses of Gadget for custom UI elements like panels, tooltips, sliders, etc.
  • 🎯 Use Button for standard buttons: The Button class extends Gadget and provides additional button-specific features.
  • 🎯 Optimize with cache canvas: Gadgets use a cache canvas for rendering, which improves performance. Only update the cache when necessary.
  • 🎯 Mouse events are automatic: Once a gadget is created, mouse events are automatically tracked. No need to manually add event listeners.
  • 🎯 Use hitbox for better UX: The hitbox extends beyond the gadget's dimensions, making it easier for users to interact with small elements.
  • 🎯 Style with shadows and borders: Use boxShadow and border properties to create visually appealing UI elements.
  • 🎯 Consider z-order: When drawing multiple gadgets, use the zOrder parameter to ensure proper layering.
  • 🎯 Update cache when styling changes: After changing appearance properties, call _updateCachCanvas() to update the visual representation.
