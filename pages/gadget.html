Gadget

Base class for creating interactive user interface elements.

📌 Description

The Gadget class is the base class for all user interface elements in JSGE. It provides common functionality such as mouse event handling, rendering, and basic properties. The Button and Text classes inherit from Gadget.

Gadget automatically manages mouse interactions (hover, click, etc.) and provides an optimized rendering system with a cache canvas for better performance.

⚠️ Important: Gadget is designed to be extended. You should not instantiate it directly, but rather use its subclasses like Button.

🚀 Basic Usage

Create a Custom Gadget

import { Gadget } from "../classes/gadget.js";
import { Camera } from "../classes/camera.js";

// Create a subclass of Gadget
class CustomGadget extends Gadget {
    constructor({position, dimension, value}) {
        super({position, dimension, value});
        // Additional customization
        this.customProperty = "my value";
    }
    
    // Custom method
    customMethod() {
        console.log("Custom method called");
    }
}

// Use the custom gadget
const myGadget = new CustomGadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "My Gadget"
});

// Draw the gadget
myGadget.draw(mainCam);

Use Mouse Events

import { Gadget } from "../classes/gadget.js";

// Create a gadget with event handlers
const myGadget = new Gadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "Interactive"
});

// Set event handlers
myGadget.onMouseEnter = () => {
    console.log("Mouse entered gadget");
};

myGadget.onMouseLeave = () => {
    console.log("Mouse left gadget");
};

myGadget.onClick = () => {
    console.log("Gadget clicked!");
};

// These handlers will be called automatically
// during mouse interactions

🔧 Constructor

The Gadget class accepts the following parameters:

Parameter Type Default Description
position {x: number, y: number} {x: 0, y: 0} Position of the gadget in the scene.
dimension {width: number, height: number} {width: 0, height: 0} Dimensions of the gadget.
value string "" Text value of the gadget (can contain special effect tags).

📜 Properties

position

Type: {x: number, y: number, offsetX: number, offsetY: number}

Description: Position of the gadget with optional offsets.

dimension

Type: {width: number, height: number}

Description: Dimensions of the gadget.

value

Type: string

Description: Text value of the gadget.

onMouseEnter

Type: function

Description: Function called when the mouse enters the gadget.

onMouseLeave

Type: function

Description: Function called when the mouse leaves the gadget.

onClick

Type: function

Description: Function called when the gadget is clicked.

backgroundColor

Type: string

Description: Background color of the gadget.

color

Type: string

Description: Text color of the gadget.

font

Type: string

Description: Font of the gadget text.

⚙️ Methods

draw(camera)

Parameters:

  • camera: Camera - The camera to draw the gadget in.

Description: Draws the gadget in the specified camera. Uses a cache canvas for better performance.

Returns: void

addTextGradient(name, gradient)

Parameters:

  • name: string - Name of the gradient.
  • gradient: CanvasGradient - The gradient object to add.

Description: Adds a gradient for the gadget text.

Returns: void

updateText()

Description: Forces the gadget text to update. Useful when you add or modify gradients after gadget creation.

Returns: void

🎯 Examples

Example 1: Create a Custom Gadget with Effects

import { Gadget } from "../classes/gadget.js";
import { Camera } from "../classes/camera.js";

// Create a gadget with text containing effects
const myGadget = new Gadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "${wave(2,5,5)} Text ${blink(0,20)} blinking"
});

// Customize appearance
myGadget.backgroundColor = "#3498db";
myGadget.color = "#fff";
myGadget.font = "16px Arial";

// Add a gradient
const gradient = myGadget._cachCanvas.getContext('2d').createLinearGradient(0, 0, 200, 0);
gradient.addColorStop(0, "#f1c40f");
gradient.addColorStop(1, "#e74c3c");
myGadget.addTextGradient("myGradient", gradient);
myGadget.updateText();

// Set events
myGadget.onMouseEnter = () => {
    myGadget.backgroundColor = "#2980b9";
};

myGadget.onMouseLeave = () => {
    myGadget.backgroundColor = "#3498db";
};

myGadget.onClick = () => {
    console.log("Gadget clicked!");
};

// Draw the gadget
function gameLoop() {
    mainCam.clear();
    myGadget.draw(mainCam);
    requestAnimationFrame(gameLoop);
}
gameLoop();

Example 2: Gadget with Border and Shadow

import { Gadget } from "../classes/gadget.js";

// Create a gadget
const styledGadget = new Gadget({
    position: {x: 150, y: 150},
    dimension: {width: 250, height: 60},
    value: "Styled Gadget"
});

// Customize style
styledGadget.backgroundColor = "#2c3e50";
styledGadget.color = "#ecf0f1";
styledGadget.font = "bold 18px Arial";

// Add a border (via _drawInfos)
styledGadget._drawInfos.border = {
    color: "#3498db",
    width: 2
};

// Add a shadow (via _drawInfos)
styledGadget._drawInfos.boxShadow = [
    [0, 0, "#000", 10, 0, 5]  // [x, y, color, blur, spread, opacity]
];

// Add border radius
styledGadget._drawInfos.borderRadius = [10, 10, 10, 10]; // [top-left, top-right, bottom-right, bottom-left]

// Draw the gadget
styledGadget.draw(mainCam);

Example 3: Global Mouse Event Management

import { Gadget } from "../classes/gadget.js";

// Gadget automatically manages global mouse events
// You can access mouse position via:
console.log("Mouse position:", Gadget.mousePosition);

// And event state via:
console.log("Mouse event active:", Gadget.mouseEvent);

// Create multiple gadgets
const gadgets = [];
for (let i = 0; i < 5; i++) {
    const gadget = new Gadget({
        position: {x: 100 + i * 120, y: 100},
        dimension: {width: 100, height: 50},
        value: `Gadget ${i + 1}`
    });
    
    gadget.onClick = () => {
        console.log(`Gadget ${i + 1} clicked!`);
    };
    
    gadgets.push(gadget);
}

// All gadgets will receive mouse events
// and call their respective handlers

💡 Tips and Best Practices

  • 🔹 Extend Gadget to create your own widget types (buttons, checkboxes, etc.).
  • 🔹 Use effect tags in the value property to create animated text (e.g., ${wave(...)}, ${blink(...)}).
  • 🔹 Call updateText() after modifying gradients or text effects.
  • 🔹 Use addTextGradient() to create text with color gradients.
  • 🔹 Customize appearance via _drawInfos properties for borders, shadows, and radii.
  • 🔹 Gadget automatically manages mouse events for all created gadgets.
