Gadget

Base class for creating interactive user interface elements.

📝 Description

The Gadget class is the base class for all user interface elements in JSGE. It provides common functionality such as mouse event handling, rendering, and basic properties. The Button and Text classes inherit from Gadget.

Gadget automatically manages mouse interactions (hover, click, etc.) and provides an optimized rendering system with a cache canvas for better performance.

New Features:

  • Enhanced mouse event handling with hitbox support
  • Improved box shadow styling with multiple shadows
  • Border radius support for rounded corners
  • Text value integration for display
  • Transition support for animations
  • Static gadget management for global mouse tracking

ℹ️ Important: Gadget is designed to be extended. You should not instantiate it directly, but rather use its subclasses like Button or create your own custom gadgets. Gadgets MUST be added to a Scene for rendering.

🚀 Basic Usage

Create a Custom Gadget

import { Gadget, Scene } from "./jsge.js";
import { Camera } from "./jsge.js";

// Create a subclass of Gadget
class CustomGadget extends Gadget {
    constructor({position, dimension, value}) {
        super({position, dimension, value});
        // Additional customization
        this.customProperty = "my value";
    }
    
    // Custom method
    customMethod() {
        console.log("Custom method called");
    }
}

// Create a scene - MANDATORY
const gameScene = new Scene();

// Use the custom gadget
const myGadget = new CustomGadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "My Gadget"
});

// Add to scene
gameScene.add(myGadget, 1);

// Draw the gadget through scene
function gameLoop() {
    mainCam.clear();
    gameScene.draw(mainCam);
    mainCam.flipBuffer(); // MUST be called
    requestAnimationFrame(gameLoop);
}

Create a Simple Gadget Directly

import { Gadget, Scene } from "./jsge.js";

// Create a gadget with text
const panel = new Gadget({
    position: {x: 50, y: 50},
    dimension: {width: 300, height: 200},
    value: "Hello, JSGE!"
});

// Create scene
const gameScene = new Scene();
gameScene.add(panel, 1);

// Customize appearance
panel.backgroundColor = "#3498db";
panel.color = "#fff";
panel.border = { lineWidth: 2, color: "#2980b9" };

// Draw through scene
function gameLoop() {
    mainCam.clear();
    gameScene.draw(mainCam);
    mainCam.flipBuffer();
    requestAnimationFrame(gameLoop);
}

📥 Constructor

The Gadget class accepts the following parameters:

Parameter Type Default Description
options Object {} Configuration object for the gadget.
options.position {x: number, y: number} {x: 0, y: 0} Initial position of the gadget.
options.dimension {width: number, height: number} {width: 0, height: 0} Dimensions of the gadget.
options.value string "" Initial text value displayed in the gadget. If empty string, no text is created.

📊 Properties

position

Type: {x: number, y: number, offsetX: number, offsetY: number}

Description: Position of the gadget. Includes offset values for shadow/box effects.

dimension

Type: {width: number, height: number}

Description: Dimensions of the gadget.

value

Type: string

Description: Text value displayed in the gadget.

mouseOver

Type: boolean

Description: Whether the mouse is currently over the gadget.

active

Type: boolean

Description: Whether the gadget is currently active (mouse button down over it).

backgroundColor

Type: string

Description: Background color of the gadget.

color

Type: string

Description: Text color of the gadget.

border

Type: {lineWidth: number, color: string, style: string} | null

Description: Border styling for the gadget.

boxShadow

Type: Array | Object | null

Description: Box shadow styling. Can be a single object or array of shadow definitions.

borderRadius

Type: Array | null

Description: Border radius for rounded corners. Can be a single number or array [tl, tr, bl, br].

font

Type: string

Description: Font style for the text.

textAlign

Type: string

Description: Text alignment: 'start', 'end', 'left', 'right', or 'center'.

textBaseline

Type: string

Description: Text baseline: 'top', 'hanging', 'middle', 'alphabetic', 'ideographic', or 'bottom'.

textDirection

Type: string

Description: Text direction: 'ltr', 'rtl', or 'inherit'.

onMouseOver

Type: Function | null

Description: Callback called when mouse is over the gadget.

onMouseEnter

Type: Function | null

Description: Callback called when mouse enters the gadget.

onMouseLeave

Type: Function | null

Description: Callback called when mouse leaves the gadget.

onClick

Type: Function | null

Description: Callback called when the gadget is clicked.

⚙️ Methods

⚠️ IMPORTANT: Gadgets do NOT have public drawing methods. All rendering MUST be done through a Scene. The methods below are for internal use or advanced scenarios only.

draw(cam, zOrder)

Parameters:

  • cam: Camera - The camera to draw through.
  • zOrder: number - The z-order for rendering (default: 0).

Description: ⚠️ NOT RECOMMENDED: While this method exists, you should NOT use it directly. Always use scene.draw(camera) instead for proper rendering with z-order sorting.

Returns: void

addTextGradient(name, gradient)

Parameters:

  • name: string - Name for the gradient.
  • gradient: CanvasGradient - Gradient object to apply to text.

Description: Adds a text gradient to the gadget's text value. Only works if the gadget has a text value.

Returns: void

updateText()

Description: Forces the text value to update its effects. Useful when changing properties that affect text rendering.

Returns: void

_processDraw(cam)

Parameters:

  • cam: Camera - The camera to draw through.

Description: ⚠️ PRIVATE METHOD: Internal method called by the camera to process drawing. Handles clipping, positioning, and mouse interaction updates. Not intended for direct use. Incorrect usage can cause engine crashes.

Returns: void

#setListeners()

Description: ⚠️ PRIVATE METHOD: Private method that sets up mouse event listeners for all gadgets. Called automatically when the first gadget is created. Not intended for direct use.

Returns: void

#update(displayedPosition, cam)

Description: ⚠️ PRIVATE METHOD: Private method that updates mouse interaction state. Checks if mouse is over the gadget and triggers appropriate callbacks. Not intended for direct use.

Returns: void

#updateCachCanvas()

Description: ⚠️ PRIVATE METHOD: Private method that updates the cache canvas. Called when appearance properties change. Not intended for direct use.

Returns: void

#drawCachCanvas()

Description: ⚠️ PRIVATE METHOD: Private method that draws to the cache canvas. Handles background, border, shadows, and text rendering. Not intended for direct use.

Returns: void

#isMouseOutOfCamera(cam)

Parameters:

  • cam: Camera - The camera to check against.

Description: ⚠️ PRIVATE METHOD: Private method that checks if the mouse is outside the camera's view. Not intended for direct use.

Returns: boolean - True if mouse is outside the camera.

🖱️ Mouse Event Handling

Gadget provides comprehensive mouse event handling:

Mouse Event Callbacks

import { Gadget, Scene } from "./jsge.js";

// Create scene
const gameScene = new Scene();

const button = new Gadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "Click Me"
});

// Add to scene
gameScene.add(button, 1);

// Set up mouse event callbacks
button.onMouseOver = (camera) => {
    console.log("Mouse is over the gadget!");
    button.backgroundColor = "#2980b9"; // Darker color on hover
};

button.onMouseEnter = (camera) => {
    console.log("Mouse entered the gadget!");
};

button.onMouseLeave = (camera) => {
    console.log("Mouse left the gadget!");
    button.backgroundColor = "#3498db"; // Restore original color
};

button.onClick = (camera) => {
    console.log("Gadget clicked!");
    // Handle click action
};

// The mouse events are automatically managed
function gameLoop() {
    mainCam.clear();
    gameScene.draw(mainCam);
    mainCam.flipBuffer();
    requestAnimationFrame(gameLoop);
}

Hitbox Configuration

Gadgets have a configurable hitbox for mouse interaction detection:

// Gadgets have a default hitbox that extends beyond their dimensions
// This makes it easier for users to interact with small elements
// The default hitbox is {width: 8, height: 8}, extending 8px in all directions

// To create a gadget with a custom hitbox, you would need to extend Gadget
class CustomGadget extends Gadget {
    constructor(options) {
        super(options);
        // Note: hitbox is a private property, modifying it requires caution
    }
}

// Then add to scene and use normally
const gadget = new CustomGadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50}
});

const gameScene = new Scene();
gameScene.add(gadget, 1);

🎨 Styling

Gadgets support extensive styling options:

Border Styling

const gadget = new Gadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "Styled Gadget"
});

// Set border
gadget.border = {
    lineWidth: 3,
    color: "#e74c3c",
    style: "solid"
};

// Set background color
gadget.backgroundColor = "#3498db";

// Set text color
gadget.color = "#fff";

Box Shadow

Gadgets support multiple box shadows:

// Single shadow
gadget.boxShadow = {
    offsetX: 5,
    offsetY: 5,
    color: "rgba(0, 0, 0, 0.5)",
    blur: 10,
    inset: false
};

// Multiple shadows (array)
gadget.boxShadow = [
    {
        offsetX: 3,
        offsetY: 3,
        color: "rgba(0, 0, 0, 0.3)",
        blur: 5,
        inset: false
    },
    {
        offsetX: -3,
        offsetY: -3,
        color: "rgba(255, 255, 255, 0.5)",
        blur: 5,
        inset: false
    }
];

// Array of arrays format
gadget.boxShadow = [
    [3, 3, "rgba(0,0,0,0.3)", 5, false],
    [-3, -3, "rgba(255,255,255,0.5)", 5, false]
];

Border Radius

Create rounded corners with border radius:

// Uniform border radius (all corners same)
gadget.borderRadius = [10];

// Different values for each corner [tl, tr, bl, br]
gadget.borderRadius = [10, 5, 10, 5];

// Or with null to use opposite corner
gadget.borderRadius = [10, 5, null, null]; // bl = tl, br = tr

Text Styling

// Set font
gadget.font = "bold 16px Arial";

// Set text alignment
gadget.textAlign = "center";

// Set text baseline
gadget.textBaseline = "middle";

// Set text direction
gadget.textDirection = "ltr";

// Add text gradient (requires canvas context)
const gradient = gadget._cachCanvas.getContext('2d').createLinearGradient(0, 0, 200, 0);
gradient.addColorStop(0, "#e74c3c");
gradient.addColorStop(1, "#f1c40f");
gadget.addTextGradient("rainbow", gradient);

💡 Tips and Best Practices

  • 🎯 Extend Gadget for custom UI: Create subclasses of Gadget for custom UI elements like panels, tooltips, sliders, etc.
  • 🎯 Use Button for standard buttons: The Button class extends Gadget and provides additional button-specific features.
  • 🎯 ALWAYS use Scene for rendering: Gadgets MUST be added to a Scene. Direct drawing is not supported.
  • 🎯 Optimize with cache canvas: Gadgets use a cache canvas for rendering, which improves performance. Only update the cache when necessary.
  • 🎯 Mouse events are automatic: Once a gadget is created and added to a scene, mouse events are automatically tracked. No need to manually add event listeners.
  • 🎯 Use hitbox for better UX: The hitbox extends beyond the gadget's dimensions, making it easier for users to interact with small elements.
  • 🎯 Style with shadows and borders: Use boxShadow and border properties to create visually appealing UI elements.
  • 🎯 Consider z-order: When drawing multiple gadgets, use the zOrder parameter to ensure proper layering.
  • ⚠️ Avoid using _ and # methods: Methods starting with underscore or hash are private and not intended for direct use. Incorrect usage can cause engine crashes.
