Gadget

Classe de base pour créer des éléments d'interface utilisateur interactifs.

📌 Description

La classe Gadget est la classe de base pour tous les éléments d'interface utilisateur dans JSGE. Elle fournit des fonctionnalités communes comme la gestion des événements souris, le rendu, et les propriétés de base. Les classes Button et Text héritent de Gadget.

Gadget gère automatiquement les interactions avec la souris (survol, clic, etc.) et fournit un système de rendu optimisé avec un cache canvas pour de meilleures performances.

⚠️ Important: Gadget est conçu pour être étendu. Vous ne devriez pas l'instancier directement, mais plutôt utiliser ses sous-classes comme Button.

🚀 Utilisation de base

Créer un gadget personnalisé

import { Gadget } from "../classes/gadget.js";
import { Camera } from "../classes/camera.js";

// Créer une sous-classe de Gadget
class CustomGadget extends Gadget {
    constructor({position, dimension, value}) {
        super({position, dimension, value});
        // Personnalisation supplémentaire
        this.customProperty = "ma valeur";
    }
    
    // Méthode personnalisée
    customMethod() {
        console.log("Méthode personnalisée appelée");
    }
}

// Utiliser le gadget personnalisé
const myGadget = new CustomGadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "Mon Gadget"
});

// Dessiner le gadget
myGadget.draw(mainCam);

Utiliser les événements souris

import { Gadget } from "../classes/gadget.js";

// Créer un gadget avec des gestionnaires d'événements
const myGadget = new Gadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "Interactif"
});

// Définir les gestionnaires d'événements
myGadget.onMouseEnter = () => {
    console.log("Souris entrée dans le gadget");
};

myGadget.onMouseLeave = () => {
    console.log("Souris sortie du gadget");
};

myGadget.onClick = () => {
    console.log("Gadget cliqué !");
};

// Ces gestionnaires seront appelés automatiquement
// lors des interactions avec la souris

🔧 Constructeur

La classe Gadget accepte les paramètres suivants :

Paramètre Type Défaut Description
position {x: number, y: number} {x: 0, y: 0} Position du gadget dans la scène.
dimension {width: number, height: number} {width: 0, height: 0} Dimensions du gadget.
value string "" Valeur textuelle du gadget (peut contenir des tags d'effets spéciaux).

📜 Propriétés

position

Type: {x: number, y: number, offsetX: number, offsetY: number}

Description: Position du gadget avec décalages optionnels.

dimension

Type: {width: number, height: number}

Description: Dimensions du gadget.

value

Type: string

Description: Valeur textuelle du gadget.

onMouseEnter

Type: function

Description: Fonction appelée lorsque la souris entre dans le gadget.

onMouseLeave

Type: function

Description: Fonction appelée lorsque la souris sort du gadget.

onClick

Type: function

Description: Fonction appelée lorsque le gadget est cliqué.

backgroundColor

Type: string

Description: Couleur d'arrière-plan du gadget.

color

Type: string

Description: Couleur du texte du gadget.

font

Type: string

Description: Police du texte du gadget.

⚙️ Méthodes

draw(camera)

Paramètres:

  • camera: Camera - La caméra dans laquelle dessiner le gadget.

Description: Dessine le gadget dans la caméra spécifiée. Utilise un cache canvas pour de meilleures performances.

Retourne: void

addTextGradient(name, gradient)

Paramètres:

  • name: string - Nom du dégradé.
  • gradient: CanvasGradient - L'objet dégradé à ajouter.

Description: Ajoute un dégradé pour le texte du gadget.

Retourne: void

updateText()

Description: Force la mise à jour du texte du gadget. Utile lorsque vous ajoutez ou modifiez des dégradés après la création du gadget.

Retourne: void

🎯 Exemples

Exemple 1: Créer un gadget personnalisé avec effets

import { Gadget } from "../classes/gadget.js";
import { Camera } from "../classes/camera.js";

// Créer un gadget avec du texte contenant des effets
const myGadget = new Gadget({
    position: {x: 100, y: 100},
    dimension: {width: 200, height: 50},
    value: "${wave(2,5,5)} Texte ${blink(0,20)} clignotant"
});

// Personnaliser l'apparence
myGadget.backgroundColor = "#3498db";
myGadget.color = "#fff";
myGadget.font = "16px Arial";

// Ajouter un dégradé
const gradient = myGadget._cachCanvas.getContext('2d').createLinearGradient(0, 0, 200, 0);
gradient.addColorStop(0, "#f1c40f");
gradient.addColorStop(1, "#e74c3c");
myGadget.addTextGradient("myGradient", gradient);
myGadget.updateText();

// Définir les événements
myGadget.onMouseEnter = () => {
    myGadget.backgroundColor = "#2980b9";
};

myGadget.onMouseLeave = () => {
    myGadget.backgroundColor = "#3498db";
};

myGadget.onClick = () => {
    console.log("Gadget cliqué !");
};

// Dessiner le gadget
function gameLoop() {
    mainCam.clear();
    myGadget.draw(mainCam);
    requestAnimationFrame(gameLoop);
}
gameLoop();

Exemple 2: Gadget avec bordure et ombre

import { Gadget } from "../classes/gadget.js";

// Créer un gadget
const styledGadget = new Gadget({
    position: {x: 150, y: 150},
    dimension: {width: 250, height: 60},
    value: "Gadget stylisé"
});

// Personnaliser le style
styledGadget.backgroundColor = "#2c3e50";
styledGadget.color = "#ecf0f1";
styledGadget.font = "bold 18px Arial";

// Ajouter une bordure (via drawInfos)
styledGadget._drawInfos.border = {
    color: "#3498db",
    width: 2
};

// Ajouter une ombre (via drawInfos)
styledGadget._drawInfos.boxShadow = [
    [0, 0, "#000", 10, 0, 5]  // [x, y, couleur, flou, étalement, opacity]
];

// Ajouter un rayon de bordure
styledGadget._drawInfos.borderRadius = [10, 10, 10, 10]; // [top-left, top-right, bottom-right, bottom-left]

// Dessiner le gadget
styledGadget.draw(mainCam);

Exemple 3: Gestion des événements souris globaux

import { Gadget } from "../classes/gadget.js";

// Gadget gère automatiquement les événements souris globaux
// Vous pouvez accéder à la position de la souris via :
console.log("Position souris:", Gadget.mousePosition);

// Et à l'état des événements via :
console.log("Événement souris actif:", Gadget.mouseEvent);

// Créer plusieurs gadgets
const gadgets = [];
for (let i = 0; i < 5; i++) {
    const gadget = new Gadget({
        position: {x: 100 + i * 120, y: 100},
        dimension: {width: 100, height: 50},
        value: `Gadget ${i + 1}`
    });
    
    gadget.onClick = () => {
        console.log(`Gadget ${i + 1} cliqué !`);
    };
    
    gadgets.push(gadget);
}

// Tous les gadgets recevront les événements souris
// et appelleront leurs gestionnaires respectifs

💡 Conseils et bonnes pratiques

  • 🔹 Étendez Gadget pour créer vos propres types de widgets (boutons, cases à cocher, etc.).
  • 🔹 Utilisez les tags d'effets dans la propriété value pour créer des textes animés (ex: ${wave(...)}, ${blink(...)}).
  • 🔹 Appelez updateText() après avoir modifié les dégradés ou les effets de texte.
  • 🔹 Utilisez addTextGradient() pour créer des textes avec des dégradés de couleur.
  • 🔹 Personnalisez l'apparence via les propriétés _drawInfos pour les bordures, ombres, et rayons.
  • 🔹 Gadget gère automatiquement les événements souris pour tous les gadgets créés.
