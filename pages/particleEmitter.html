ParticleEmitter

Class for creating and managing particle systems for visual effects like explosions, fire, smoke, and more.

📝 Description

The ParticleEmitter class allows you to create complex particle systems for visual effects. Particles are automatically managed, emitted, updated, and drawn based on the emitter's configuration.

ParticleEmitter works with the Camera class to render particles. Particles are automatically removed when they go out of the camera view to optimize performance.

⚠️ Important: Particles are removed if they exit the camera boundaries. The particleColorChangeRate property is applied to the ParticleEmitter, affecting all particles emitted from it. The color parameter accepts HEX format (#RRGGBB) or RGB format (rgb(r, g, b)).

🚀 Basic Usage

Create a Simple Particle Emitter

import { ParticleEmitter } from "../classes/particleEmitter.js";
import { Camera } from "../classes/camera.js";

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const camera = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

// Create a particle emitter
const emitter = new ParticleEmitter(400, 300);

// Configure the emitter
emitter.particleEmissionSpeed = {min: 2, max: 5};
emitter.particleSize = {width: 4, height: 4};
emitter.particleColorRange = {startColor: "#ff0000", endColor: "#ffff00"};
emitter.emissionRate = 30;

// Start emission
emitter.startEmission(() => {
    console.log("Emission complete!");
});

// In your game loop
function gameLoop() {
    camera.clear();
    
    // Draw the emitter (which will draw all particles)
    emitter.draw(camera);
    
    camera.flipBuffer();
    requestAnimationFrame(gameLoop);
}
gameLoop();

Create a Fire Effect

import { ParticleEmitter } from "../classes/particleEmitter.js";

// Create fire emitter
const fireEmitter = new ParticleEmitter(400, 500);

// Configure for fire effect
fireEmitter.particleEmissionSpeed = {min: 1, max: 3};
fireEmitter.particleSize = {width: 6, height: 6};
fireEmitter.particleColorRange = {startColor: "#ff4400", endColor: "#ffff00"};
fireEmitter.particleColorChangeRate = {r: -1, g: 0, b: 0}; // Fade to red
fireEmitter.particleLifetime = {min: 500, max: 1500};
fireEmitter.particleAcceleration = {x: 0, y: -0.1}; // Particles go up
fireEmitter.emissionRate = 20;
fireEmitter.particleEmitterAngleRange = {rangeMin: 80, rangeMax: 100};
fireEmitter.particleEmitterDirection = {x: 0, y: -1};

// Start continuous emission
fireEmitter.startEmission();

// To stop later: fireEmitter.stopEmission();

📦 Constructor

The ParticleEmitter class accepts the following parameters:

Parameter Type Default Description
x number - X coordinate of the emitter position.
y number - Y coordinate of the emitter position.

📊 Properties

All properties have getter and setter methods.

x

Type: number

Description: X coordinate of the emitter.

y

Type: number

Description: Y coordinate of the emitter.

particleAcceleration

Type: object

Default: {x: 0, y: 0}

Description: Acceleration applied to all particles (in pixels per frame squared).

particleEmissionSpeed

Type: object

Default: {min: 1, max: 3}

Description: Speed range for emitted particles. Each particle gets a random speed from this range.

particleSize

Type: object

Default: {width: 1, height: 1}

Description: Size of each particle in pixels.

particleColorRange

Type: object

Default: {startColor: "#ffffff", endColor: "#000000"}

Description: Color range for particles. Each particle gets a random color from this range. Accepts HEX or RGB format.

particleColorChangeRate

Type: object

Default: {r: 0, g: 0, b: 0}

Description: Rate at which particle colors change over time (per frame). Applied to all particles from this emitter. Use negative values to fade out.

particleLifetime

Type: object

Default: {min: 1000, max: 2000}

Description: Lifetime range for particles in milliseconds. Each particle gets a random lifetime from this range.

emissionRate

Type: number

Default: 10

Description: Number of particles emitted per second.

particlesPerEmission

Type: number

Default: 1

Description: Number of particles emitted per emission tick.

emissionDuration

Type: number

Default: 1000

Description: Duration of the emission in milliseconds. Set to 0 for continuous emission.

particleEmitterAngleRange

Type: object

Default: {rangeMin: 45, rangeMax: 90}

Description: Angle range (in degrees) for particle emission. Particles are emitted at random angles within this range.

particleEmitterDirection

Type: object

Default: {x: 0, y: -1}

Description: Base direction vector for particle emission. Combined with angle range to determine final particle direction.

🔧 Public Methods

startEmission(endCallback)

Parameters:

  • endCallback: function - Callback function called when emission is finished (all particles have expired).

Description: Starts particle emission. Particles will be emitted according to the configured rate and duration.

Returns: void

stopEmission()

Description: Stops particle emission immediately. Existing particles will continue to exist until their lifetime expires.

Returns: void

draw(camera, zOrder=0)

Parameters:

  • camera: Camera - The camera to draw particles on.
  • zOrder: number - Optional z-order for drawing priority.

Description: Draws all active particles. Must be called every frame. Particles are only drawn if the emitter is emitting or has active particles.

Returns: void

clone()

Description: Creates a copy of this emitter with the same configuration.

Returns: ParticleEmitter - A new ParticleEmitter instance with the same properties.

🔒 Private Methods

The following methods are private (prefixed with _ or #) and are used internally by the engine. Do not call these methods directly.

_processDraw(camera)

Description: Internal method for processing particle drawing. Updates particle positions, colors, lifetimes, and removes particles that are out of bounds or expired.

⚠️ Warning: Methods starting with _ or # are PRIVATE. Incorrect usage can crash the engine. Only use the public methods documented above.

🎯 Examples

Example 1: Explosion Effect

import { ParticleEmitter } from "../classes/particleEmitter.js";
import { Camera } from "../classes/camera.js";

// Create explosion emitter
function createExplosion(x, y) {
    const emitter = new ParticleEmitter(x, y);
    
    // Configure for explosion
    emitter.particleEmissionSpeed = {min: 2, max: 8};
    emitter.particleSize = {width: 5, height: 5};
    emitter.particleColorRange = {startColor: "#ff0000", endColor: "#ffff00"};
    emitter.particleColorChangeRate = {r: -2, g: -1, b: 0};
    emitter.particleLifetime = {min: 300, max: 800};
    emitter.particleAcceleration = {x: 0, y: 0.2};
    emitter.emissionRate = 100;
    emitter.particlesPerEmission = 5;
    emitter.emissionDuration = 200; // Short burst
    emitter.particleEmitterAngleRange = {rangeMin: 0, rangeMax: 360};
    emitter.particleEmitterDirection = {x: 0, y: 0};
    
    // Start and auto-cleanup
    emitter.startEmission(() => {
        // Explosion complete - emitter can be removed
        console.log("Explosion complete!");
    });
    
    return emitter;
}

// Usage
const explosion = createExplosion(400, 300);

// In game loop
function gameLoop() {
    camera.clear();
    explosion.draw(camera);
    camera.flipBuffer();
    requestAnimationFrame(gameLoop);
}

Example 3: Multiple Emitters

import { ParticleEmitter } from "../classes/particleEmitter.js";

// Create multiple emitters
const emitters = [];

// Fire emitter
const fire = new ParticleEmitter(300, 500);
fire.particleColorRange = {startColor: "#ff4400", endColor: "#ffff00"};
fire.particleAcceleration = {x: 0, y: -0.2};
fire.emissionRate = 15;
fire.startEmission();
emitters.push(fire);

// Water emitter
const water = new ParticleEmitter(500, 500);
water.particleColorRange = {startColor: "#0088ff", endColor: "#00ffff"};
water.particleAcceleration = {x: 0, y: 0.1};
water.emissionRate = 10;
water.startEmission();
emitters.push(water);

// In game loop
function gameLoop() {
    camera.clear();
    emitters.forEach(emitter => emitter.draw(camera));
    camera.flipBuffer();
    requestAnimationFrame(gameLoop);
}

Example 4: Directional Particle Stream

import { ParticleEmitter } from "../classes/particleEmitter.js";

// Create directional stream (like a flame thrower)
const streamEmitter = new ParticleEmitter(400, 300);

// Narrow angle range for directional effect
streamEmitter.particleEmitterAngleRange = {rangeMin: 0, rangeMax: 10};
streamEmitter.particleEmitterDirection = {x: 1, y: 0}; // Pointing right

streamEmitter.particleEmissionSpeed = {min: 5, max: 10};
streamEmitter.particleSize = {width: 4, height: 2};
streamEmitter.particleColorRange = {startColor: "#ff0000", endColor: "#ff8800"};
streamEmitter.particleLifetime = {min: 500, max: 1000};
streamEmitter.emissionRate = 50;

// Start emission
streamEmitter.startEmission();

// You can change direction dynamically
streamEmitter.particleEmitterDirection = {x: 0, y: -1}; // Now pointing up

💡 Tips and Best Practices

  • 🎯 Use higher emission rates for dense effects like fire or explosions.
  • 🎯 Use lower emission rates for subtle effects like smoke or sparkles.
  • 🎯 Set emissionDuration to 0 for continuous emission.
  • 🎯 Use particleColorChangeRate to create fading effects.
  • 🎯 Adjust particleAcceleration to simulate gravity or other forces.
  • 🎯 Use narrow particleEmitterAngleRange for directional effects.
  • 🎯 Use wide particleEmitterAngleRange (0-360) for spherical effects.
  • 🎯 Remember to call draw(camera) every frame for active emitters.
  • 🎯 Particles are automatically removed when they exit camera view or their lifetime expires.
  • 🎯 Use clone() to create multiple emitters with the same configuration.
