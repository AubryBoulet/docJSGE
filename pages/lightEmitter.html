LightEmitter

Class representing a light source for the mask light engine. Creates lighting effects with shadows.

📝 Description

The LightEmitter class creates a light source that works with the maskLightEngine to produce lighting effects with shadows. Lights can be omnidirectional (360 degrees) or directional (conical).

⚠️ Important:
  • The lookAt position uses absolute (world) coordinates, not relative to the light position.
  • When angleRange !== 360, the light becomes directional. The lookAt parameter determines the central direction.
  • The color parameter accepts HEX format (#RRGGBB) or RGB format (rgb(r, g, b)). Named colors like "red" are NOT supported.
  • The cache canvas has dimensions of radius*4 x radius*2 to accommodate the light shape and mask operations.

🚀 Basic Usage

Create a Simple Light

import { Camera } from "../classes/camera.js";

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const camera = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

// Initialize the light engine
const lightEngine = camera.initMaskLightEngine();

// Add a light emitter
const light = lightEngine.addLightEmitter(400, 300, 200, "#ffff00");

// In your game loop
function gameLoop() {
    camera.clear();
    
    // Draw your game elements here
    // ...
    
    camera.flipBuffer();
    requestAnimationFrame(gameLoop);
}
gameLoop();

Create a Light with Gradient

import { Camera } from "../classes/camera.js";

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const camera = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

// Initialize the light engine
const lightEngine = camera.initMaskLightEngine();

// Add a light emitter
const light = lightEngine.addLightEmitter(400, 300, 200);

// Create a radial gradient for the light
light.createGradient(
    0,          // Inner radius
    200,       // Outer radius
    [
        [0, "#ffff00"],   // 0%: Yellow
        [0.5, "#ff8800"], // 50%: Orange
        [1, "#ff0000"]    // 100%: Red
    ]
);

// In your game loop
function gameLoop() {
    camera.clear();
    // ...
    camera.flipBuffer();
    requestAnimationFrame(gameLoop);
}

📦 Constructor

The LightEmitter class accepts the following parameters:

Parameter Type Default Description
x number - X coordinate of the light source.
y number - Y coordinate of the light source.
radius number - Radius of the light source in pixels.
color string or CanvasGradient null Color of the light. Can be HEX, RGB, or a gradient created with createGradient().
angleRange number 360 Angle range in degrees. 360 for omnidirectional, less for directional light.

📊 Properties

All properties have getter and setter methods.

x

Type: number

Description: X coordinate of the light source.

y

Type: number

Description: Y coordinate of the light source.

radius

Type: number

Description: Radius of the light source in pixels.

color

Type: string or CanvasGradient

Description: Color of the light. Can be HEX, RGB, or a gradient.

angleRange

Type: number

Default: 360

Description: Angle range in degrees. 360 for omnidirectional, less for directional light.

lookAt

Type: object

Default: {x: 1, y: 0}

Description: Point that the light is looking at (absolute world coordinates). Used to determine the direction of a directional light.

lineAngle

Type: number

Description: Read-only. The calculated angle in radians based on lookAt position.

_cacheCanvas

Type: HTMLCanvasElement

Description: Read-only. Internal canvas used for light rendering. Dimensions are radius*4 x radius*2.

🔧 Public Methods

createGradient(r0, r1, stops)

Parameters:

  • r0: number - Inner radius of the gradient.
  • r1: number - Outer radius of the gradient.
  • stops: Array - Array of color stops in format [[position, color], ...] where position is 0-1 and color is a CSS color string.

Description: Creates a radial gradient for the light color. This allows for smooth color transitions from the center to the edge of the light.

Returns: void

ℹ️ Note: The stops parameter follows the same format as CanvasRenderingContext2D.createRadialGradient(). Each stop is an array of [position, color] where position is between 0 and 1.

🔒 Private Methods

The following methods are private (prefixed with _ or #) and are used internally by the engine. Do not call these methods directly.

#calculateLineAngle()

Description: Calculates the angle based on the lookAt position. Only used when angleRange is not 360.

#updateCanvas()

Description: Updates the internal cache canvas with the light shape and color.

⚠️ Warning: Methods starting with _ or # are PRIVATE. Incorrect usage can crash the engine. Only use the public methods documented above.

🎯 Examples

Example 1: Moving Light

import { Camera } from "../classes/camera.js";

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const camera = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

// Initialize the light engine
const lightEngine = camera.initMaskLightEngine();

// Add a moving light
const light = lightEngine.addLightEmitter(400, 300, 150, "#ffff00");

// Animate the light
let angle = 0;
function gameLoop() {
    camera.clear();
    
    // Move light in a circle
    angle += 0.01;
    light.x = 400 + Math.cos(angle) * 200;
    light.y = 300 + Math.sin(angle) * 200;
    
    // Draw your game elements here
    // ...
    
    camera.flipBuffer();
    requestAnimationFrame(gameLoop);
}
gameLoop();

💡 Tips and Best Practices

  • 🎯 Use angleRange = 360 for omnidirectional point lights.
  • 🎯 Use angleRange < 360 with lookAt for directional spotlights.
  • 🎯 The lookAt parameter uses absolute world coordinates.
  • 🎯 Adjust the mask color opacity to control shadow darkness (e.g., rgba(0,0,0,0.9) for lighter shadows).
  • 🎯 Use createGradient() to create smooth color transitions in your lights.
  • 🎯 The zOrder property controls drawing order. Default is 999 (lights on top).
  • 🎯 Light masks move with the camera automatically.
  • 🎯 For best performance, minimize the number of active light emitters.
  • 🎯 Larger radius lights are more expensive to render.
