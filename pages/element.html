Element

Classe pour créer des éléments statiques avec sprite, sans physique ni animations.

📌 Description

La classe Element représente un élément statique du jeu. Contrairement à Entity, les éléments n'ont pas de physique, d'animations, ou de propriétés dynamiques. Ils sont parfaits pour les décors, les arrière-plans, ou tout élément qui ne nécessite pas de mise à jour à chaque frame.

⚠️ Important: Les éléments ne peuvent pas être animés. Utilisez Entity si vous avez besoin d'animations ou de physique.
⚠️ Attention: La méthode drawElement() ne fonctionne pas avec des sprites animés. Utilisez draw() pour un contrôle plus fin.

🚀 Utilisation de base

Créer un élément simple

import { Element } from "../classes/element.js";
import { Sprite } from "../classes/sprites.js";

// Créer un sprite pour l'élément
const treeSprite = await Sprite.load("./assets/tree.png", false);

// Créer un élément
const tree = new Element({
    sprite: treeSprite,
    position: {x: 200, y: 300},
    scale: 1
});

// Dessiner l'élément dans une caméra
function gameLoop() {
    mainCam.clear();
    tree.drawElement(mainCam);
    requestAnimationFrame(gameLoop);
}

Créer un élément avec un sprite généré

import { Element } from "../classes/element.js";
import { Sprite } from "../classes/sprites.js";

// Créer un sprite vide
const wallSprite = Sprite.create(100, 50, false);
const ctx = wallSprite.ctx;

// Dessiner un mur
ctx.fillStyle = "#8B4513"; // Marron
ctx.fillRect(0, 0, 100, 50);

// Ajouter des détails
ctx.fillStyle = "#A0522D";
for (let i = 0; i < 100; i += 10) {
    ctx.fillRect(i, 0, 5, 50);
}

// Créer un élément avec le sprite
const wall = new Element({
    sprite: wallSprite,
    position: {x: 100, y: 200},
    scale: 1
});

// Dessiner l'élément
wall.drawElement(mainCam);

🔧 Constructeur

La classe Element accepte les paramètres suivants :

Paramètre Type Défaut Description
sprite Sprite - Le sprite de l'élément.
position {x: number, y: number} {x: 0, y: 0} Position initiale de l'élément.
scale number 1 Échelle de l'élément.
targetFPS number 60 FPS cible (peu utilisé pour les éléments statiques).

📜 Propriétés

sprite

Type: Sprite

Description: Le sprite de l'élément.

position

Type: {x: number, y: number}

Description: Position de l'élément dans la scène.

scale

Type: number

Description: Échelle de l'élément.

targetFPS

Type: number

Description: FPS cible pour l'élément.

⚙️ Méthodes

drawElement(camera)

Paramètres:

  • camera: Camera - La caméra dans laquelle dessiner l'élément.

Description: Dessine l'élément dans la caméra spécifiée. Cette méthode gère automatiquement le clippage si l'élément est partiellement hors de la caméra.

Retourne: void

draw(camera, dimension, position)

Paramètres:

  • camera: Camera - La caméra dans laquelle dessiner.
  • dimension: object - Les dimensions de la source à dessiner.
  • position: object - La position et la taille de destination.

Description: Méthode de dessin de bas niveau pour un contrôle plus fin. Utilisée en interne par drawElement().

Retourne: void

🎯 Exemples

Exemple 1: Créer un décor avec des éléments

import { Element } from "../classes/element.js";
import { Sprite } from "../classes/sprites.js";
import { Camera } from "../classes/camera.js";

// Charger les sprites pour le décor
const groundSprite = await Sprite.load("./assets/ground.png", false);
const treeSprite = await Sprite.load("./assets/tree.png", false);
const rockSprite = await Sprite.load("./assets/rock.png", false);

// Créer les éléments du décor
const ground = new Element({
    sprite: groundSprite,
    position: {x: 0, y: 500},
    scale: 1
});

const tree1 = new Element({
    sprite: treeSprite,
    position: {x: 200, y: 300},
    scale: 1.5
});

const tree2 = new Element({
    sprite: treeSprite,
    position: {x: 400, y: 350},
    scale: 1.2
});

const rock1 = new Element({
    sprite: rockSprite,
    position: {x: 100, y: 450},
    scale: 1
});

const rock2 = new Element({
    sprite: rockSprite,
    position: {x: 300, y: 400},
    scale: 0.8
});

// Créer une caméra
const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#87CEEB" // Ciel bleu
});

function gameLoop() {
    mainCam.clear();
    
    // Dessiner le décor
    ground.drawElement(mainCam);
    tree1.drawElement(mainCam);
    tree2.drawElement(mainCam);
    rock1.drawElement(mainCam);
    rock2.drawElement(mainCam);
    
    // Dessiner les entités dynamiques...
    
    requestAnimationFrame(gameLoop);
}

Exemple 2: Arrière-plan en tuiles

import { Element } from "../classes/element.js";
import { Sprite } from "../classes/sprites.js";

// Créer un sprite pour une tuile
const tileSprite = Sprite.create(32, 32, false);
const ctx = tileSprite.ctx;
ctx.fillStyle = "#4CAF50"; // Vert
ctx.fillRect(0, 0, 32, 32);

// Créer un tableau d'éléments pour l'arrière-plan
const tiles = [];
const tileSize = 32;
const mapWidth = 20;
const mapHeight = 15;

for (let y = 0; y < mapHeight; y++) {
    for (let x = 0; x < mapWidth; x++) {
        const tile = new Element({
            sprite: tileSprite,
            position: {x: x * tileSize, y: y * tileSize},
            scale: 1
        });
        tiles.push(tile);
    }
}

// Dessiner toutes les tuiles
function drawTiles() {
    tiles.forEach(tile => {
        tile.drawElement(mainCam);
    });
}

Exemple 3: Éléments avec différents sprites

import { Element } from "../classes/element.js";
import { Sprite } from "../classes/sprites.js";

// Créer différents types d'éléments
const elements = [];

// Éléments de type "sol"
for (let i = 0; i < 10; i++) {
    const groundSprite = Sprite.create(50, 20, false);
    groundSprite.ctx.fillStyle = "#8B4513";
    groundSprite.ctx.fillRect(0, 0, 50, 20);
    
    const ground = new Element({
        sprite: groundSprite,
        position: {x: i * 50, y: 500},
        scale: 1
    });
    elements.push(ground);
}

// Éléments de type "plateforme"
for (let i = 0; i < 5; i++) {
    const platformSprite = Sprite.create(80, 15, false);
    platformSprite.ctx.fillStyle = "#654321";
    platformSprite.ctx.fillRect(0, 0, 80, 15);
    
    const platform = new Element({
        sprite: platformSprite,
        position: {x: 100 + i * 150, y: 400 - i * 50},
        scale: 1
    });
    elements.push(platform);
}

// Éléments de type "piège"
for (let i = 0; i < 3; i++) {
    const trapSprite = Sprite.create(30, 30, false);
    trapSprite.ctx.fillStyle = "#FF0000";
    trapSprite.ctx.fillRect(0, 0, 30, 30);
    
    const trap = new Element({
        sprite: trapSprite,
        position: {x: 200 + i * 100, y: 500},
        scale: 1
    });
    elements.push(trap);
}

// Dessiner tous les éléments
function drawElements() {
    elements.forEach(element => {
        element.drawElement(mainCam);
    });
}

💡 Conseils et bonnes pratiques

  • 🔹 Utilisez Element pour les éléments statiques qui ne changent pas (décors, arrière-plans, plateformes).
  • 🔹 Utilisez Entity pour les objets dynamiques qui nécessitent des animations ou de la physique.
  • 🔹 Pour les grands décors, envisagez de regrouper les éléments dans des sprites plus grands pour réduire le nombre d'appels de dessin.
  • 🔹 Vous pouvez changer le sprite d'un élément à tout moment pour créer des effets visuels.
  • 🔹 Utilisez la propriété scale pour redimensionner les éléments sans modifier le sprite original.
  • 🔹 Pour les jeux avec défilement, les éléments statiques peuvent être optimisés car ils ne nécessitent pas de mise à jour à chaque frame.
