Element

Class for creating static elements with sprites, without physics or animations.

📝 Description

The Element class represents a static game element. Unlike Entity, elements do not have physics, animations, or dynamic properties. They are perfect for scenery, backgrounds, or any element that does not require updating every frame.

New Features:

  • Elements can now be added to and removed from the global displayedElement list automatically when added/removed from scenes
  • Gravity contact callback support for interaction with entities
  • Flip support (horizontal and vertical) for mirroring sprites

ℹ️ Important: Elements cannot be animated. Use Entity if you need animations or physics.
⚠️ Warning: The drawElement() method does not work with animated sprites. Use draw() for more fine-grained control.

🚀 Basic Usage

Create a Simple Element

import { Element } from "./jsge.js";
import { Sprite } from "./jsge.js";

// Create a sprite for the element
const treeSprite = await Sprite.load("./assets/tree.png", false);

// Create an element
const tree = new Element({
    sprite: treeSprite,
    position: {x: 200, y: 300},
    scale: 1
});

// Draw the element in a camera
function gameLoop() {
    mainCam.clear();
    tree.draw(mainCam);
    requestAnimationFrame(gameLoop);
}

Create an Element with a Generated Sprite

import { Element } from "./jsge.js";
import { Sprite } from "./jsge.js";

// Create an empty sprite
const wallSprite = Sprite.create(100, 50, false);
const ctx = wallSprite.ctx;
ctx.fillStyle = "#8B4513";
ctx.fillRect(0, 0, 100, 50);

// Create an element with the generated sprite
const wall = new Element({
    sprite: wallSprite,
    position: {x: 300, y: 200},
    scale: 1
});

// Draw the element
wall.draw(mainCam);

Create an Element Using the Static Factory Method

import { Element } from "./jsge.js";

// Create an element with custom properties
const customElement = Element.create(
    {
        sprite: mySprite,
        position: {x: 100, y: 100},
        scale: 2
    },
    [
        {
            customProperty: "value",
            customMethod: () => { console.log("Hello!"); }
        }
    ]
);

// Access custom properties
console.log(customElement.customProperty); // "value"
customElement.customMethod(); // "Hello!"

📥 Constructor

The Element class accepts the following parameters:

Parameter Type Default Description
options Object {} Configuration object for the element.
options.sprite Sprite null The sprite to display for this element.
options.position {x: number, y: number} {x: 0, y: 0} Initial position of the element.
options.scale number 1 Scale factor for the element (1 = normal size).

Static Factory Method

The Element.create() method allows creating elements with custom properties:

Parameter Type Default Description
datas Object null Base configuration for the element (sprite, position, scale).
assigns Array<Object> null Array of objects containing custom properties and methods to assign to the element.

📊 Properties

sprite

Type: Sprite

Description: The sprite displayed by this element.

position

Type: {x: number, y: number}

Description: Position of the element in the scene.

scale

Type: number

Description: Scale factor of the element.

flippedX

Type: boolean

Description: If true, the element is flipped horizontally (mirrored on X-axis).

flippedY

Type: boolean

Description: If true, the element is flipped vertically (mirrored on Y-axis).

onGravityContact

Type: Function | null

Description: Callback function called when an entity with gravity comes into contact with this element.

displayedElement (static)

Type: Array<Element>

Description: Static array containing all currently displayed elements. Elements are automatically added/removed when added/removed from scenes.

⚙️ Methods

draw(cam, zOrder)

Parameters:

  • cam: Camera - The camera to draw through.
  • zOrder: number - The z-order for rendering (default: 0).

Description: Draws the element through the specified camera with the given z-order.

Returns: void

_processDraw(cam)

Parameters:

  • cam: Camera - The camera to draw through.

Description: Internal method called by the camera to process drawing. Handles clipping and positioning.

Returns: void

assign(assigns, options)

Parameters:

  • assigns: Array<Object> - Array of objects with properties to assign.
  • options: { overwrite: boolean } - Options object. Set overwrite: true to force overwrite existing properties.

Description: Assigns custom properties and methods to the element. Warns if properties already exist unless overwrite: true is specified.

Returns: void

// Add custom properties
const element = new Element({ sprite: mySprite, position: {x: 0, y: 0} });

element.assign([
    { health: 100 },
    { damage: (amount) => { this.health -= amount; } }
]);

// With overwrite
element.assign([{ health: 50 }], { overwrite: true });

create(datas, assigns) (static)

Parameters:

  • datas: Object - Base configuration for the element.
  • assigns: Array<Object> - Custom properties and methods to assign.

Description: Static factory method to create an element with custom properties.

Returns: Element - The newly created element.

_addToDisplayedElement(element) (static)

Parameters:

  • element: Element - The element to add.

Description: Internal static method to add an element to the displayed elements list.

Returns: void

_removeFromDisplayedElement(element) (static)

Parameters:

  • element: Element - The element to remove.

Description: Internal static method to remove an element from the displayed elements list.

Returns: void

🎯 Examples

Example 1: Creating Background Elements

import { Element, Sprite } from "./jsge.js";

// Load background sprites
const mountainSprite = await Sprite.load("./assets/mountain.png", false);
const treeSprite = await Sprite.load("./assets/tree.png", false);
const bushSprite = await Sprite.load("./assets/bush.png", false);

// Create background elements
const mountain = new Element({
    sprite: mountainSprite,
    position: {x: 0, y: 400},
    scale: 1
});

const tree1 = new Element({
    sprite: treeSprite,
    position: {x: 200, y: 350},
    scale: 1
});

const tree2 = new Element({
    sprite: treeSprite,
    position: {x: 400, y: 350},
    scale: 1
});

const bush = new Element({
    sprite: bushSprite,
    position: {x: 300, y: 400},
    scale: 0.8
});

// Draw all elements
function gameLoop() {
    mainCam.clear();
    
    mountain.draw(mainCam, 0);
    tree1.draw(mainCam, 0);
    tree2.draw(mainCam, 0);
    bush.draw(mainCam, 1);
    
    requestAnimationFrame(gameLoop);
}

Example 2: Using Flipped Elements

import { Element } from "./jsge.js";

const treeSprite = await Sprite.load("./assets/tree.png", false);

// Create a normal tree
const treeLeft = new Element({
    sprite: treeSprite,
    position: {x: 200, y: 300},
    scale: 1
});

// Create a flipped tree (mirrored)
const treeRight = new Element({
    sprite: treeSprite,
    position: {x: 400, y: 300},
    scale: 1
});
treeRight.flippedX = true; // Flip horizontally

// Draw both trees
function gameLoop() {
    mainCam.clear();
    treeLeft.draw(mainCam);
    treeRight.draw(mainCam);
    requestAnimationFrame(gameLoop);
}

Example 3: Gravity Contact with Elements

import { Element, Entity } from "./jsge.js";

// Create a platform element
const platform = new Element({
    sprite: platformSprite,
    position: {x: 300, y: 400},
    scale: 1
});

// Set up gravity contact callback
platform.onGravityContact = (element, entity) => {
    console.log(`Entity ${entity} landed on platform ${element}`);
    // Play landing sound, trigger animations, etc.
};

// Create a player entity with gravity
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 300, y: 200},
    gravity: 0.5,
    gravityAcceleration: 1
});

// Add elements to the displayed list
Element._addToDisplayedElement(platform);

// Update and draw
function gameLoop() {
    mainCam.clear();
    
    player.update();
    player.draw(mainCam, 1);
    platform.draw(mainCam, 0);
    
    requestAnimationFrame(gameLoop);
}

Example 4: Using Elements with Scenes

import { Element, Scene, Sprite } from "./jsge.js";

// Create a scene
const levelScene = new Scene();

// Create background elements
const background = new Element({
    sprite: bgSprite,
    position: {x: 0, y: 0}
});

const foreground = new Element({
    sprite: fgSprite,
    position: {x: 0, y: 0}
});

// Add elements to the scene with z-orders
levelScene.add(background, 0);
levelScene.add(foreground, 2);

// Elements are automatically added to the displayed elements list
// when added to a scene

// Draw the entire scene
function gameLoop() {
    mainCam.clear();
    levelScene.draw(mainCam);
    requestAnimationFrame(gameLoop);
}

💡 Tips and Best Practices

  • 🎯 Use Elements for static content: Elements are perfect for backgrounds, scenery, and any visual elements that don't need to move or change.
  • 🎯 Use Entity for dynamic content: If you need physics, animations, or collision detection, use Entity instead.
  • 🎯 Leverage flipping: Use the flippedX and flippedY properties to mirror elements without creating separate sprites.
  • 🎯 Use z-order effectively: When drawing multiple elements, use the z-order parameter to control which elements appear in front of others.
  • 🎯 Gravity contact callbacks: Use the onGravityContact property to create interactive elements that respond when entities land on them.
  • 🎯 Scene integration: When using scenes, elements are automatically managed in the displayed elements list, simplifying element management.
  • 🎯 Custom properties: Use the assign() method or create() factory to add custom properties and methods to elements for game-specific functionality.
