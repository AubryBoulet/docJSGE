Element

Class for creating static elements with sprites, without physics or animations.

📌 Description

The Element class represents a static game element. Unlike Entity, elements do not have physics, animations, or dynamic properties. They are perfect for scenery, backgrounds, or any element that does not require updating every frame.

⚠️ Important: Elements cannot be animated. Use Entity if you need animations or physics.
⚠️ Warning: The drawElement() method does not work with animated sprites. Use draw() for more fine-grained control.

🚀 Basic Usage

Create a Simple Element

import { Element } from "../classes/element.js";
import { Sprite } from "../classes/sprites.js";

// Create a sprite for the element
const treeSprite = await Sprite.load("./assets/tree.png", false);

// Create an element
const tree = new Element({
    sprite: treeSprite,
    position: {x: 200, y: 300},
    scale: 1
});

// Draw the element in a camera
function gameLoop() {
    mainCam.clear();
    tree.drawElement(mainCam);
    requestAnimationFrame(gameLoop);
}

Create an Element with a Generated Sprite

import { Element } from "../classes/element.js";
import { Sprite } from "../classes/sprites.js";

// Create an empty sprite
const wallSprite = Sprite.create(100, 50, false);
const ctx = wallSprite.ctx;

// Draw a wall
ctx.fillStyle = "#8B4513"; // Brown
ctx.fillRect(0, 0, 100, 50);

// Add details
ctx.fillStyle = "#A0522D";
for (let i = 0; i < 100; i += 10) {
    ctx.fillRect(i, 0, 5, 50);
}

// Create an element with the sprite
const wall = new Element({
    sprite: wallSprite,
    position: {x: 100, y: 200},
    scale: 1
});

// Draw the element
wall.drawElement(mainCam);

🔧 Constructor

The Element class accepts the following parameters:

Parameter Type Default Description
sprite Sprite - The element's sprite.
position {x: number, y: number} {x: 0, y: 0} Initial position of the element.
scale number 1 Scale of the element.
targetFPS number 60 Target FPS (rarely used for static elements).

📜 Properties

sprite

Type: Sprite

Description: The element's sprite.

position

Type: {x: number, y: number}

Description: Position of the element in the scene.

scale

Type: number

Description: Scale of the element.

targetFPS

Type: number

Description: Target FPS for the element.

⚙️ Methods

drawElement(camera)

Parameters:

  • camera: Camera - The camera to draw the element in.

Description: Draws the element in the specified camera. This method automatically handles clipping if the element is partially outside the camera.

Returns: void

draw(camera, dimension, position)

Parameters:

  • camera: Camera - The camera to draw in.
  • dimension: object - The source dimensions to draw.
  • position: object - The destination position and size.

Description: Low-level drawing method for finer control. Used internally by drawElement().

Returns: void

🎯 Examples

Example 1: Create Scenery with Elements

import { Element } from "../classes/element.js";
import { Sprite } from "../classes/sprites.js";
import { Camera } from "../classes/camera.js";

// Load sprites for the scenery
const groundSprite = await Sprite.load("./assets/ground.png", false);
const treeSprite = await Sprite.load("./assets/tree.png", false);
const rockSprite = await Sprite.load("./assets/rock.png", false);

// Create scenery elements
const ground = new Element({
    sprite: groundSprite,
    position: {x: 0, y: 500},
    scale: 1
});

const tree1 = new Element({
    sprite: treeSprite,
    position: {x: 200, y: 300},
    scale: 1.5
});

const tree2 = new Element({
    sprite: treeSprite,
    position: {x: 400, y: 350},
    scale: 1.2
});

const rock1 = new Element({
    sprite: rockSprite,
    position: {x: 100, y: 450},
    scale: 1
});

const rock2 = new Element({
    sprite: rockSprite,
    position: {x: 300, y: 400},
    scale: 0.8
});

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#87CEEB" // Sky blue
});

function gameLoop() {
    mainCam.clear();
    
    // Draw scenery
    ground.drawElement(mainCam);
    tree1.drawElement(mainCam);
    tree2.drawElement(mainCam);
    rock1.drawElement(mainCam);
    rock2.drawElement(mainCam);
    
    // Draw dynamic entities...
    
    requestAnimationFrame(gameLoop);
}

Example 2: Tiled Background

import { Element } from "../classes/element.js";
import { Sprite } from "../classes/sprites.js";

// Create a sprite for a tile
const tileSprite = Sprite.create(32, 32, false);
const ctx = tileSprite.ctx;
ctx.fillStyle = "#4CAF50"; // Green
ctx.fillRect(0, 0, 32, 32);

// Create an array of elements for the background
const tiles = [];
const tileSize = 32;
const mapWidth = 20;
const mapHeight = 15;

for (let y = 0; y < mapHeight; y++) {
    for (let x = 0; x < mapWidth; x++) {
        const tile = new Element({
            sprite: tileSprite,
            position: {x: x * tileSize, y: y * tileSize},
            scale: 1
        });
        tiles.push(tile);
    }
}

// Draw all tiles
function drawTiles() {
    tiles.forEach(tile => {
        tile.drawElement(mainCam);
    });
}

Example 3: Elements with Different Sprites

import { Element } from "../classes/element.js";
import { Sprite } from "../classes/sprites.js";

// Create different types of elements
const elements = [];

// Ground elements
for (let i = 0; i < 10; i++) {
    const groundSprite = Sprite.create(50, 20, false);
    groundSprite.ctx.fillStyle = "#8B4513";
    groundSprite.ctx.fillRect(0, 0, 50, 20);
    
    const ground = new Element({
        sprite: groundSprite,
        position: {x: i * 50, y: 500},
        scale: 1
    });
    elements.push(ground);
}

// Platform elements
for (let i = 0; i < 5; i++) {
    const platformSprite = Sprite.create(80, 15, false);
    platformSprite.ctx.fillStyle = "#654321";
    platformSprite.ctx.fillRect(0, 0, 80, 15);
    
    const platform = new Element({
        sprite: platformSprite,
        position: {x: 100 + i * 150, y: 400 - i * 50},
        scale: 1
    });
    elements.push(platform);
}

// Trap elements
for (let i = 0; i < 3; i++) {
    const trapSprite = Sprite.create(30, 30, false);
    trapSprite.ctx.fillStyle = "#FF0000";
    trapSprite.ctx.fillRect(0, 0, 30, 30);
    
    const trap = new Element({
        sprite: trapSprite,
        position: {x: 200 + i * 100, y: 500},
        scale: 1
    });
    elements.push(trap);
}

// Draw all elements
function drawElements() {
    elements.forEach(element => {
        element.drawElement(mainCam);
    });
}

💡 Tips and Best Practices

  • 🔹 Use Element for static elements that don't change (scenery, backgrounds, platforms).
  • 🔹 Use Entity for dynamic objects that require animations or physics.
  • 🔹 For large scenery, consider grouping elements into larger sprites to reduce the number of draw calls.
  • 🔹 You can change the sprite of an element at any time to create visual effects.
  • 🔹 Use the scale property to resize elements without modifying the original sprite.
  • 🔹 For scrolling games, static elements can be optimized as they don't require updates every frame.
