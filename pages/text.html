Text

Classe pour créer et afficher du texte avec effets spéciaux et animations.

📌 Description

La classe Text permet de créer et d'afficher du texte avec divers effets spéciaux comme les ondes, les tremblements, les clignotements, et les dégradés. Elle est utilisée en interne par Gadget et Button, mais peut aussi être utilisée indépendamment pour afficher du texte à l'écran.

Text gère automatiquement le rendu du texte avec les effets appliqués, et peut être mis à jour dynamiquement.

🚀 Utilisation de base

Créer un texte simple

import { Text } from "../classes/text.js";

// Créer un objet Text
const myText = new Text(
    "Bonjour JSGE!",    // Texte à afficher
    200,                // Largeur du canvas
    50                 // Hauteur du canvas
);

// Accéder au canvas et au contexte
const canvas = myText._canvas;
const ctx = myText._ctx;

// Dessiner le texte manuellement
ctx.clearRect(0, 0, canvas.width, canvas.height);
myText._updateCanvas(); // Met à jour le rendu du texte

Créer un texte avec effets

import { Text } from "../classes/text.js";

// Créer un texte avec des effets
const animatedText = new Text(
    "${wave(2,5,5)} Texte ${blink(0,20)} animé",
    300,
    60
);

// Le texte sera automatiquement animé lors des mises à jour
// Pour forcer une mise à jour :
animatedText._update();

🔧 Constructeur

La classe Text accepte les paramètres suivants :

Paramètre Type Défaut Description
value string - Texte à afficher. Peut contenir des tags d'effets spéciaux.
width number - Largeur du canvas interne.
height number - Hauteur du canvas interne.

📜 Propriétés

value

Type: string

Description: Texte à afficher.

originalValue

Type: string

Description: Valeur originale du texte (sans les effets appliqués).

canvas

Type: HTMLCanvasElement

Description: Le canvas interne utilisé pour le rendu du texte.

ctx

Type: CanvasRenderingContext2D

Description: Le contexte 2D du canvas interne.

width

Type: number

Description: Largeur du canvas interne.

height

Type: number

Description: Hauteur du canvas interne.

⚙️ Méthodes

addGradient(name, gradient)

Paramètres:

  • name: string - Nom du dégradé.
  • gradient: CanvasGradient - L'objet dégradé à enregistrer.

Description: Enregistre un dégradé pour une utilisation ultérieure avec le tag ${grad(name)}.

Retourne: void

_updateEffect()

Description: Force le recalcul des effets de texte. Utile lorsque vous modifiez les propriétés des effets.

Retourne: void

_update()

Description: Vérifie si les effets de texte doivent être mis à jour. Retourne true si une mise à jour est nécessaire.

Retourne: boolean

_updateCanvas()

Description: Met à jour le canvas interne avec le texte et les effets actuels.

Retourne: void

🎯 Exemples

Exemple 1: Texte avec plusieurs effets

Animation de texte avec différents effets. 

import { Text } from "../classes/text.js";
import { Camera } from "../classes/camera.js";

// Créer un texte avec plusieurs effets
const fancyText = new Text(
    "${wave(2,5,5)} JSGE ${shake(3,5,3)} est ${blink(0,20)} génial !",
    400,
    100
);

// Créer une caméra
const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

// Dessiner le texte dans la caméra
function gameLoop() {
    mainCam.clear();
    
    // Mettre à jour les effets
    fancyText._update();
    
    // Dessiner le canvas du texte dans la caméra
    mainCam.ctx.drawImage(
        fancyText._canvas,
        100,  // x
        100   // y
    );
    
    requestAnimationFrame(gameLoop);
}
gameLoop();

Exemple 2: Texte avec dégradé

import { Text } from "../classes/text.js";

// Créer un texte
const gradientText = new Text("Texte avec dégradé", 300, 50);

// Créer un dégradé
const gradient = gradientText._ctx.createLinearGradient(0, 0, 300, 0);
gradient.addColorStop(0, "#e74c3c");
gradient.addColorStop(0.5, "#f1c40f");
gradient.addColorStop(1, "#2ecc71");

// Ajouter le dégradé au texte
gradientText.addGradient("rainbow", gradient);

// Mettre à jour le texte pour appliquer le dégradé
gradientText.value = "${grad(rainbow)} Texte coloré";
gradientText._updateEffect();

// Dessiner le texte
const canvas = document.querySelector("#gameCanvas");
const ctx = canvas.getContext("2d");
ctx.drawImage(gradientText._canvas, 100, 100);

Exemple 4: Texte avec effets dynamiques

import { Text } from "../classes/text.js";

// Créer un texte
const dynamicText = new Text("Texte dynamique", 300, 50);

// Changer le texte dynamiquement
function updateTextContent() {
    const effects = [
        "${wave(2,5,5)} Ondulation",
        "${shake(3,5,3)} Tremblement",
        "${blink(0,20)} Clignotement",
        "${wave(1,10,2)${shake(2,8,4)}} Combinaison"
    ];
    
    const randomEffect = effects[Math.floor(Math.random() * effects.length)];
    dynamicText.value = randomEffect;
    dynamicText._updateEffect();
}

// Mettre à jour le texte toutes les 2 secondes
setInterval(updateTextContent, 2000);

// Dessiner le texte
function gameLoop() {
    dynamicText._update();
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    ctx.drawImage(dynamicText._canvas, 100, 100);
    requestAnimationFrame(gameLoop);
}

💡 Conseils et bonnes pratiques

  • 🔹 Appelez _update() à chaque frame pour mettre à jour les animations de texte.
  • 🔹 Utilisez _updateEffect() après avoir modifié la valeur du texte ou les dégradés.
  • 🔹 Appelez addGradient() avant de définir la valeur du texte si vous utilisez le tag ${grad()}.
  • 🔹 Vous pouvez combiner plusieurs effets dans un même texte.
  • 🔹 Pour de meilleures performances avec beaucoup de texte, envisagez de cacher les textes hors de l'écran.
  • 🔹 Utilisez la propriété _textInfos pour personnaliser l'apparence du texte (police, couleur, alignement, etc.).

🔗 Voir aussi

La classe Text est utilisée par :

  • 🔹 Gadget - Classe de base pour les éléments UI
  • 🔹 Button - Boutons cliquables

📖 Tags d'effets disponibles

Text supporte les tags d'effets suivants :

Tag Paramètres Description
${wave(amplitude, frequency, speed)} amplitude: number - Amplitude de l'onde en pixels
frequency: number - Fréquence de l'onde (nombre de frames avant mise à jour)
speed: number - Vitesse de déplacement de l'onde 		Fait onduler le texte verticalement. Crée un effet de vague.
${shake(amplitude, frequency, speed)} amplitude: number - Amplitude du tremblement en pixels
frequency: number - Fréquence du tremblement
speed: number - Vitesse du tremblement 		Fait trembler le texte horizontalement et verticalement.
${blink(start, duration)} start: number - Position de départ du clignotement (0-1)
duration: number - Durée du clignotement en frames 		Fait clignoter le texte en le faisant disparaître et réapparaître.
${grad(name)} name: string - Nom du dégradé enregistré avec addGradient() Applique un dégradé de couleur au texte.
ℹ️ Info: Vous pouvez imbriquer les tags d'effets pour créer des combinaisons complexes : ${wave(2,5,5)${shake(1,3,2)}}

🎨 Personnalisation du texte

La propriété _textInfos permet de personnaliser l'apparence du texte :

Propriété Type Défaut Description
font string "24px arial" Police du texte (taille + famille).
align string "start" Alignement horizontal du texte.
baseline string "alphabetic" Ligne de base verticale du texte.
direction string "inherit" Direction du texte.
lineHeight number 3 Hauteur de ligne pour le texte multi-lignes.
color string "black" Couleur du texte.
