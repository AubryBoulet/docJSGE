Text

Class for creating and displaying text with special effects and animations.

📌 Description

The Text class allows you to create and display text with various special effects such as waves, shakes, blinks, and gradients. It is used internally by Gadget and Button, but can also be used independently to display text on screen.

Text automatically handles text rendering with applied effects, and can be updated dynamically.

🚀 Basic Usage

Create Simple Text

import { Text } from "../classes/text.js";

// Create a Text object
const myText = new Text(
    "Hello JSGE!",    // Text to display
    200,              // Canvas width
    50               // Canvas height
);

// Access canvas and context
const canvas = myText._canvas;
const ctx = myText._ctx;

// Draw text manually
ctx.clearRect(0, 0, canvas.width, canvas.height);
myText._updateCanvas(); // Update text rendering

Create Text with Effects

import { Text } from "../classes/text.js";

// Create text with effects
const animatedText = new Text(
    "${wave(2,5,5) Text} ${blink(0,20) animated}",
    300,
    60
);

// Text will be automatically animated during updates
// To force an update:
animatedText._update();

🔧 Constructor

The Text class accepts the following parameters:

Parameter Type Default Description
value string - Text to display. Can contain special effect tags.
width number - Width of the internal canvas.
height number - Height of the internal canvas.

📜 Properties

value

Type: string

Description: Text to display.

originalValue

Type: string

Description: Original text value (without applied effects).

canvas

Type: HTMLCanvasElement

Description: Internal canvas used for text rendering.

ctx

Type: CanvasRenderingContext2D

Description: 2D context of the internal canvas.

width

Type: number

Description: Width of the internal canvas.

height

Type: number

Description: Height of the internal canvas.

⚙️ Methods

addGradient(name, gradient)

Parameters:

  • name: string - Name of the gradient.
  • gradient: CanvasGradient - Gradient object to register.

Description: Registers a gradient for later use with the ${grad(name)} tag.

Returns: void

_updateEffect()

Description: Forces recalculation of text effects. Useful when you modify effect properties.

Returns: void

_update()

Description: Checks if text effects need to be updated. Returns true if an update is needed.

Returns: boolean

_updateCanvas()

Description: Updates the internal canvas with the current text and effects.

Returns: void

🎯 Examples

Example 1: Text with Multiple Effects

Text animation with different effects. 

import { Text } from "../classes/text.js";
import { Camera } from "../classes/camera.js";

// Create text with multiple effects
const fancyText = new Text(
    "${wave(2,5,5) JSGE} ${shake(3,5,3) is} ${blink(0,20) awesome!}",
    400,
    100
);

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

// Draw text in the camera
function gameLoop() {
    mainCam.clear();
    
    // Update effects
    fancyText._update();
    
    // Draw text canvas in the camera
    mainCam.ctx.drawImage(
        fancyText._canvas,
        100,  // x
        100   // y
    );
    
    requestAnimationFrame(gameLoop);
}
gameLoop();
💁️ Important: In effect syntax, the text to be affected must be inside the effect tags: ${effectName params}text to affect. For example: ${wave(2,5,5) JSGE} applies the wave effect to "JSGE".

You can nest effects to combine them: ${wave(2,5,5) ${shake(3,5,3) is awesome!}} applies both wave and shake to "is awesome!".

You can also change text color using HEX or color names: ${wave(2,5,5) ${red JSGE} ${#00FF00 is}}.

→ Note: Always put a space between two effects!

Example 2: Text with Gradient

import { Text } from "../classes/text.js";

// Create text
const gradientText = new Text("Text with gradient", 300, 50);

// Create a gradient
const gradient = gradientText._ctx.createLinearGradient(0, 0, 300, 0);
gradient.addColorStop(0, "#e74c3c");
gradient.addColorStop(0.5, "#f1c40f");
gradient.addColorStop(1, "#2ecc71");

// Add gradient to text
gradientText.addGradient("rainbow", gradient);

// Set text value with gradient tag
gradientText.value = "${grad(rainbow)} Colored text";
gradientText._updateEffect();

// Draw text
const canvas = document.querySelector("#gameCanvas");
const ctx = canvas.getContext("2d");
ctx.drawImage(gradientText._canvas, 100, 100);

Example 3: Multi-line Text

import { Text } from "../classes/text.js";

// Create multi-line text
const multiLineText = new Text(
    "Line 1\nLine 2\nLine 3",
    300,
    100
);

// Customize text properties
multiLineText._textInfos.font = "16px Arial";
multiLineText._textInfos.align = "center";
multiLineText._textInfos.baseline = "middle";
multiLineText._textInfos.color = "#3498db";

// Update canvas
multiLineText._updateCanvas();

// Draw text
ctx.drawImage(multiLineText._canvas, 100, 100);

Example 4: Text with Dynamic Effects

import { Text } from "../classes/text.js";

// Create text
const dynamicText = new Text("Dynamic text", 300, 50);

// Change text dynamically
function updateTextContent() {
    const effects = [
        "${wave(2,5,5) Waving}",
        "${shake(3,5,3) Shaking}",
        "${blink(0,20) Blinking}",
        "${wave(1,10,2)${shake(2,8,4)}} Combination"
    ];
    
    const randomEffect = effects[Math.floor(Math.random() * effects.length)];
    dynamicText.value = randomEffect;
    dynamicText._updateEffect();
}

// Update text every 2 seconds
setInterval(updateTextContent, 2000);

// Draw text
function gameLoop() {
    dynamicText._update();
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    ctx.drawImage(dynamicText._canvas, 100, 100);
    requestAnimationFrame(gameLoop);
}

💡 Tips and Best Practices

  • 🔹 Call _update() every frame to update text animations.
  • 🔹 Use _updateEffect() after modifying the text value or gradients.
  • 🔹 Call addGradient() before setting the text value if you use the ${grad()} tag.
  • 🔹 You can combine multiple effects in the same text.
  • 🔹 For better performance with lots of text, consider hiding text outside the screen.
  • 🔹 Use the _textInfos property to customize text appearance (font, color, alignment, etc.).

📖 Available Effect Tags

Text supports the following effect tags:

Tag Parameters Description
${wave(amplitude, frequency, speed)} amplitude: number - Wave amplitude in pixels
frequency: number - Wave frequency (number of frames before update)
speed: number - Wave movement speed 		Makes text wave vertically. Creates a wave effect.
${shake(amplitude, frequency, speed)} amplitude: number - Shake amplitude in pixels
frequency: number - Shake frequency
speed: number - Shake speed 		Makes text shake horizontally and vertically.
${blink(start, duration)} start: number - Blink start position (0-1)
duration: number - Blink duration in frames 		Makes text blink by fading in and out.
${grad(name)} name: string - Name of the gradient registered with addGradient() Applies a color gradient to the text.
ℹ️ Info: You can nest effect tags to create complex combinations: ${wave(2,5,5) ${shake(1,3,2) nested effects}}

🎨 Text Customization

The _textInfos property allows you to customize text appearance:

Property Type Default Description
font string "24px arial" Text font (size + family).
align string "start" Horizontal text alignment.
baseline string "alphabetic" Vertical baseline of the text.
direction string "inherit" Text direction.
lineHeight number 3 Line height for multi-line text.
color string "black" Text color.
