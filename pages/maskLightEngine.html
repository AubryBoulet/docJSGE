maskLightEngine

Class for creating and managing light masking effects. Produces lighting with shadows by masking out areas not covered by light sources.

📝 Description

The maskLightEngine class manages a masking system that creates lighting effects with shadows. It works by first creating "holes" in a mask for all light sources, then applying the light colors. This allows light masks to overlap without being affected by the holes from other light sources.

This class is typically initialized via Camera.initMaskLightEngine() and is automatically integrated with the camera's rendering pipeline.

⚠️ Important:
  • The mask canvas is initialized with the camera dimensions.
  • The mask position (on the main canvas) is relative to the camera position.
  • If you move the camera, the mask will follow.
  • When modifying mask position or size, ensure it doesn't exceed camera dimensions.
  • The default mask color is rgba(0,0,0,1) (fully opaque black).
  • The default zIndex is 999, meaning lights are drawn on top of most elements.

🚀 Basic Usage

Initialize the Light Engine

import { Camera } from "../classes/camera.js";

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const camera = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

// Initialize the light engine
// This returns the maskLightEngine instance
const lightEngine = camera.initMaskLightEngine();

// Add light emitters
const light1 = lightEngine.addLightEmitter(400, 300, 200, "#ffff00");
const light2 = lightEngine.addLightEmitter(200, 200, 150, "#ff00ff");

// In your game loop
function gameLoop() {
    camera.clear();
    
    // Draw your game elements here
    // ...
    
    camera.flipBuffer();
    requestAnimationFrame(gameLoop);
}
gameLoop();

Customize Mask Properties

import { Camera } from "../classes/camera.js";

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const camera = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

// Initialize the light engine
const lightEngine = camera.initMaskLightEngine();

// Customize the mask
// Change mask color for penumbra effects (lighter shadows)
lightEngine.mask = {
    color: "rgba(0,0,0,0.9)" // 90% opacity = lighter shadows
};

// Change z-order (default is 999)
lightEngine.zIndex = 100; // Draw lights behind game elements

// Add a light
const light = lightEngine.addLightEmitter(400, 300, 200, "#ffffff");

// In game loop
function gameLoop() {
    camera.clear();
    // ...
    camera.flipBuffer();
    requestAnimationFrame(gameLoop);
}

📦 Constructor

The maskLightEngine constructor is typically not called directly. Instead, use Camera.initMaskLightEngine().

If you need to create a standalone instance, the constructor accepts:

Parameter Type Description
mask object Mask configuration object with x, y, width, height, and color properties.

📊 Properties

All properties have getter and setter methods.

mask

Type: object

Default: {x: 0, y: 0, width: camera.width, height: camera.height, color: "rgba(0,0,0,1)"}

Description: Configuration of the mask. Contains x, y, width, height, and color properties.

zIndex

Type: number

Default: 999

Description: Drawing order. Higher values are drawn on top. Default is 999 (lights on top of everything).

🔧 Public Methods

addLightEmitter(x, y, radius, color=null)

Parameters:

  • x: number - X coordinate of the light emitter.
  • y: number - Y coordinate of the light emitter.
  • radius: number - Radius of the light emitter in pixels.
  • color: string - Optional color of the light (HEX or RGB format).

Description: Creates and adds a new light emitter to the engine. Returns the LightEmitter instance for further configuration.

Returns: LightEmitter - The created light emitter instance.

removeLightEmitter(lightEmitterInstance)

Parameters:

  • lightEmitterInstance: LightEmitter - The light emitter instance to remove.

Description: Removes a light emitter from the engine.

Returns: void

getLightEmitters()

Description: Returns an array of all active light emitters.

Returns: Array - Array of LightEmitter instances.

getRenderCtx()

Description: Returns the rendering context of the internal render canvas. Useful for custom rendering.

Returns: CanvasRenderingContext2D - The 2D rendering context.

🔒 Private Methods

The following methods are private (prefixed with _ or #) and are used internally by the engine. Do not call these methods directly.

_drawLightEmitters(camera)

Parameters:

  • camera: Camera - The camera to draw lights on.

Description: Internal method for drawing all light emitters. Called automatically during camera flipBuffer().

#updateMaskCanvas()

Description: Updates the mask canvas with the current mask configuration.

#updateRenderCanvas()

Description: Updates the render canvas by:

  1. Drawing the mask
  2. Using destination-out composite operation to "punch holes" for each light emitter
  3. Using source-over composite operation to apply light colors

⚠️ Warning: Methods starting with _ or # are PRIVATE. Incorrect usage can crash the engine. Only use the public methods documented above.

🎯 Examples

Example 1: Basic Lighting Setup

import { Camera } from "../classes/camera.js";
import { Scene } from "../classes/scene.js";

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const camera = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#000000" // Dark background for lighting effects
});

// Initialize the light engine
const lightEngine = camera.initMaskLightEngine();

// Add lights
const playerLight = lightEngine.addLightEmitter(400, 300, 100, "#ffffff");
const ambientLight1 = lightEngine.addLightEmitter(200, 200, 200, "#ffaa00");
const ambientLight2 = lightEngine.addLightEmitter(600, 400, 150, "#00aaff");

// Create a scene and add elements
const scene = new Scene();
// Add your game elements to the scene...

// In game loop
function gameLoop() {
    camera.clear();
    
    // Draw scene
    scene.draw(camera);
    
    camera.flipBuffer();
    requestAnimationFrame(gameLoop);
}
gameLoop();

Example 2: Flashlight Effect

import { Camera } from "../classes/camera.js";

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const camera = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#000000"
});

// Initialize the light engine
const lightEngine = camera.initMaskLightEngine();

// Create a directional light (flashlight)
const flashlight = lightEngine.addLightEmitter(400, 300, 150, "#ffffff");
flashlight.angleRange = 45; // Narrow beam
flashlight.lookAt = {x: 600, y: 300}; // Pointing right

// Animate the flashlight
let angle = 0;
function gameLoop() {
    camera.clear();
    
    // Rotate flashlight
    angle += 0.01;
    flashlight.lookAt = {
        x: 400 + Math.cos(angle) * 300,
        y: 300 + Math.sin(angle) * 200
    };
    
    // Draw your game elements here
    // ...
    
    camera.flipBuffer();
    requestAnimationFrame(gameLoop);
}
gameLoop();

💡 Tips and Best Practices

  • 🎯 Use initMaskLightEngine() on the camera to initialize the light engine.
  • 🎯 The mask canvas is automatically sized to match the camera dimensions.
  • 🎯 The mask position is relative to the camera position - it moves with the camera.
  • 🎯 Adjust the mask color opacity to control shadow darkness (e.g., rgba(0,0,0,0.9) for softer shadows).
  • 🎯 Use zIndex to control whether lights are drawn on top of or behind game elements.
  • 🎯 The default zIndex is 999, meaning lights are drawn on top of most elements.
  • 🎯 For performance, minimize the number of active light emitters.
  • 🎯 Larger radius lights are more expensive to render.
  • 🎯 Light masks can overlap without interfering with each other.
