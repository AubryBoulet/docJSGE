Transition

Classe pour créer des animations fluides avec différentes courbes d'interpolation.

📌 Description

La classe Transition permet de créer des animations fluides entre deux valeurs en utilisant différentes fonctions d'interpolation (easing functions). Elle est particulièrement utile pour les animations d'interface, les déplacements d'entités, ou toute autre animation qui nécessite un contrôle précis du mouvement.

Transition utilise les fonctions de la classe Bezier pour les courbes d'interpolation, ce qui permet une grande variété d'effets d'animation.

⚠️ Important: Les transitions sont gérées globalement et mises à jour automatiquement via requestAnimationFrame.

🚀 Utilisation de base

Créer une transition simple

import { Transition } from "../classes/transition.js";

// Créer une transition entre deux valeurs
const transitionId = Transition.create([
    0,          // Valeur initiale
    100,       // Valeur cible
    "linear",  // Fonction d'interpolation
    (value) => {
        // Callback appelé à chaque mise à jour avec la valeur actuelle
        console.log("Valeur actuelle:", value);
    },
    1,         // Durée en secondes
    0,         // Délai avant le début
    () => {    // Callback appelé à la fin de la transition
        console.log("Transition terminée !");
    }
]);

// Pour annuler la transition plus tard :
// Transition.delete(transitionId);

Créer une transition avec easing

import { Transition } from "../classes/transition.js";

// Créer une transition avec easing "easeOutElastic"
const bouncyTransition = Transition.create([
    0,
    500,
    "easeOutElastic",  // Effet rebond
    (value) => {
        element.style.left = value + "px";
    },
    1.5,  // 1.5 secondes
    0.5   // Délai de 0.5 seconde
]);

🔧 Méthode de création

La classe Transition utilise une méthode statique create() :

Paramètre Type Défaut Description
args Array - Tableau contenant les paramètres de la transition.

Le tableau args doit contenir les éléments suivants dans l'ordre :

Index Paramètre Type Défaut Description
0 initialValue number - Valeur de départ de la transition.
1 targetValue number - Valeur cible de la transition.
2 timingFunction string "linear" Nom de la fonction d'interpolation (voir Bezier).
3 callback function - Fonction appelée à chaque mise à jour avec la valeur interpolée.
4 duration number 1 Durée de la transition en secondes.
5 delay number 0 Délai avant le début de la transition en secondes.
6 endCallback function - Fonction appelée à la fin de la transition.

⚙️ Méthodes statiques

Transition.create(args)

Paramètres:

  • args: Array - Tableau de paramètres (voir ci-dessus).

Description: Crée une nouvelle transition.

Retourne: number - L'ID de la transition créée.

Transition.delete(transitionId)

Paramètres:

  • transitionId: number - L'ID de la transition à supprimer.

Description: Supprime une transition spécifique.

Retourne: void

Transition.clear()

Description: Supprime toutes les transitions actives.

Retourne: void

Transition.reset(transitionId)

Paramètres:

  • transitionId: number - L'ID de la transition à réinitialiser.

Description: Réinitialise une transition (redémarre depuis le début).

Retourne: void

Exemple 1: Transition basique

1-7: Changer easing | R: Réinitialiser 

import { Transition } from "../classes/transition.js";

// Créer une transition pour animer la position X d'un élément
let currentX = 0;
const targetX = 500;

const transitionId = Transition.create([
    currentX,           // Valeur initiale
    targetX,           // Valeur cible
    "easeInOutQuad",   // Fonction d'interpolation
    (value) => {
        // Mettre à jour la position
        currentX = value;
        element.style.left = currentX + "px";
    },
    2,                 // Durée: 2 secondes
    0,                 // Délai: 0 seconde
    () => {
        console.log("Transition terminée !");
    }
]);

// Plus tard, vous pouvez annuler la transition
// Transition.delete(transitionId);

Exemple 3: Animation d'une entité avec Transition

import { Transition } from "../classes/transition.js";
import { Entity } from "../classes/entity.js";

// Créer une entité
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100}
});

// Animer le déplacement de l'entité
function moveTo(x, y, easing = "linear", duration = 1) {
    // Supprimer les transitions existantes
    if (player.transitionId) {
        Transition.delete(player.transitionId);
    }
    
    // Créer de nouvelles transitions pour X et Y
    const startX = player.position.x;
    const startY = player.position.y;
    
    const xTransitionId = Transition.create([
        startX,
        x,
        easing,
        (value) => {
            player.position.x = value;
        },
        duration
    ]);
    
    const yTransitionId = Transition.create([
        startY,
        y,
        easing,
        (value) => {
            player.position.y = value;
        },
        duration
    ]);
    
    // Stocker les IDs pour pouvoir les annuler plus tard
    player.transitionId = [xTransitionId, yTransitionId];
}

// Utiliser la fonction
moveTo(300, 200, "easeOutElastic", 1.5);

Exemple 4: Transition en chaîne

import { Transition } from "../classes/transition.js";

let currentTransitionId = null;

function startChainedAnimation() {
    // Étape 1: Déplacer vers la droite
    currentTransitionId = Transition.create([
        0,
        400,
        "easeOutBack",
        (value) => {
            element.style.left = value + "px";
        },
        1,
        0,
        () => {
            // Étape 2: Déplacer vers le bas (après la fin de l'étape 1)
            currentTransitionId = Transition.create([
                0,
                300,
                "easeInOutCubic",
                (value) => {
                    element.style.top = value + "px";
                },
                1,
                0,
                () => {
                    // Étape 3: Retour à la position initiale
                    currentTransitionId = Transition.create([
                        400,
                        0,
                        "easeInBack",
                        (value) => {
                            element.style.left = value + "px";
                        },
                        1
                    ]);
                }
            ]);
        }
    ]);
}

// Démarrer l'animation
startChainedAnimation();

💡 Conseils et bonnes pratiques

  • 🔹 Utilisez des fonctions d'interpolation appropriées pour l'effet souhaité (ex: easeOutElastic pour un effet rebond).
  • 🔹 N'oubliez pas de supprimer les transitions inutiles avec Transition.delete() pour éviter les fuites de mémoire.
  • 🔹 Utilisez Transition.clear() pour supprimer toutes les transitions si nécessaire.
  • 🔹 Les transitions sont automatiquement mises à jour via requestAnimationFrame, vous n'avez pas besoin de les mettre à jour manuellement.
  • 🔹 Pour les animations complexes, envisagez d'enchaîner les transitions en utilisant les callbacks de fin.
  • 🔹 Utilisez la méthode reset() pour redémarrer une transition depuis le début.
  • 🔹 Les transitions sont légères et optimisées pour les animations fluides.

easeInCubic Accélération cubique Accélération plus prononcée
easeOutCubic Décélération cubique Ralentissement plus prononcé
easeInOutCubic Accélération puis décélération cubique Effet plus prononcé que Quad
easeInQuart Accélération quartique Accélération très prononcée
easeOutQuart Décélération quartique Ralentissement très prononcé
easeInOutQuart Accélération puis décélération quartique Effet très prononcé
easeInQuint Accélération quintique Accélération extrêmement prononcée
easeOutQuint Décélération quintique Ralentissement extrêmement prononcé
easeInOutQuint Accélération puis décélération quintique Effet extrêmement prononcé
easeInSine Accélération sinusoïdale Effet sinusoïdal en entrée
easeOutSine Décélération sinusoïdale Effet sinusoïdal en sortie
easeInOutSine Accélération puis décélération sinusoïdale Effet sinusoïdal complet
easeInExpo Accélération exponentielle Accélération très rapide
easeOutExpo Décélération exponentielle Ralentissement très rapide
easeInOutExpo Accélération puis décélération exponentielle Effet exponentiel complet
easeInCirc Accélération circulaire Effet circulaire en entrée
easeOutCirc Décélération circulaire Effet circulaire en sortie
easeInOutCirc Accélération puis décélération circulaire Effet circulaire complet
easeInElastic Accélération élastique Effet élastique avec rebond en entrée
easeOutElastic Décélération élastique Effet élastique avec rebond en sortie
easeInOutElastic Accélération puis décélération élastique Effet élastique complet
easeInBack Accélération avec rebond arrière Effet de rebond en entrée
easeOutBack Décélération avec rebond arrière Effet de rebond en sortie
easeInOutBack Accélération puis décélération avec rebond Effet de rebond complet
easeOutBounce Décélération avec rebond Effet de rebond prononcée (comme un ballon)
easeInBounce Accélération avec rebond Effet de rebond en entrée
easeInOutBounce Accélération puis décélération avec rebond Effet de rebond complet
