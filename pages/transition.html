Transition

Class for creating smooth animations with different interpolation curves.

📌 Description

The Transition class allows you to create smooth animations between two values using different interpolation functions (easing functions). It is particularly useful for UI animations, entity movements, or any other animation that requires precise motion control.

Transition uses the functions from the Bezier class for interpolation curves, which allows for a wide variety of animation effects.

⚠️ Important: Transitions are globally managed and automatically updated via requestAnimationFrame.

🚀 Basic Usage

Create a Simple Transition

import { Transition } from "../classes/transition.js";

// Create a transition between two values
const transitionId = Transition.create([
    0,          // Initial value
    100,       // Target value
    "linear",  // Interpolation function
    (value) => {
        // Callback called on each update with the current value
        console.log("Current value:", value);
    },
    1,         // Duration in seconds
    0,         // Delay before start
    () => {    // Callback called at the end of the transition
        console.log("Transition complete!");
    }
]);

// To cancel the transition later:
// Transition.delete(transitionId);

Create a Transition with Easing

import { Transition } from "../classes/transition.js";

// Create a transition with "easeOutElastic" easing
const bouncyTransition = Transition.create([
    0,
    500,
    "easeOutElastic",  // Bounce effect
    (value) => {
        element.style.left = value + "px";
    },
    1.5,  // 1.5 seconds
    0.5   // 0.5 second delay
]);

🔧 Creation Method

The Transition class uses a static create() method:

Parameter Type Default Description
args Array - Array containing the transition parameters.

The args array must contain the following elements in order:

Index Parameter Type Default Description
0 initialValue number - Starting value of the transition.
1 targetValue number - Target value of the transition.
2 timingFunction string "linear" Name of the interpolation function (see Bezier).
3 callback function - Function called on each update with the interpolated value.
4 duration number 1 Duration of the transition in seconds.
5 delay number 0 Delay before the transition starts in seconds.
6 endCallback function - Function called at the end of the transition.

⚙️ Static Methods

Transition.create(args)

Parameters:

  • args: Array - Array of parameters (see above).

Description: Creates a new transition.

Returns: number - The ID of the created transition.

Transition.delete(transitionId)

Parameters:

  • transitionId: number - The ID of the transition to remove.

Description: Removes a specific transition.

Returns: void

Transition.clear()

Description: Removes all active transitions.

Returns: void

Transition.reset(transitionId)

Parameters:

  • transitionId: number - The ID of the transition to reset.

Description: Resets a transition (restarts from the beginning).

Returns: void

Example 1: Basic Transition

1-7: Change easing | R: Reset 

import { Transition } from "../classes/transition.js";

// Create a transition to animate an element's X position
let currentX = 0;
const targetX = 500;

const transitionId = Transition.create([
    currentX,           // Initial value
    targetX,           // Target value
    "easeInOutQuad",   // Interpolation function
    (value) => {
        // Update position
        currentX = value;
        element.style.left = currentX + "px";
    },
    2,                 // Duration: 2 seconds
    0,                 // Delay: 0 second
    () => {
        console.log("Transition complete!");
    }
]);

// Later, you can cancel the transition
// Transition.delete(transitionId);

Example 3: Animate an Entity with Transition

import { Transition } from "../classes/transition.js";
import { Entity } from "../classes/entity.js";

// Create an entity
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100}
});

// Animate entity movement
function moveTo(x, y, easing = "linear", duration = 1) {
    // Delete existing transitions
    if (player.transitionId) {
        Transition.delete(player.transitionId);
    }
    
    // Create new transitions for X and Y
    const startX = player.position.x;
    const startY = player.position.y;
    
    const xTransitionId = Transition.create([
        startX,
        x,
        easing,
        (value) => {
            player.position.x = value;
        },
        duration
    ]);
    
    const yTransitionId = Transition.create([
        startY,
        y,
        easing,
        (value) => {
            player.position.y = value;
        },
        duration
    ]);
    
    // Store IDs to be able to cancel them later
    player.transitionId = [xTransitionId, yTransitionId];
}

// Use the function
moveTo(300, 200, "easeOutElastic", 1.5);

Example 4: Chained Transition

import { Transition } from "../classes/transition.js";

let currentTransitionId = null;

function startChainedAnimation() {
    // Step 1: Move to the right
    currentTransitionId = Transition.create([
        0,
        400,
        "easeOutBack",
        (value) => {
            element.style.left = value + "px";
        },
        1,
        0,
        () => {
            // Step 2: Move down (after step 1 completes)
            currentTransitionId = Transition.create([
                0,
                300,
                "easeInOutCubic",
                (value) => {
                    element.style.top = value + "px";
                },
                1,
                0,
                () => {
                    // Step 3: Return to initial position
                    currentTransitionId = Transition.create([
                        400,
                        0,
                        "easeInBack",
                        (value) => {
                            element.style.left = value + "px";
                        },
                        1
                    ]);
                }
            ]);
        }
    ]);
}

// Start animation
startChainedAnimation();

💡 Tips and Best Practices

  • 🔹 Use appropriate interpolation functions for the desired effect (e.g., easeOutElastic for a bounce effect).
  • 🔹 Don't forget to delete unused transitions with Transition.delete() to avoid memory leaks.
  • 🔹 Use Transition.clear() to remove all transitions if needed.
  • 🔹 Transitions are automatically updated via requestAnimationFrame, you don't need to update them manually.
  • 🔹 For complex animations, consider chaining transitions using end callbacks.
  • 🔹 Use the reset() method to restart a transition from the beginning.
  • 🔹 Transitions are lightweight and optimized for smooth animations.

📖 Available Interpolation Functions

Transition uses the functions from the Bezier class. Here is the complete list:

Name Description Effect
linear Linear interpolation Constant speed
easeInQuad Quadratic acceleration Slow start, acceleration
easeOutQuad Quadratic deceleration Fast start, slow down
easeInOutQuad Quadratic acceleration then deceleration Slow start, acceleration, slow down
easeInCubic Cubic acceleration More pronounced acceleration
easeOutCubic Cubic deceleration More pronounced slow down
easeInOutCubic Cubic acceleration then deceleration More pronounced than Quad
easeInQuart Quartic acceleration Very pronounced acceleration
easeOutQuart Quartic deceleration Very pronounced slow down
easeInOutQuart Quartic acceleration then deceleration Very pronounced effect
easeInQuint Quintic acceleration Extremely pronounced acceleration
easeOutQuint Quintic deceleration Extremely pronounced slow down
easeInOutQuint Quintic acceleration then deceleration Extremely pronounced effect
easeInSine Sine acceleration Sine wave in effect
easeOutSine Sine deceleration Sine wave out effect
easeInOutSine Sine acceleration then deceleration Complete sine wave effect
easeInExpo Exponential acceleration Very fast acceleration
easeOutExpo Exponential deceleration Very fast slow down
easeInOutExpo Exponential acceleration then deceleration Complete exponential effect
easeInCirc Circular acceleration Circular in effect
easeOutCirc Circular deceleration Circular out effect
easeInOutCirc Circular acceleration then deceleration Complete circular effect
easeInElastic Elastic acceleration Elastic effect with bounce in
easeOutElastic Elastic deceleration Elastic effect with bounce out
easeInOutElastic Elastic acceleration then deceleration Complete elastic effect
easeInBack Back acceleration Pull back effect in
easeOutBack Back deceleration Pull back effect out
easeInOutBack Back acceleration then deceleration Complete pull back effect
easeOutBounce Bounce deceleration Pronounced bounce effect (like a ball)
easeInBounce Bounce acceleration Bounce effect in
easeInOutBounce Bounce acceleration then deceleration Complete bounce effect
