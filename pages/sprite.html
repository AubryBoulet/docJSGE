Sprite

Classe pour charger, créer et gérer des images et sprites pour le rendu 2D.

📌 Description

La classe Sprite permet de charger des images depuis des fichiers ou de créer des sprites dynamiquement. Elle gère également les animations via la classe Animation. Chaque sprite peut être animé ou statique, et peut être utilisé avec des entités pour l'affichage dans une caméra.

⚠️ Important: Les sprites chargés depuis des images sont asynchrones. Utilisez await ou .then() pour attendre le chargement.

🚀 Utilisation de base

Charger un sprite depuis une image

import { Sprite } from "../classes/sprites.js";

// Méthode asynchrone pour charger une image
const playerSprite = await Sprite.load("./assets/player.png", true);

// Le sprite est maintenant prêt à être utilisé
console.log("Sprite chargé:", playerSprite);

Créer un sprite vide

import { Sprite } from "../classes/sprites.js";

// Créer un sprite vide de 50x50 pixels
const emptySprite = Sprite.create(50, 50, false);

// Dessiner sur le sprite
const ctx = emptySprite.ctx;
ctx.fillStyle = "red";
ctx.fillRect(0, 0, 50, 50);

🔧 Constructeur

La classe Sprite peut être instanciée directement, mais il est recommandé d'utiliser les méthodes statiques :

Méthode Paramètres Retourne Description
Sprite.load(imageSrc, animate) imageSrc: string - Chemin vers l'image
animate: boolean - Si vrai, le sprite est animé 		Promise<Sprite> Charge une image et retourne une promesse avec le sprite.
Sprite.create(width, height, animate) width: number - Largeur du sprite
height: number - Hauteur du sprite
animate: boolean - Si vrai, le sprite est animé 		Sprite Crée un sprite vide avec les dimensions spécifiées.

📜 Propriétés

image

Type: HTMLImageElement | HTMLCanvasElement

Description: L'image ou le canvas sous-jacent du sprite.

ctx

Type: CanvasRenderingContext2D | null

Description: Le contexte 2D si le sprite a été créé avec Sprite.create().

width

Type: number

Description: Largeur du sprite.

height

Type: number

Description: Hauteur du sprite.

animate

Type: boolean

Description: Indique si le sprite est animé.

animations

Type: Animation

Description: L'objet Animation associé au sprite pour gérer les animations.

scale

Type: number

Description: Échelle du sprite (par défaut 1).

⚙️ Méthodes

initSpriteSheet()

Description: Initialise les dimensions du sprite sheet. Appelé automatiquement lors du chargement.

Retourne: void

🎯 Exemples

Exemple 1: Charger et afficher un sprite

Flèches: Déplacer | + / -: Zoom | R: Rotation | S: Réinitialiser 

import { Sprite } from "../classes/sprites.js";
import { Entity } from "../classes/entity.js";
import { Camera } from "../classes/camera.js";

// Charger un sprite
const playerSprite = await Sprite.load("./assets/player.png", true);

// Créer une entité avec le sprite
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100}
});

// Créer une caméra
const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

function gameLoop() {
    mainCam.clear();
    player.drawEntity(mainCam);
    requestAnimationFrame(gameLoop);
}
gameLoop();

Exemple 2: Créer un sprite dynamiquement

import { Sprite } from "../classes/sprites.js";

// Créer un sprite vide de 100x100 pixels
const customSprite = Sprite.create(100, 100, false);

// Dessiner un cercle sur le sprite
const ctx = customSprite.ctx;
ctx.fillStyle = "#3498db";
ctx.beginPath();
ctx.arc(50, 50, 40, 0, Math.PI * 2);
ctx.fill();

// Dessiner un texte
ctx.fillStyle = "#fff";
ctx.font = "20px Arial";
ctx.textAlign = "center";
ctx.textBaseline = "middle";
ctx.fillText("JSGE", 50, 50);

// Utiliser le sprite avec une entité
const entity = Entity.create({
    sprite: customSprite,
    position: {x: 200, y: 200}
});

Exemple 3: Charger plusieurs sprites

import { Sprite } from "../classes/sprites.js";

// Charger plusieurs sprites en parallèle
const spritePromises = [
    Sprite.load("./assets/player.png", true),
    Sprite.load("./assets/enemy.png", true),
    Sprite.load("./assets/background.png", false)
];

// Attendre que tous les sprites soient chargés
Promise.all(spritePromises)
    .then(([playerSprite, enemySprite, bgSprite]) => {
        // Tous les sprites sont prêts
        const player = Entity.create({ sprite: playerSprite });
        const enemy = Entity.create({ sprite: enemySprite });
        
        // Utiliser les sprites...
    })
    .catch(error => {
        console.error("Erreur de chargement:", error);
    });

💡 Conseils et bonnes pratiques

  • 🔹 Toujours attendre que les sprites soient chargés avant de les utiliser avec await ou .then().
  • 🔹 Utilisez Sprite.create() pour créer des sprites dynamiques (barres de vie, icônes, etc.).
  • 🔹 Pour de meilleures performances, préchargez tous vos sprites avant de commencer le jeu.
  • 🔹 Les sprites animés (animate: true) sont optimisés pour les animations avec la classe Animation.
  • 🔹 Vous pouvez modifier directement le contexte (ctx) d'un sprite créé avec Sprite.create() pour dessiner dessus.
  • 🔹 Pour les jeux avec beaucoup de sprites, envisagez de les regrouper dans des sprite sheets pour réduire le nombre de requêtes HTTP.
