Sprite

Class for loading, creating and managing images and sprites for 2D rendering.

📌 Description

The Sprite class allows you to load images from files or create sprites dynamically. It also handles animations via the Animation class. Each sprite can be animated or static, and can be used with entities for display in a camera.

⚠️ Important: Sprites loaded from images are asynchronous. Use await or .then() to wait for loading.

🚀 Basic Usage

Load a Sprite from an Image

import { Sprite } from "../classes/sprites.js";

// Async method to load an image
const playerSprite = await Sprite.load("./assets/player.png", true);

// The sprite is now ready to use
console.log("Sprite loaded:", playerSprite);

Create an Empty Sprite

import { Sprite } from "../classes/sprites.js";

// Create an empty sprite of 50x50 pixels
const emptySprite = Sprite.create(50, 50, false);

// Draw on the sprite
const ctx = emptySprite.ctx;
ctx.fillStyle = "red";
ctx.fillRect(0, 0, 50, 50);

Type: HTMLImageElement | HTMLCanvasElement

Description: The underlying image or canvas of the sprite.

Type: CanvasRenderingContext2D | null

Description: The 2D context if the sprite was created with Sprite.create().

width

Type: number

Description: Width of the sprite.

height

Type: number

Description: Height of the sprite.

animate

Type: boolean

Description: Indicates if the sprite is animated.

animations

Type: Animation

Description: The Animation object associated with the sprite to manage animations.

scale

Type: number

Description: Scale of the sprite (default 1).

🎯 Examples

Example 1: Load and Display a Sprite

Arrows: Move | + / -: Zoom | R: Rotate | S: Reset 

import { Sprite } from "../classes/sprites.js";
import { Entity } from "../classes/entity.js";
import { Camera } from "../classes/camera.js";

// Load a sprite
const playerSprite = await Sprite.load("./assets/player.png", true);

// Create an entity with the sprite
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100}
});

// Create a camera
const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600}
});

function gameLoop() {
    mainCam.clear();
    player.drawEntity(mainCam);
    requestAnimationFrame(gameLoop);
}
gameLoop();

Example 2: Create a Sprite Dynamically

import { Sprite } from "../classes/sprites.js";

// Create an empty sprite of 100x100 pixels
const customSprite = Sprite.create(100, 100, false);

// Draw a circle on the sprite
const ctx = customSprite.ctx;
ctx.fillStyle = "#3498db";
ctx.beginPath();
ctx.arc(50, 50, 40, 0, Math.PI * 2);
ctx.fill();

// Draw text
ctx.fillStyle = "#fff";
ctx.font = "20px Arial";
ctx.textAlign = "center";
ctx.textBaseline = "middle";
ctx.fillText("JSGE", 50, 50);

// Use the sprite with an entity
const entity = Entity.create({
    sprite: customSprite,
    position: {x: 200, y: 200}
});

Example 3: Load Multiple Sprites

import { Sprite, Entity, Camera, Scene } from "./jsge.js";

// Game state management
const gameState = {
    current: "loading", // loading, running
    sprites: {},
    camera: null,
    scene: null
};

// Initialize game
async function initGame() {
    // Create camera and scene
    gameState.camera = new Camera(800, 600);
    gameState.scene = new Scene();
    
    // Load multiple sprites in parallel
    const spritePromises = [
        Sprite.load("./assets/player.png", true),
        Sprite.load("./assets/enemy.png", true),
        Sprite.load("./assets/background.png", false)
    ];
    
    try {
        // Wait for all sprites to load
        const [playerSprite, enemySprite, bgSprite] = await Promise.all(spritePromises);
        
        // Store loaded sprites
        gameState.sprites.player = playerSprite;
        gameState.sprites.enemy = enemySprite;
        gameState.sprites.background = bgSprite;
        
        // Create entities
        const player = Entity.create({ sprite: playerSprite });
        const enemy = Entity.create({ sprite: enemySprite });
        
        // Add to scene
        gameState.scene.add(player);
        gameState.scene.add(enemy);
        
        // Transition to running state
        gameState.current = "running";
        
    } catch (error) {
        console.error("Loading error:", error);
    }
}

// Game loop
function gameLoop() {
    if (gameState.current === "loading") {
        // Display loading screen
        gameState.camera.clear();
        // Display loading methode...
        gameState.camera.flipBuffer();
    } else if (gameState.current === "running") {
        // Main game rendering
        gameState.camera.clear();
        gameState.scene.draw(gameState.camera);
        gameState.camera.flipBuffer();
    }
    
    requestAnimationFrame(gameLoop);
}

// Start the game
initGame();
gameLoop();

💡 Tips and Best Practices

  • 🔹 Always wait for sprites to load before using them with await or .then().
  • 🔹 Use Sprite.create() to create dynamic sprites (health bars, icons, etc.).
  • 🔹 For better performance, preload all your sprites before starting the game.
  • 🔹 Animated sprites (animate: true) are optimized for animations with the Animation class.
  • 🔹 You can directly modify the context (ctx) of a sprite created with Sprite.create() to draw on it.
  • 🔹 For games with many sprites, consider grouping them into sprite sheets to reduce the number of HTTP requests.
