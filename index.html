Welcome to JSGE Documentation

A lightweight and performant 2D game engine written in pure JavaScript.

📖 About JSGE

⚡ Fast

JSGE is optimized for maximum performance, using requestAnimationFrame for smooth 60 FPS rendering.

🎨 Flexible

Designed to be easily extensible, with a modular and well-organized class system.

📱 Lightweight

No external dependencies, just pure JavaScript. Perfect for lightweight web games.

🚀 Installation and Usage

<!DOCTYPE html>
<html>
<head>
    <title>My JSGE Game</title>
</head>
<body>
    <canvas id="gameCanvas" width="800" height="600"></canvas>
    <script src="jsge.js" type="module"></script>
    <script src="myGame.js" type="module"></script>
</body>
</html>

Or import individual classes from the classes/ folder.

📚 Quick Start Guide

1️⃣ Create a Canvas

Start by adding a canvas element to your HTML:

<canvas id="gameCanvas" width="800" height="600"></canvas>

2️⃣ Initialize a Camera

The Camera is the heart of rendering in JSGE:

import { Camera } from "./classes/camera.js";

const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#222"
});

3️⃣ Load a Sprite

Load images to create sprites:

import { Sprite } from "./classes/sprites.js";

// Load a sprite from an image
const playerSprite = await Sprite.load("./assets/player.png", true);

// Or create an empty sprite
const emptySprite = Sprite.create(32, 32, false);

4️⃣ Create an Entity

Entities are the game objects:

import { Entity } from "./classes/entity.js";

const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    scale: 1,
    physic: true,
    gravity: 0.5
});

5️⃣ Game Loop

Update and draw your entities:

function gameLoop() {
    // Clear the camera
    mainCam.clear();
    
    // Update entity
    player.update();
    
    // Draw entity
    player.drawEntity(mainCam);
    
    requestAnimationFrame(gameLoop);
}
gameLoop();

📝 Full Example

A complete example showing multiple JSGE features:

Move character with arrow keys. Hover over the button. 

import { Camera } from "./classes/camera.js";
import { Sprite } from "./classes/sprites.js";
import { Entity } from "./classes/entity.js";
import { Button } from "./classes/button.js";

// Initialization
const canvas = document.querySelector("#gameCanvas");
const ctx = canvas.getContext("2d");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#222"
});

// Load a sprite
const playerSprite = await Sprite.load("./assets/player.png", true);

// Create player entity
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 400, y: 300},
    physic: true
});

// Create a button
const button = Button.create("Click Me", {
    width: 200,
    height: 50
});
button.position = {x: 300, y: 500};

// Keyboard input handling
document.addEventListener("keydown", (e) => {
    const speed = 5;
    switch(e.key) {
        case 'ArrowUp': player.velocity.y = -speed; break;
        case 'ArrowDown': player.velocity.y = speed; break;
        case 'ArrowLeft': player.velocity.x = -speed; break;
        case 'ArrowRight': player.velocity.x = speed; break;
    }
});

// Game loop
function gameLoop() {
    mainCam.clear();
    
    player.update();
    player.drawEntity(mainCam);
    
    button.draw(mainCam);
    
    requestAnimationFrame(gameLoop);
}
gameLoop();
