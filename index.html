Bienvenue dans la documentation JSGE

Un moteur de jeu 2D léger et performant développé en JavaScript pur.

📖 À propos de JSGE

⚡ Rapide

JSGE est optimisé pour des performances maximales, utilisant requestAnimationFrame pour un rendu fluide à 60 FPS.

🎨 Flexible

Conçu pour être facilement extensible, avec un système de classes modulaire et bien organisé.

📱 Léger

Aucune dépendance externe, juste du JavaScript natif. Parfait pour les jeux web légers.

🚀 Installation et utilisation

<!DOCTYPE html>
<html>
<head>
    <title>Mon Jeu JSGE</title>
</head>
<body>
    <canvas id="gameCanvas" width="800" height="600"></canvas>
    <script src="jsge.js" type="module"></script>
    <script src="monJeu.js" type="module"></script>
</body>
</html>

Ou importez les classes individuellement depuis le dossier classes/.

📚 Guide de démarrage

1️⃣ Créer un canvas

Commencez par ajouter un élément canvas à votre HTML :

<canvas id="gameCanvas" width="800" height="600"></canvas>

2️⃣ Initialiser une caméra

La caméra est le cœur du rendu dans JSGE :

import { Camera } from "./classes/camera.js";

const canvas = document.querySelector("#gameCanvas");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#222"
});

3️⃣ Charger un sprite

Chargez vos images pour créer des sprites :

import { Sprite } from "./classes/sprites.js";

// Charger un sprite depuis une image
const playerSprite = await Sprite.load("./assets/player.png", true);

// Ou créer un sprite vide
const emptySprite = Sprite.create(32, 32, false);

4️⃣ Créer une entité

Les entités sont les objets de votre jeu :

import { Entity } from "./classes/entity.js";

const player = Entity.create({
    sprite: playerSprite,
    position: {x: 100, y: 100},
    scale: 1,
    physic: true,
    gravity: 0.5
});

5️⃣ Boucle de jeu

Mettez à jour et dessinez vos entités :

function gameLoop() {
    // Effacer la caméra
    mainCam.clear();
    
    // Mettre à jour l'entité
    player.update();
    
    // Dessiner l'entité
    player.drawEntity(mainCam);
    
    requestAnimationFrame(gameLoop);
}
gameLoop();

📝 Exemple complet

Un exemple complet montrant l'utilisation de plusieurs fonctionnalités de JSGE :

Déplacez le personnage avec les flèches. Passez la souris sur le bouton. 

import { Camera } from "./classes/camera.js";
import { Sprite } from "./classes/sprites.js";
import { Entity } from "./classes/entity.js";
import { Button } from "./classes/button.js";

// Initialisation
const canvas = document.querySelector("#gameCanvas");
const ctx = canvas.getContext("2d");
const mainCam = new Camera({
    canvas: canvas,
    position: {x: 0, y: 0},
    dimensions: {width: 800, height: 600},
    backgroundColor: "#222"
});

// Charger un sprite
const playerSprite = await Sprite.load("./assets/player.png", true);

// Créer une entité joueur
const player = Entity.create({
    sprite: playerSprite,
    position: {x: 400, y: 300},
    physic: true
});

// Créer un bouton
const button = Button.create("Cliquez ici", {
    width: 200,
    height: 50
});
button.position = {x: 300, y: 500};

// Gestion des entrées clavier
document.addEventListener("keydown", (e) => {
    const speed = 5;
    switch(e.key) {
        case 'ArrowUp': player.velocity.y = -speed; break;
        case 'ArrowDown': player.velocity.y = speed; break;
        case 'ArrowLeft': player.velocity.x = -speed; break;
        case 'ArrowRight': player.velocity.x = speed; break;
    }
});

// Boucle de jeu
function gameLoop() {
    mainCam.clear();
    
    player.update();
    player.drawEntity(mainCam);
    
    button.draw(mainCam);
    
    requestAnimationFrame(gameLoop);
}
gameLoop();
